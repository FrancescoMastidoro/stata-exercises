## Background
The `auto` dataset contains information on 74 automobiles from 1978, including price, fuel efficiency, and repair records. Diagnosing data quality problems — spotting missing values, checking whether numeric ranges are plausible, and verifying that variables are stored in the right format — is the first thing a careful researcher does before running any model, because undetected issues silently distort every result downstream.

## Your tasks

1. **Audit variable types and structure** — Load the dataset with `sysuse auto, clear` and run `describe`. Identify which variable is stored as a string and which variables are stored as labeled numeric types. Write a comment in your do-file noting what real-world concept each of those variables captures and why string storage might create problems for numeric analysis.

2. **Find and count missing values** — Run `misstable summarize` to produce a compact overview of missingness across all variables. Which variable has missing values, and how many observations are affected? Then confirm the count using `count if missing(rep78)`. Write a comment explaining what it means substantively if a car's repair record is missing — is it likely random, or might there be a systematic reason?

3. **Inspect the distribution of the variable with missing values** — Run `summarize rep78, detail`. Note the mean, median, and the reported number of observations. How many observations were excluded from the summary due to missingness? Write a comment stating whether the distribution appears roughly symmetric or skewed, and what the scale of `rep78` (check it with `codebook rep78`) actually represents.

4. **Check for implausible values in a continuous variable** — Use `summarize` and `codebook` on the variable `mpg` to retrieve its minimum and maximum. Then use `tabulate mpg` to see the full distribution. Write `count` commands with appropriate `if` conditions to flag any values that fall below 15 or above 35 miles per gallon. Write a comment discussing whether those extreme values seem like data errors or genuine outliers for 1978 cars, given the overall distribution.

5. *(Bonus)* **Compare distributions across a labeled group** — Use `tabulate foreign` to confirm the two categories of the `foreign` variable and their numeric codes. Then run `summarize rep78 if foreign == 0` and `summarize rep78 if foreign == 1`, noting how Stata handles the missing values automatically. Compare the means and observation counts between domestic and foreign cars. Write a comment discussing whether missingness appears to be concentrated in one group — and what that would imply for any analysis that drops missing observations without further thought.
