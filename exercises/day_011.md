## Background
The `census` dataset contains 1980 U.S. Census data aggregated at the state level, covering population composition, urbanization, and demographic outcomes across all 50 states. Visualization is a foundational skill in quantitative research because it reveals distributional shapes, outliers, and cross-group patterns that summary statistics alone can obscure — especially when working with geographic or demographic aggregates.

## Your tasks

1. **Histogram of median age** — Load the dataset with `sysuse census, clear` and draw a histogram of `medage`. Add the option `frequency` to display counts on the y-axis rather than density. Then add a descriptive title using the `title()` option. Write a comment noting the approximate center and shape of the distribution (symmetric, left-skewed, or right-skewed).

2. **Scatter plot of urbanization and median age** — Create a scatter plot with `popurban` on the x-axis and `medage` on the y-axis. Add axis labels using `xtitle()` and `ytitle()`. Write a comment describing whether there appears to be a positive, negative, or no clear relationship between urbanization and median age across states.

3. **Overlay a linear fit on the scatter plot** — Using `twoway`, combine a scatter plot and a linear fit (`lfit`) for the same variables as Task 2. Give the overall graph a title. Write a comment discussing whether the fitted line supports or contradicts what you observed visually in Task 2.

4. **Bar chart of average median age by region** — Use `graph bar medage, over(region)` to display average median age across the four Census regions. Add a title and label the y-axis. Then write a comment identifying which region has the highest average median age and proposing one demographic explanation (e.g., migration patterns, age structure of historical settlement).

5. *(Bonus)* **Side-by-side histograms by region** — Use `twoway` with the `histogram` plot type and the `by(region)` option to draw a separate histogram of `medage` for each of the four regions in a single figure. Add a shared title. Write a comment comparing the spread and center across regions — do some regions show tighter clustering than others?
