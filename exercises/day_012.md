**Dataset**: `sysuse nlsw88`

## Background
The `nlsw88` dataset contains 1988 National Longitudinal Survey data on American women, covering wages, hours worked, occupation, and demographics. Visualization is a core skill in quantitative research because patterns in distributions and bivariate relationships often reveal structure that summary statistics alone cannot capture.

## Your tasks

1. **Explore the data** — Load `nlsw88`, run `describe` and `summarize` on the variables `wage`, `hours`, `age`, and `ttl_exp`. Note which variables have missing values.

2. **Plot a wage histogram** — Draw a histogram of `wage`. Add a title and label the x-axis "Hourly wage (USD)". Then redraw it with 20 bins instead of the default number and observe how the shape changes.

3. **Overlay a density curve** — Reproduce the 20-bin histogram from Task 2, but this time add a normal density curve on top of it. Does the wage distribution look approximately normal?

4. **Scatter plot with a fit line** — Create a scatter plot of `wage` (y-axis) against `ttl_exp` (total work experience, x-axis). Using `twoway`, overlay a linear fitted line on the same graph. Add an informative title and axis labels.

5. *(Bonus)* **Bar chart by occupation group** — Using `graph bar`, plot the mean wage for each category of `occupation`. Sort the bars in descending order of mean wage and add value labels above each bar so the exact means are visible.
