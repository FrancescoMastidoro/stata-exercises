## Background
The `nlsw88` dataset contains data from the 1988 National Longitudinal Survey of Women, covering wages, hours worked, occupation, and demographics for working women in the United States. Visualization is a core skill in labor economics research because it allows you to communicate distributional patterns, group differences, and variable relationships clearly before and after formal analysis.

## Your tasks

1. **Explore the wage distribution** — Load the dataset and draw a histogram of the variable `wage`. Add a normal density curve overlay so you can visually assess whether wages are approximately normally distributed.

2. **Examine wages by race** — Create a bar chart showing the mean wage for each racial group (variable `race`). Make sure the chart has a descriptive title and labeled axes so it is self-explanatory.

3. **Customize the bar chart** — Repeat task 2, but this time add error bars showing 95% confidence intervals around each group mean. Think about which `graph bar` option controls this.

4. **Scatter plot with a fit line** — Draw a scatter plot of `wage` (y-axis) against `ttl_exp` (total work experience, x-axis). Overlay a linear fit line using a `twoway` command that combines both `scatter` and `lfit` in a single graph. Add a meaningful title and axis labels.

5. *(Bonus)* **Faceted histograms by union status** — Produce side-by-side histograms of `wage` separately for union and non-union workers (variable `union`) using the `by()` option. Ensure both panels share the same x-axis scale for comparability, and briefly comment in a code note (`//`) on what the visual difference suggests.
