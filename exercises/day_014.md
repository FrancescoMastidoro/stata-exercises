# Day 14: Visualizing Distributions and Relationships

**Dataset**: `sysuse nlsw88`
**Estimated time**: ~25 minutes

## Background
The `nlsw88` dataset contains 1988 National Longitudinal Survey data on working women in the United States, including wages, hours worked, occupation, and demographic characteristics. Creating informative graphs is a core skill in labor economics — visualizing distributions and relationships helps you spot patterns, outliers, and heterogeneity before running any regressions.

## Your tasks

1. **Load and inspect** — Load `nlsw88`, then use `summarize` and `codebook` to identify the variables `wage`, `hours`, `race`, and `collgrad`. Note the value labels attached to `race` and `collgrad` — you will need them when reading your graphs.

2. **Plot a wage histogram** — Draw a histogram of `wage`. Add the option to overlay a normal density curve on top of the bars, and give the graph a descriptive title. Observe whether the wage distribution looks symmetric or skewed.

3. **Compare wages by college graduation** — Draw two histograms of `wage` side by side (using `by()`) separated by the `collgrad` variable, so you can visually compare the wage distribution of college graduates versus non-graduates.

4. **Scatter plot with a fitted line** — Create a scatter plot of `wage` (y-axis) against `hours` (x-axis). Overlay a linear fitted line using `twoway` and the `lfit` plot type. Add axis labels and a title so the graph is self-contained.

5. *(Bonus)* **Bar chart of mean wages by occupation** — Use `graph bar` to display the mean wage across categories of the `occupation` variable. Rotate the x-axis labels so they are readable, and add value labels above each bar. Then export the graph as a `.png` file using `graph export`.

- **Hint 1 (Task 2)**: The `histogram` command accepts a `normal` option that draws the overlaid normal curve — look into `help histogram` to see where to place it and how to add `title()`.
- **Hint 2 (Task 3)**: The `by()` option inside `histogram` splits the plot by a categorical variable; make sure `collgrad` is recognized as a factor variable and check whether `by(collgrad, total)` gives you an extra panel with the overall distribution.
- **Hint 3 (Task 4)**: In `twoway`, you can combine multiple plot types by listing them in parentheses: `twoway (scatter wage hours) (lfit wage hours)`. Add `xtitle()`, `ytitle()`, and `title()` options outside the parentheses.
- **Hint 4 (Bonus)**: `graph bar (mean) wage, over(occupation)` is the starting point. For rotated labels, look into the `angle()` sub-option inside `over()`. For exporting, `graph export filename.png, replace` saves the last displayed graph.
