# Day 14: Building Visualizations for Labor Economics Analysis

**Dataset**: `sysuse auto`
**Estimated time**: ~25 minutes

## Background
The `auto` dataset contains 1978 automobile characteristics including price, fuel efficiency, weight, and whether a car is foreign or domestic. Visualizing distributions and relationships between variables is a foundational skill in quantitative research, helping you spot patterns, outliers, and heterogeneity before running any formal models.

## Your tasks

1. **Histogram of fuel efficiency** — Draw a histogram of `mpg`. Add the `frequency` option so the y-axis shows counts rather than density, and give the graph a descriptive title.

2. **Scatter plot of price and weight** — Create a scatter plot with `weight` on the x-axis and `price` on the y-axis. Label both axes clearly using `xtitle()` and `ytitle()`.

3. **Distinguishing foreign from domestic cars** — Repeat the scatter plot from Task 2, but this time use the `msymbol()` and `mcolor()` options (or the `by()` option) to visually separate foreign cars from domestic cars. Comment in your do-file on what pattern you observe.

4. **Bar chart of average price by car type** — Use `graph bar` to display the mean of `price` separately for foreign and domestic cars. Add appropriate axis labels and a title. Then, on the same graph, overlay the mean of `mpg` as a second bar group so you can compare both variables side by side across car types.

5. *(Bonus)* **Twoway overlaid distributions** — Use `twoway` to overlay two kernel density plots of `mpg` on the same axes — one for foreign cars and one for domestic cars — using `kdensity`. Add a legend that clearly labels each curve, and use contrasting line colors so the two groups are easy to distinguish.
