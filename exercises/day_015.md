## Background
The `nlsw88` dataset contains 1988 National Longitudinal Survey data on American women aged 34–46, covering wages, hours worked, occupation, and demographics. Visualization is a foundational skill in labor economics research because it reveals distributional patterns, outliers, and variable relationships before any formal modeling begins.

## Your tasks

1. **Inspect the data** — Load the dataset and use `describe` and `summarize` to familiarize yourself with the variables `wage`, `hours`, `age`, `race`, and `collgrad`. Note the variable types and whether any have missing values.

2. **Plot a wage histogram** — Draw a histogram of `wage` with 20 bins. Add a title "Wage Distribution (1988)" and a label on the x-axis reading "Hourly Wage (USD)". Observe whether the distribution looks symmetric or skewed.

3. **Overlay a normal density curve** — Reproduce the histogram from Task 2 but this time add the `normal` option so that a fitted normal distribution curve is overlaid. Does the wage distribution appear to follow a normal curve?

4. **Scatter plot with a fitted line** — Create a scatter plot of `wage` (y-axis) against `hours` (x-axis). Then use `twoway` to display both the scatter points and a linear fitted line (`lfit`) on the same graph. Add a legend and a descriptive title.

5. *(Bonus)* **Bar chart by education and race** — Use `graph bar (mean) wage`, grouping observations by `collgrad` (over) and further breaking down by `race` (over). Format the chart with axis titles and a legend so that a reader unfamiliar with the dataset can interpret it immediately.

- **Hint 1 (Task 2)**: The `histogram` command accepts a `bin()` option to control the number of bins, and graph titles/axis labels are added with `title()`, `xtitle()`, and `ytitle()` as suboptions inside the command — check `help histogram` to see how to chain these together.
- **Hint 2 (Task 4)**: Inside a `twoway` call you can stack multiple plot types by wrapping each one in parentheses: `twoway (scatter ...) (lfit ...)` — both share the same axes automatically, and `legend(label(...))` lets you rename each series in the legend.
