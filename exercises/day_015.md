# Day 15: Visualizing Labor Market Patterns

**Dataset**: `sysuse census`
**Estimated time**: ~25 minutes
**Difficulty**: ⬛⬛⬜⬜⬜

## Background
The `census` dataset contains 1980 U.S. Census data aggregated to the state level, covering population counts, age structure, and vital statistics across all 50 states. Visualization is a core skill in quantitative research — before running any regression, good researchers always plot their data to spot outliers, distributions, and relationships.

## Your tasks

1. **Histogram of median age** — Draw a histogram of `medage` (median age by state). Add a title and label the x-axis "Median Age (years)". How would you describe the shape of the distribution?

2. **Scatter plot: marriage vs. divorce rates** — Create a scatter plot with `marriage` on the x-axis and `divorce` on the y-axis. Add a meaningful title and axis labels. Do higher-marriage states tend to have higher divorce rates?

3. **Add a fitted line to the scatter** — Rebuild the scatter plot from Task 2 using `twoway`, and overlay a linear fit line (`lfit`). Combine both plot elements in a single `twoway` command using parentheses.

4. **Bar chart of mean population by region** — Use `graph bar` to display the mean of `pop` across the four Census regions (`region`). Label the bars using the `over()` option and add a title.

5. *(Bonus)* **Annotate an outlier** — In your `twoway` scatter from Task 3, use `mlabel(state2)` to label each point with its state abbreviation. Identify which state appears to be an outlier in either `marriage` or `divorce`, and add a note to the graph using the `note()` option explaining your observation.
