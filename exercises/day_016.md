# Day 16: Creating and Labelling New Variables

**Dataset**: `sysuse nlsw88`

## Background
The `nlsw88` dataset contains 1988 National Longitudinal Survey data on American women, including wages, hours worked, occupation, and demographic characteristics. Being able to create, recode, and label variables is a foundational skill in labor economics research, allowing you to construct meaningful categories and indicators from raw survey data before any analysis.

## Your tasks

1. **Load and inspect** — Load the dataset with `sysuse nlsw88` and run `describe` and `codebook wage hours grade` to understand the key variables you will be transforming.

2. **Generate a wage category variable** — Create a new variable called `wage_cat` that equals `1` if `wage` is strictly below 5, `2` if `wage` is between 5 and 10 (inclusive on both ends), and `3` if `wage` is above 10. Use a combination of `generate` and `replace` with appropriate `if` conditions.

3. **Label the wage category variable** — Define a value label called `wage_lbl` that maps `1` to `"Low"`, `2` to `"Medium"`, and `3` to `"High"`. Attach this label to `wage_cat`, then run `tabulate wage_cat` to verify the labels appear correctly.

4. **Create a full-time indicator using recode** — The variable `hours` records usual hours worked per week. First use `generate` to create a copy called `hours_cat`, then use `recode` to collapse it into three groups: `1/34` → `1` (part-time), `35/40` → `2` (standard), `41/max` → `3` (overwork). Add a variable label to `hours_cat` that reads `"Weekly hours category"` and assign appropriate value labels.

5. *(Bonus)* **Interaction indicator** — Generate a new binary variable called `high_edu_employed` that equals `1` if a woman has at least 16 years of education (`grade >= 16`) **and** is not missing `wage`, and `0` otherwise. Attach a descriptive variable label, then produce a `tabulate` of this variable broken down by `collgrad` to check whether your logic is consistent with the existing college-graduate indicator.
