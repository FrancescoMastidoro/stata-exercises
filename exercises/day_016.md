# Day 16: Creating and Labelling Variables from Scratch

**Dataset**: `sysuse nlsw88`
**Estimated time**: ~25 minutes
**Difficulty**: ⬛⬛⬛⬜⬜

## Background
The NLSW 1988 dataset contains labour market information on 2,246 American women, including wages, education, occupation, and demographic characteristics. Being able to construct new variables — and label them clearly — is one of the most fundamental skills in applied labour economics, since raw survey data rarely arrives in exactly the form your analysis requires.

## Your tasks

1. **Explore the wage distribution** — Load the dataset and use `summarize wage` and `tabulate collgrad` to familiarise yourself with the key variables you will use in the tasks below. Note the wage range (1.00–40.75) and that `collgrad` is a binary indicator of college graduation.

2. **Create a log-wage variable** — Use `generate` to create a new variable called `ln_wage` equal to the natural logarithm of `wage`. Then use `summarize ln_wage` to confirm it was created correctly. Verify that `ln_wage` has no missing values (since `wage` has none either).

3. **Create a wage category variable** — Use `generate` and `replace` to construct an integer variable called `wage_cat` that takes the value `1` if `wage < 5`, `2` if `wage >= 5` and `wage < 15`, and `3` if `wage >= 15`. After building it, use `tabulate wage_cat` to check that every observation has been assigned a category.

4. **Attach value labels to `wage_cat`** — Define a value-label set called `wagegrp` with labels `"Low"` for 1, `"Medium"` for 2, and `"High"` for 3. Attach it to `wage_cat` using `label values`, and then run `tabulate wage_cat` again to confirm the labels appear. Finally, use `label variable wage_cat "Wage category (low/medium/high)"` to add a variable label.

5. *(Bonus)* **Recode union membership and cross-tabulate** — The variable `union` has 368 missing values. Use `recode` to create a new variable `union2` from `union`, collapsing the existing values so that `0 = 0` ("Non-union") and `1 = 1` ("Union"), while explicitly setting missing values to `0` and labelling them `"Unknown"` using a separate category value (e.g., `9`). Attach appropriate value labels to `union2`, then produce a two-way `tabulate wage_cat union2` to examine how union status varies across wage categories. (*Think carefully: should you really recode missing as 0, or is a separate category safer for research integrity?*)

- **Hint 1 (Task 3)**: Remember that Stata evaluates `generate` and `replace` sequentially. A safe approach is to first `generate wage_cat = .` and then write three separate `replace` statements, each with an `if` condition using `&` if you need two bounds simultaneously.
- **Hint 2 (Task 4)**: The workflow has three distinct steps: `label define wagegrp 1 "Low" 2 "Medium" 3 "High"`, then `label values wage_cat wagegrp`, then `label variable wage_cat "..."`. Getting the order right matters — you must define the label set before attaching it.
