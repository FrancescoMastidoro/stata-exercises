# Day 17: Creating and Labelling New Variables

**Dataset**: `sysuse nlsw88`
**Estimated time**: ~25 minutes
**Difficulty**: ⬛⬛⬛⬜⬜

## Background
The `nlsw88` dataset contains 1988 survey data on American women's labor market outcomes, including wages, occupation, industry, and demographic characteristics. Creating well-labelled derived variables is a fundamental skill in labor economics research because raw survey data rarely arrives in the exact form needed for analysis.

## Your tasks

1. **Inspect the raw data** — Load the dataset and run `describe` and `codebook` on the variables `wage`, `hours`, `race`, and `collgrad`. Note which variables are numeric, which are labelled, and what their value ranges are.

2. **Generate a weekly earnings variable** — Create a new variable called `weekly_earn` equal to `wage` multiplied by `hours`. Then attach a variable label to it that reads `"Weekly earnings (wage × hours)"`.

3. **Create a wage tercile indicator** — Using `weekly_earn`, generate a new variable called `earn_group` that equals `1` if weekly earnings are in the bottom third of the distribution, `2` if in the middle third, and `3` if in the top third. Use `xtile` to do the splitting, then attach a variable label.

4. **Recode and label a binary education variable** — Use `recode` on `collgrad` to create a new variable called `edu_bin` where `0` becomes `2` (labelled `"No degree"`) and `1` stays `1` (labelled `"College grad"`). Attach both a variable label and value labels using `label define` and `label values`.

5. *(Bonus)* **Combine conditions with `generate` and `replace`** — Create a variable called `highwage_white` that equals `1` if a woman is white *and* her `weekly_earn` is above the median, `0` if she is white but below the median, and `.` (missing) for all non-white observations. Verify your work with `tabulate highwage_white race, missing`.

## Hints

- **Hint 1 (Task 2)**: Variable labels are attached with `label variable varname "text"` — this is separate from the `generate` command itself.
- **Hint 2 (Task 3)**: `xtile earn_group = weekly_earn, nquantiles(3)` splits a variable into *n* equal-frequency groups — look at the help file to confirm the syntax before running it.
- **Hint 3 (Task 4)**: The workflow is: `recode` → `label define` (create a named label set) → `label values` (attach it to the variable). These are three separate commands.
- **Hint 4 (Bonus)**: Start by `generate highwage_white = .` for all observations, then use `replace` with compound conditions using `&` to fill in the `1` and `0` cases selectively.
