# Day 17: Creating and Labelling Variables from Scratch

**Dataset**: `webuse mroz87`
**Estimated time**: ~25 minutes

## Background
The Mroz (1987) dataset drawn from the PSID is a classic benchmark in female labor economics, containing detailed information on wives' and husbands' wages, hours, education, and family structure for 753 married women. Creating well-labelled derived variables is essential for any serious quantitative research project, because it keeps your analysis reproducible, readable, and free of silent errors.

## Your tasks

1. **Load and explore** — Load the dataset with `webuse mroz87`. Run `describe` and `summarize wifeage wedyrs kl6 k618 wwage76 lfp` to get a feel for the six variables you will work with throughout this exercise. Note the ranges and what each variable measures.

2. **Generate a total-children variable** — Create a new variable called `totalkids` equal to the sum of `kl6` (children under 6) and `k618` (children aged 6–18). Attach a variable label that clearly describes what it counts. Verify your result by running `tabulate totalkids`.

3. **Generate and label an age-group variable** — Create a categorical variable called `agegrp` that groups wives into three bands: 1 = "30–39", 2 = "40–49", 3 = "50–60", based on `wifeage`. Use `generate` and `replace` (or a single `recode`) to assign the codes, then define value labels named `agegrp_lbl` and attach them to `agegrp`. Confirm with `tabulate agegrp`.

4. **Create a high-education indicator and a wage interaction** — Generate a binary variable `higheduc` equal to 1 if `wedyrs` is strictly greater than 12 (i.e., more than a high-school education) and 0 otherwise. Then create `wage_higheduc`, equal to `wwage76` multiplied by `higheduc`. Give both new variables descriptive variable labels. Use `tabstat wwage76 wage_higheduc, by(higheduc) stats(mean n)` to sanity-check the interaction.

5. *(Bonus)* **Recode labor-force participation with a new label scheme** — `lfp` is already a 0/1 variable. Use `recode` to create a new variable `lfp3` that equals 0 if the wife did not participate (`lfp == 0`), 1 if she participated *and* has no young children (`lfp == 1 & kl6 == 0`), and 2 if she participated *and* has at least one young child (`lfp == 1 & kl6 >= 1`). Attach meaningful value labels. Think carefully about whether `recode` alone can handle a condition on two variables, or whether you need `generate`/`replace` logic instead.

- **Hint 1 (Task 2)**: `generate totalkids = kl6 + k618` is the core step; attach a label with `label variable totalkids "..."`.
- **Hint 2 (Task 3)**: Either write three `replace agegrp = ...` statements after an initial `generate agegrp = .`, or use `recode wifeage (30/39=1) (40/49=2) (50/60=3), generate(agegrp)`. To attach value labels, first define them with `label define agegrp_lbl 1 "30–39" ...`, then link with `label values agegrp agegrp_lbl`.
- **Hint 3 (Task 4)**: For a binary indicator, `generate higheduc = (wedyrs > 12)` works cleanly in Stata — no `if` needed. Then `generate wage_higheduc = wwage76 * higheduc`.
- **Hint 4 (Bonus)**: `recode` maps values to values, not combinations of two variables. Start with `generate lfp3 = 0 if lfp == 0`, then use `replace` statements with compound conditions joined by `&`.
