# Day 18: Creating and Labelling New Variables

**Dataset**: `sysuse auto`
**Estimated time**: ~25 minutes
**Difficulty**: ⬛⬛⬛⬜⬜

## Background
The `auto` dataset contains 1978 automobile specifications and prices for 74 car models, including fuel efficiency, weight, and repair records. Creating derived variables and attaching clear labels is a core skill in labor and applied economics — it makes your analysis reproducible and your output self-documenting.

## Your tasks

1. **Inspect the data** — Load the dataset and run `describe` and `codebook rep78` to understand the variables. Note which variable has missing values and confirm how many observations are missing for `rep78`.

2. **Generate a weight class variable** — Create a new variable called `weight_class` that takes the value `1` if `weight < 2500`, `2` if `weight >= 2500` and `weight < 3500`, and `3` if `weight >= 3500`. Use `generate` and `replace` (no missing values exist in `weight`, so no special handling is needed).

3. **Label the new variable** — Attach a variable label to `weight_class` that reads `"Vehicle weight class (1=light, 2=medium, 3=heavy)"`. Then define a value label called `wclass_lbl` that maps `1` to `"Light"`, `2` to `"Medium"`, and `3` to `"Heavy"`, and apply it to `weight_class`. Verify with `tab weight_class`.

4. **Recode repair record into a binary** — Using `recode`, create a new variable `good_rep` from `rep78` such that values `1` and `2` become `0` (poor/average repair record) and values `3`, `4`, and `5` become `1` (good repair record). Missing values in `rep78` should remain missing in `good_rep`. Label the variable `"Good repair record (1=yes)"` and verify the result with `tab good_rep, miss`.

5. *(Bonus)* **Generate a price-per-pound efficiency index** — Create a variable `value_index` equal to `mpg / (weight / 1000)`, which captures fuel efficiency per thousand pounds of vehicle weight. Generate a second variable `value_cat` that categorises `value_index` into terciles using `xtile`. Label `value_cat` with value labels `"Low"`, `"Mid"`, `"High"`. Report the mean `price` within each `value_cat` group using `tabstat price, by(value_cat)`.

## Hints

- **Hint 1 (Task 2)**: Start with `generate weight_class = 1`, then write two `replace` statements using `if weight >= ...` conditions. Remember that the conditions are mutually exclusive only if you write them in the right order.

- **Hint 2 (Task 3)**: The workflow is: (a) `label variable weight_class "..."`, (b) `label define wclass_lbl 1 "Light" 2 "Medium" 3 "Heavy"`, (c) `label values weight_class wclass_lbl`. These are three separate commands.

- **Hint 3 (Task 4)**: `recode` can handle multiple source values in one step: `recode varname (1 2 = 0) (3 4 5 = 1), gen(good_rep)`. Missing values not listed in any rule are left as missing by default — check this with the `, miss` option in `tab`.

- **Hint 4 (Bonus)**: `xtile value_cat = value_index, nq(3)` splits a variable into three equal-sized groups. After creating the value label, don't forget `label values value_cat` to apply it.
