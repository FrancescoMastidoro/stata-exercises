# Day 18: Creating and Labelling New Variables

**Dataset**: `sysuse nlsw88`
**Estimated time**: ~25 minutes
**Difficulty**: ⬛⬛⬛⬜⬜

## Background
The `nlsw88` dataset contains 1988 National Longitudinal Survey data on American women, including wages, hours, occupation, and demographic characteristics. Being able to construct, recode, and label new variables is fundamental in labor economics research, where raw survey data rarely arrives in analysis-ready form.

## Your tasks

1. **Explore the data** — Load the dataset with `sysuse nlsw88`, then run `describe` and `codebook collgrad married hours wage` to understand the variables you will be working with.

2. **Create a binary overtime variable** — Using `generate`, create a new variable called `overtime` that equals `1` if a woman works more than 40 hours per week and `0` otherwise. (*Hint: think about how to handle missing values in `hours` before or during this step.*)

3. **Create a wage category variable** — Using `generate` and `replace`, create a variable called `wage_cat` that takes the value `1` if `wage` is below the sample median, `2` if it is at or above the median but below the 75th percentile, and `3` if it is at or above the 75th percentile. Use `summarize wage, detail` first to retrieve the relevant cutoff values.

4. **Label everything** — Attach a variable label to both `overtime` and `wage_cat`. Then define and attach value labels to both variables (e.g., `overtime`: 0 = "40 hrs or fewer", 1 = "More than 40 hrs"; `wage_cat`: 1 = "Low", 2 = "Medium", 3 = "High"). Verify the labels appear correctly with `tabulate`.

5. *(Bonus)* **Recode occupation into a simplified grouping** — The variable `occ` has many categories. Use `recode` to collapse it into a new variable `occ3` with three broad groups of your choosing (e.g., professional, blue-collar, other). Attach appropriate value labels and cross-tabulate `occ3` with `collgrad` to check whether the grouping makes intuitive sense.

## Hints

- **Hint 1 (Task 2)**: `generate` evaluates a logical condition directly — for example, `generate x = (varname > threshold)` produces 1 where true and 0 where false, but check what happens to observations where `hours` is missing; you may want to add an `if !missing(hours)` condition or follow up with a `replace` for missing cases.
- **Hint 2 (Task 3)**: Run `summarize wage, detail` and read off `p50` and `p75` from the output; then use a sequence of `generate` and `replace` statements with appropriate `if` conditions — remember that each `replace` only overwrites observations that satisfy its condition, so order matters.
- **Hint 3 (Task 4)**: Value labels in Stata are two-step: first define the label scheme with `label define labelname # "text" # "text" ...`, then attach it to the variable with `label values varname labelname`; use `label variable` for the plain-text variable description.
- **Hint 4 (Bonus)**: Look at `codebook occ` to see the existing numeric codes and their meanings before deciding on your three groups; `recode` accepts range syntax like `(1/3 = 1)` and can write directly to a new variable using the `gen()` option.
