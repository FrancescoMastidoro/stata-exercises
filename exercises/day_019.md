# Day 19: Creating and Labelling New Variables

**Dataset**: `sysuse nlsw88`
**Estimated time**: ~25 minutes
**Difficulty**: ⬛⬛⬛⬜⬜

## Background
The `nlsw88` dataset contains 1988 National Longitudinal Survey data on American women, including wages, hours worked, occupation, and demographic characteristics. Creating well-labelled derived variables is a foundational skill in labor economics, where raw survey codes must be transformed into meaningful analytical categories before any estimation can begin.

## Your tasks

1. **Inspect the raw data** — Load the dataset and run `describe` and `codebook` on the variables `wage`, `hours`, `race`, and `collgrad`. Note which variables are already labelled and which use raw numeric codes.

2. **Generate a weekly earnings variable** — Create a new variable called `weekly_earn` equal to `wage` multiplied by `hours`. Then attach a variable label that clearly describes what the variable measures and its units.

3. **Categorise weekly earnings into quintiles** — Using `weekly_earn`, generate a new integer variable called `earn_quintile` that takes values 1 through 5, where 1 = lowest 20% and 5 = highest 20% of weekly earnings. (*Hint: think about how `xtile` works.*)

4. **Recode and label a race indicator** — The variable `race` uses codes 1, 2, and 3. Use `recode` to create a new variable `race_cat` that collapses codes 2 and 3 into a single "non-white" category (coded 0) and keeps white (coded 1) as the reference. Then define and attach a value label so that 0 displays as `"Non-white"` and 1 displays as `"White"`.

5. *(Bonus)* **Build a combined human-capital indicator** — Generate a variable called `hc_index` that equals 1 if a woman is a college graduate **and** her `tenure` is strictly above the sample median tenure, 0 otherwise. Attach both a variable label and a value label. Then tabulate `hc_index` against `earn_quintile` and briefly comment (in a `/* */` block) on the pattern you observe.
