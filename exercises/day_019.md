# Day 19: Creating and Labelling New Variables

**Dataset**: `webuse psidextract`
**Estimated time**: ~25 minutes
**Difficulty**: ⬛⬛⬛⬜⬜

## Background
The PSID extract contains 4,165 observations of workers followed over up to 7 periods, with information on wages, demographics, occupation, and job characteristics. Creating and labelling derived variables is an essential first step in any empirical project — clean, well-documented variables make your analysis reproducible and your output readable.

## Your tasks

1. **Inspect the raw data** — Load the dataset and run `describe` and `codebook ed blk fem union` to understand the type, range, and existing labels of these four variables before you create anything new.

2. **Generate a squared experience term** — Create a new variable called `exp2` equal to `exp` squared. This kind of quadratic term is standard in Mincer wage equations to capture diminishing returns to experience. Confirm its range with `summarize exp2`.

3. **Recode occupation into a labelled binary** — The variable `occ` already equals 0 or 1, but suppose you want a version where 1 = "white-collar" and 0 = "blue-collar". Use `generate` (or `recode`) to create `occ_label`, then define and attach a value label so that the categories display as text rather than numbers.

4. **Create an education group variable** — Using `generate` and `replace` (or `recode`), build a three-category variable called `edgrp` where: 1 = fewer than 12 years of education, 2 = exactly 12 years (high-school graduate), and 3 = more than 12 years. Add a variable label describing what `edgrp` measures, and attach value labels for all three categories. Check frequencies with `tabulate edgrp`.

5. *(Bonus)* **Build an interaction indicator** — Create a variable called `fem_union` that equals 1 if the worker is *both* female (`fem == 1`) *and* unionised (`union == 1`), and 0 otherwise. Label the variable "Female union member". Then use `tabulate fem union` and `tabulate fem_union` to verify your counts are consistent with the cross-tabulation.
