# Day 20: Creating and Labelling New Variables

**Dataset**: `sysuse nlsw88`
**Estimated time**: ~25 minutes
**Difficulty**: ⬛⬛⬛⬜⬜

## Background
The NLSW 1988 extract contains labour market information on working women in the United States, including wages, experience, education, and demographic characteristics. Creating well-labelled derived variables is a foundational skill in empirical labour economics, making your analysis reproducible and your output self-documenting.

## Your tasks

1. **Inspect and tabulate** — Load the dataset and run `describe` and `tabulate race` to understand the existing variable types and value labels before creating anything new.

2. **Generate a wage category variable** — Using the `wage` variable (range 1.00–40.75), create a new variable called `wage_cat` that takes the value 1 if wage is below 5, value 2 if wage is between 5 and 10 (inclusive of 10), and value 3 if wage is above 10. Use `generate` and `replace` with appropriate conditions.

3. **Label your new variable** — Attach a variable label to `wage_cat` (e.g., `"Wage tercile category"`), then define a value label called `wage_cat_lbl` with descriptive text for values 1, 2, and 3, and apply it to `wage_cat`. Confirm with `tabulate wage_cat`.

4. **Recode experience into an education–experience group** — `collgrad` is a 0/1 indicator for college graduation and `ttl_exp` records total work experience (range 0.12–28.88). Generate a four-category variable called `edu_exp_group` using the following logic: value 1 = no college and low experience (ttl_exp ≤ 10), value 2 = no college and high experience (ttl_exp > 10), value 3 = college and low experience (ttl_exp ≤ 10), value 4 = college and high experience (ttl_exp > 10). Add appropriate variable and value labels.

5. *(Bonus)* **Handle missings explicitly and validate** — The variable `union` has 368 missing values. Generate a new variable `union_clean` that equals `union` where observed, and equals 0 where `union` is missing (treating missing as non-union). Add a note to the variable using `notes union_clean:` explaining this imputation decision. Then use `assert` to confirm that `union_clean` has no missing values.

- **Hint 1 (Task 2)**: Remember that `generate` creates the variable for the first condition; subsequent conditions use `replace ... if`. Be careful with boundary values — decide whether `wage == 5` and `wage == 10` belong to category 1, 2, or 3 and apply that consistently. You may also want to check that every observation has been assigned a category using `tabulate wage_cat, missing`.

- **Hint 2 (Task 3)**: Define a value label with `label define wage_cat_lbl 1 "Low" 2 "Medium" 3 "High"` (use your own text), then attach it with `label values`. The variable label goes through `label variable`.

- **Hint 3 (Task 4)**: You can combine two conditions in a single `replace` using `&`. Build the variable step by step — initialise it with `generate edu_exp_group = .` and then fill in each category with a `replace ... if collgrad == ? & ttl_exp ? ?` line.

- **Hint 4 (Bonus)**: The function `missing()` or the condition `== .` can identify missing observations. To add a note, the syntax is `notes varname: "your text here"`. Check the Stata help for `notes` if unfamiliar.
