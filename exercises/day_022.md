## Background
The `auto` dataset contains 1978 automobile data for 74 cars, covering price, fuel efficiency, weight, and origin (domestic vs. foreign). Mastering `if`/`in` conditions and `bysort` is essential for labor economics research, where you constantly need to compare subgroups — for example, wage gaps across industries or employment patterns by region.

## Your tasks

1. **Explore domestic vs. foreign cars** — Load the dataset and use `tabulate` with an `if` condition to display the distribution of `rep78` (repair record) separately for domestic cars (`foreign == 0`) and foreign cars (`foreign == 1`). Notice that `rep78` has 5 missing values — does missingness appear concentrated in one group?

2. **Group-wise summary statistics** — Use `bysort foreign:` to compute the mean of `price`, `mpg`, and `weight` for each group in a single command. Write a comment in your do-file noting which group tends to be heavier and which has better fuel economy.

3. **Create a fuel-efficiency flag** — Generate a new binary variable called `efficient` that equals 1 if a car's `mpg` is strictly above 25, and 0 otherwise. Then use `bysort foreign: summarize efficient` to see whether high-efficiency cars are more concentrated among domestic or foreign models.

4. **Restricting observations with `in` and `if` together** — Use `list make price mpg if price > 10000 & foreign == 1` to identify which expensive foreign cars are in the dataset. Then separately list the five cheapest cars overall using `in 1/5` after sorting by `price` ascending. Write a comment explaining what `in` refers to (observation numbers, not variable values).

5. *(Bonus)* **Group-wise standardisation** — Using `bysort foreign:`, generate a new variable `mpg_zscore` equal to each car's `mpg` minus its group mean, divided by its group standard deviation. You will need to use `egen` with `mean()` and `sd()` inside a `bysort` prefix to first store the group mean and standard deviation, then compute the z-score in a second step. Verify your result makes sense by checking that the group means of `mpg_zscore` are approximately zero.

## Hints

- **Hint 1 (Task 2)**: The `bysort` prefix goes *before* the command with a colon — for example, `bysort foreign: summarize price mpg weight`. You can list multiple variables after `summarize` in one go.

- **Hint 2 (Task 3)**: To generate a binary variable based on a condition, `generate efficient = (mpg > 25)` works because Stata evaluates the Boolean expression in parentheses as 1 (true) or 0 (false). Since `mpg` has no missing values in this dataset, you do not need to worry about missing-value contamination here.

- **Hint 3 (Task 4)**: After `sort price`, the observation in row 1 has the lowest price. The `in 1/5` qualifier selects rows 1 through 5 by current sort order — it does *not* filter by the value of any variable.

- **Hint 4 (Bonus)**: Start with `bysort foreign: egen mpg_mean = mean(mpg)` and a parallel line for the standard deviation using `sd()`. Once those two variables exist, compute the z-score with a regular `generate` statement — no `bysort` needed for that final step.
