## Background
The NLSW 1988 dataset contains employment and demographic information for 2,246 working women observed in the National Longitudinal Survey. Subsetting data with `if`/`in` and computing statistics within groups using `bysort` are foundational skills for any labor economics analysis, where comparisons across subpopulations — by education, race, or union status — are routine.

## Your tasks

1. **Explore the wage distribution by college graduation** — Use `tabstat wage, by(collgrad) statistics(mean sd min max)` to summarize hourly wages separately for non-college and college graduates. Report what you observe about the wage gap.

2. **Restrict to a subgroup and summarize** — Using an `if` condition, compute the mean and standard deviation of `wage` and `ttl_exp` (total work experience) only for married women (`married == 1`) who live in a metropolitan area (`smsa == 1`). Use `summarize` with the appropriate `if` clause.

3. **Create a group mean variable with `bysort`** — Generate a new variable `mean_wage_race` that contains the average wage for each racial group (variable `race`). Use `bysort race: egen mean_wage_race = mean(wage)`. Then use `list race mean_wage_race in 1/10` to inspect the result.

4. **Combine `bysort` and a conditional count** — For each value of `collgrad`, use `bysort collgrad: egen n_south = total(south)` to count how many women in each education group live in the South. Then use `tabulate collgrad` alongside your new variable to compute the *share* of southern women within each group manually (divide `n_south` by the group size). Display your results using `tabstat n_south, by(collgrad)`.

5. *(Bonus)* **Rank wages within experience quartiles** — First, use `xtile exp_q = ttl_exp, nquantiles(4)` to create experience quartiles. Then, within each quartile, generate a rank variable `wage_rank` using `bysort exp_q: egen wage_rank = rank(wage)`. Finally, using an `if` condition, list the top 3 wage-earners (`wage_rank >= .`) within the highest experience quartile (`exp_q == 4`) — but first figure out the correct threshold by checking the maximum rank within that group using `summarize wage_rank if exp_q == 4`.

## Hints
<details>
<summary>Click to reveal hints (try first!)</summary>

- **Hint 1 (Task 2)**: You can chain multiple conditions in a single `if` clause using `&`. The syntax is `summarize varlist if condition1 & condition2`. Make sure you use `==` (double equals) for logical equality, not `=`.

- **Hint 2 (Task 3)**: `bysort` temporarily sorts and groups observations, then applies the command that follows to each group separately. `egen` with `mean()` fills in the group mean for *every* observation in that group — so after running it, all women of the same race will share the same value of `mean_wage_race`.

- **Hint 3 (Task 4)**: `total()` inside `egen` sums a binary variable across the group, giving you the count of ones. To get the group size, consider using `bysort collgrad: egen n_group = count(wage)` (since `wage` has no missing values, this counts all observations in the group).
