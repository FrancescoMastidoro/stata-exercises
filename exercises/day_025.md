# Day 25: Conditional Logic and Group Operations

**Dataset**: `webuse psidextract`
**Estimated time**: ~25 minutes

## Background
The PSID extract tracks 595 individuals over up to 7 time periods, recording wages, employment characteristics, and demographics for use in classic labor economics panel studies. Mastering `if`, `in`, and `bysort` is essential for any researcher who needs to compare subgroups, restrict samples, or compute group-level statistics before running regressions.

## Your tasks

1. **Subset and summarize** — Load the dataset and use `summarize lwage if fem == 1` and `summarize lwage if fem == 0` to compare the log-wage distribution between women and men. Report the mean log-wage for each group.

2. **Conditional tabulation** — Use `tab union if south == 1` to examine union membership among workers in southern states. Then repeat for `south == 0`. Do union rates appear higher or lower in the South?

3. **Group means with `bysort`** — Use `bysort fem: summarize lwage ed` to compute mean log-wages and mean education separately for men and women in a single command. Notice how `bysort` structures the output compared to the two separate `if` commands in Task 1.

4. **Combining `bysort` with `egen`** — Create a new variable `mean_lwage_group` that stores the **group mean** of `lwage` for each combination of `fem` and `union` (four groups total). Use `bysort fem union: egen mean_lwage_group = mean(lwage)`. Then use `list fem union mean_lwage_group in 1/20` to inspect the result and verify the four distinct values are correct.

5. *(Bonus)* **Group ranks** — Within each individual (`id`), use `bysort id (t): gen lwage_change = lwage - lwage[_n-1]` to compute the period-to-period change in log-wages. Then use `summarize lwage_change if fem == 1` and `summarize lwage_change if fem == 0` to compare wage growth volatility by gender. Why does the first observation for each individual always produce a missing value?

## Hints

<summary>Click to reveal hints (try first!)</summary>

- **Hint 1 (Tasks 1–2)**: The `if` qualifier in Stata comes *after* the command and variable name but *before* any options — the syntax is `command varname if condition`. For binary variables like `fem` and `south`, the condition is simply `fem == 1` (two equals signs for comparison, not assignment).

- **Hint 2 (Task 4)**: `bysort` with multiple grouping variables requires listing them space-separated inside the `bysort` prefix — for example `bysort var1 var2: ...`. The `egen` function `mean()` computes the arithmetic mean of a variable within each group defined by `bysort`. After running the command, each row will hold the mean of its own group, not a single summary number.
