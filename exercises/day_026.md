# Day 26: Reshaping and Merging Panel Data

**Dataset**: `webuse grunfeld`

## Background
The Grunfeld dataset records annual investment, market value, and capital stock for 10 large US firms across 20 years (1935–1954), making it a classic panel dataset in econometrics. Reshaping and merging are foundational data-management skills in labor and applied economics, where data often arrive in different shapes or from separate sources that must be combined before analysis.

## Your tasks

1. **Inspect the panel structure** — Load the dataset with `webuse grunfeld`. Use `describe` and `xtset` (setting `company` as the panel ID and `year` as the time variable) to confirm the panel is balanced. How many companies and years are there?

2. **Reshape wide** — Use `reshape wide` to convert the dataset from long format (one row per company–year) into wide format, so that each row represents a single company and each year's values of `invest`, `mvalue`, and `kstock` appear as separate variables (e.g., `invest1935`, `invest1936`, …). After reshaping, describe the result: how many observations and variables does the wide dataset have?

3. **Reshape back to long** — Starting from your wide dataset, use `reshape long` to recover the original long format. Verify you have the same number of observations (200) and variables (6) as the original. Use `assert` to confirm the number of observations is exactly 200.

4. **Split and merge** — From the original long dataset, create two separate datasets: one containing only `company`, `year`, and `invest`; the other containing only `company`, `year`, `mvalue`, and `kstock`. Save them as temporary files. Then use `merge 1:1` on `company` and `year` to rejoin them, and check the merge result using `tabulate _merge`.

5. *(Bonus)* **Append a subset** — From the original dataset, keep only observations where `company == 1` and save as a temporary file. Then separately keep only `company == 2` and save as another temporary file. Use `append` to stack them, confirm you have exactly 40 observations, and run a simple `regress invest mvalue kstock` on this two-company subset. How do the coefficients compare to a regression on the full dataset?

For the merge, remember that both datasets must be sorted on the key variables (`company` and `year`) before merging — or let Stata sort automatically. After merging, `_merge == 3` for all rows means a perfect match.
