# Day 27: Reshaping and Merging Blood-Pressure Data

**Dataset**: `sysuse bpwide`
**Estimated time**: ~25 minutes

## Background
The `bpwide` dataset contains fictional blood-pressure measurements for 120 patients recorded in **wide format**, with one row per patient and separate variables for blood pressure before and after treatment. Reshaping between wide and long formats is a foundational skill in labor economics, where panel data routinely arrives in either layout and must be transformed before estimation.

## Your tasks

1. **Explore the wide structure** — Load `bpwide` and use `describe` and `list` to inspect the first 5 observations. Identify which variables distinguish the "before" and "after" measurements and note the patient identifier variable.

2. **Reshape to long format** — Reshape the dataset from wide to long so that each patient contributes **two rows**: one for the pre-treatment measurement and one for the post-treatment measurement. The new time-identifying variable should be called `when`, and the blood-pressure outcome variable should be called `bp`. After reshaping, verify the result with `describe` and confirm you now have 240 observations.

3. **Label the time variable** — After reshaping, `when` will take on string or numeric values corresponding to `"before"` and `"after"`. Use `tabulate when` to inspect its values, then use `list` on the first 6 rows to confirm the long structure looks correct.

4. **Compute group means and merge back** — Using the long dataset, collapse the data to compute the mean `bp` by `when` and `sex`, storing results in a temporary frame or saving as a separate dataset. Then `reshape` the collapsed result back to wide format so each row represents one sex-group, with columns for mean bp before and after. *(Hint: you will need to think carefully about what the "i" and "j" options should be after collapsing.)*

5. *(Bonus)* **Append a synthetic observation** — After completing Task 2, manually `input` a new observation representing a hypothetical patient (patient ID = 999, `sex` = 0, `agegrp` = 2, `when` = `"before"`, `bp` = 160) and `append` it to the long dataset. Use `assert` to confirm the final dataset has exactly 241 observations, then drop the synthetic observation and confirm you are back to 240.

- **Hint 1 (Task 2)**: The `reshape long` command requires you to specify the *stub* — the common prefix shared by the wide variables you want to stack. Look at the names `bp_before` and `bp_after`: the stub is `bp_`, and the `j()` option names the new variable that will record which time period each row belongs to. The syntax skeleton is `reshape long stub, i(id_var) j(time_var) string`.
- **Hint 2 (Task 4)**: After `collapse (mean) bp, by(when sex)`, you have a small dataset with one row per `when`–`sex` combination. To reshape it back to wide, think about which variable should be the row identifier (`i()`) and which should spread across columns (`j()`). Since you want one row per sex, `sex` is your `i()` and `when` is your `j()`.
