# Day 28: Reshaping and Appending Panel-Style Data

**Dataset**: `sysuse bpwide` → reshaped; then `sysuse census` for appending practice
**Estimated time**: ~25 minutes
**Difficulty**: ⬛⬛⬛⬜⬜

## Background
`bpwide` contains fictional blood-pressure measurements recorded in **wide format** — one row per patient with separate variables for pre- and post-treatment blood pressure. Reshaping and appending are foundational data-management skills in labor economics, where panel datasets (one row per person-period) are the standard structure for identifying causal effects.

## Your tasks

1. **Load and inspect the wide data** — Load `sysuse bpwide`. Use `describe` and `list` to understand its structure. How many observations are there, and which variables hold the two blood-pressure measurements?

2. **Reshape to long format** — Reshape the dataset from wide to long so that each patient contributes **two rows**: one for `bp_before` and one for `bp_after`. The new time-identifier variable should be called `time`, and the single blood-pressure variable should be called `bp`. After reshaping, confirm you have 240 observations.

3. **Label the time variable** — After reshaping, the `time` variable takes values `before` and `after` (as a string stub identifier). Tabulate `time` to confirm both values appear, then generate a numeric indicator `post` equal to 1 if `time == "after"` and 0 otherwise.

4. **Summarize by group** — Using your long-format dataset, compute the mean blood pressure separately for `post == 0` and `post == 1`, broken down further by `agegrp`. Does blood pressure appear to change on average across the two time points? Report the means with `tabstat`.

5. *(Bonus)* **Reshape back and verify** — Reshape the long dataset back to wide format (recreating `bp_before` and `bp_after`). Then use `cf` (compare files) or `assert` to verify that the reshaped-back values of `bp_before` match the original values from the raw `bpwide` dataset. *Hint: you will need to reload the original data first and save it as a tempfile for comparison.*

## Hints

- **Hint 1 (Task 2)**: The `reshape long` command needs you to specify the *stub* — the common prefix shared by the wide variables. Here the stubs are `bp_before` and `bp_after`… look carefully at how Stata identifies a stub versus a suffix. The syntax is `reshape long stubname, i(id_var) j(new_time_var) string`.

- **Hint 2 (Task 3)**: After `reshape long`, Stata creates a string variable for `j` when you include the `string` option. To create `post`, you can use `generate post = (time == "after")` — Stata evaluates the logical expression and assigns 1 or 0 automatically.

- **Hint 3 (Task 4)**: `tabstat bp, by(agegrp) statistics(mean)` works for one grouping at a time. To cross-tabulate two groupings simultaneously, consider creating a combined group variable with `egen` or running `tabstat` separately for each value of `post`.

- **Hint 4 (Task 5)**: `reshape wide` reverses the process — specify the same stub, `i()`, and `j()`. To compare with the original, `save` the original dataset to a `tempfile` before reshaping, then reload it and use `assert` with `merge` results, or compare specific variables directly.
