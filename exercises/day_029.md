## Background
The PSID extract contains 4,165 observations on up to 595 individuals observed across 7 time periods, covering wages, employment, and demographic characteristics relevant to labor economics. Knowing how to reshape between wide and long formats — and how to combine datasets via merge and append — is essential for building panel datasets from multiple sources in empirical research.

## Your tasks

1. **Explore the panel structure** — Load `webuse psidextract`. Use `xtset` to declare the panel (individual identifier `id`, time variable `t`). Then use `xtdescribe` to confirm how many individuals are observed and how balanced the panel is.

2. **Reshape to wide format** — Reshape the dataset from long to wide so that each row represents one individual (`id`) and each time-varying variable (`lwage`, `wks`, `union`) gets a separate column for each of the 7 periods (e.g., `lwage1`, `lwage2`, …, `lwage7`). After reshaping, verify that the number of observations equals 595.

3. **Compute a summary measure in wide format** — Still in wide format, generate a new variable `mean_lwage` that is the arithmetic average of `lwage1` through `lwage7` for each individual. Then report the mean and standard deviation of `mean_lwage` across individuals using `summarize`.

4. **Reshape back to long and merge on a constant** — Reshape the data back to long format (restoring the original structure). Then create a small helper dataset in memory: keep only `id`, `ed`, and `blk` (which are time-invariant), drop duplicates, and save it as `psid_characteristics.dta`. Reload the original long dataset and perform a many-to-one merge (`m:1`) on `id` using the helper file. Confirm that all observations matched using `assert _merge == 3`.

5. *(Bonus)* **Append two wage datasets** — Load `sysuse nlsw88` and keep only `idcode`, `wage`, and `ttl_exp`. Rename `idcode` to `id` and `wage` to `lwage`. Add a string variable `source` equal to `"nlsw88"` for all rows. Do the same for your reshaped-back PSID data (keeping `id`, `lwage`, `ttl_exp`; setting `source = "psid"`). Append the two datasets and report how many total observations result, broken down by `source` using `tabulate source`.

## Hints
<details>
<summary>Click to reveal hints (try first!)</summary>

- **Hint 1 (Task 1)**: After `webuse psidextract`, the syntax for declaring a panel is `xtset panelvar timevar`. Look at the variable descriptions to identify which variable indexes individuals and which indexes time periods.

- **Hint 2 (Task 2)**: `reshape wide` requires you to specify the variables that will become multiple columns, the `i()` option (the row identifier) and the `j()` option (the variable whose values become suffixes). Check `help reshape` and note that `t` runs from 1 to 7.

- **Hint 3 (Task 3)**: You can use `rowmean()` inside `egen` to average across a list of variables in one step, rather than adding them manually and dividing.

- **Hint 4 (Task 4)**: After reshaping back to long, `duplicates drop id, force` (combined with keeping only the right variables) is one way to isolate one row per individual. When merging, remember that `_merge` is generated automatically — check its values with `tabulate _merge` before asserting.

- **Hint 5 (Bonus)**: For the append to work cleanly, both datasets need a common `lwage` variable. Since `nlsw88` stores wages as `wage` (a float in dollars), rename it before appending — and be aware that PSID's `lwage` is a log wage, so the two series are not directly comparable. You can still append them mechanically; just note the conceptual difference.
