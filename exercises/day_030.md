# Day 30: Merging Datasets and Reshaping for Panel Analysis

## Background
The Grunfeld dataset is a classic balanced panel of 10 US firms observed annually from 1935 to 1954, containing investment, market value, and capital stock — a cornerstone of panel econometrics. Mastering merge, append, and reshape is essential for labor and corporate economics research, where data almost always arrive in separate files or in the wrong shape for your analysis.

## Your tasks

1. **Inspect and summarize the panel structure** — Load `webuse grunfeld`, then use `xtset` to declare the panel structure with `company` as the panel identifier and `year` as the time variable. After setting the panel, run `xtsum invest` and briefly note how the within-firm and between-firm variation compare (you can write your interpretation as a comment in the `.do` file).

2. **Reshape to wide format** — The data are currently in long format (one row per company-year). Use `reshape wide` to convert the dataset so that each row represents a single company and the variables `invest`, `mvalue`, and `kstock` appear as separate columns for each year (e.g., `invest1935`, `invest1936`, …). After reshaping, check how many observations remain and confirm it equals 10.

3. **Reshape back to long format** — Starting from the wide-format data you created in Task 2, use `reshape long` to restore the original long format. Confirm you recover 200 observations. Then sort by `company` and `year` and compare the result to the original dataset using `browse` to satisfy yourself the round-trip was clean.

4. **Create a company-level summary dataset and merge it back** — From the long-format data, use `collapse (mean) mean_invest=invest mean_mvalue=mvalue, by(company)` to produce a 10-observation company-level dataset and save it as a tempfile. Then reload the full long panel and `merge m:1 company` using that tempfile to attach each company's average investment and average market value to every row. Inspect the `_merge` variable and verify all 200 observations matched perfectly (i.e., `_merge == 3` for all rows).

5. *(Bonus)* **Append a second dataset and flag the source** — Load `webuse laborsup` and keep only the variables `fem_educ`, `fem_inc`, and `fem_work`. Generate a new string variable `source` equal to `"laborsup"`. Then load `webuse grunfeld`, keep `company`, `invest`, and `year`, and generate a `source` variable equal to `"grunfeld"`. Use `append using` to stack the two datasets. After appending, use `tabulate source, missing` to confirm both sources are represented, and note in a comment why appending datasets with different variables is valid in Stata but requires careful interpretation.
