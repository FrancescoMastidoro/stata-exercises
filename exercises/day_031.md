# Day 31: Loops and Macros — Automating Repetitive Tasks

**Dataset**: `sysuse nlsw88`
**Estimated time**: ~25 minutes

## Background
The NLSW 1988 dataset contains information on 2,246 working women, including wages, experience, demographics, and job characteristics — a classic resource for labor economics research. Loops and macros are essential tools for avoiding repetitive code: once you can automate a task across variables or values, your scripts become shorter, cleaner, and far easier to maintain.

## Your tasks

1. **Define and display a local macro** — Define a `local` macro called `outcome` that contains the string `"wage"`. Then use `display` to print the message: *"The outcome variable is: wage"* by referencing the macro (not the literal word "wage"). Run it and confirm the output in the Results window.

2. **Loop over a list of binary variables** — Use `foreach` to loop over the variables `married`, `collgrad`, `south`, `smsa`, and `c_city`. Inside the loop, use `tabulate` to display the frequency table for each variable. Observe how a single loop replaces five separate `tabulate` commands.

3. **Summarize wage by age using `forvalues`** — Use `forvalues` to loop over ages 34, 35, 36, ..., 46 (the full range of `age` in this dataset). Inside the loop, use `summarize wage if age == `i'' to print summary statistics of `wage` for each age group. *(Tip: think carefully about how to refer to the loop counter inside the `if` condition.)*

4. **Combine a local macro with a `foreach` loop** — Define a `local` macro called `controls` containing the variables `age`, `tenure`, `ttl_exp`, and `grade`. Then write a `foreach` loop that iterates over each variable in `controls` and runs a simple OLS regression of `wage` on that single variable (four regressions total, one per iteration). Print a separator line using `display` before each regression so the output is easy to read. Note: `tenure` and `grade` have some missing values — observe how Stata handles sample size automatically.

5. *(Bonus)* **Build a results table with a loop and a global macro** — Define a `global` macro called `covariates` containing `age ttl_exp collgrad south smsa`. Write a `forvalues` loop that runs a sequence of *cumulative* OLS regressions of `wage`: the first iteration regresses `wage` on just the first variable, the second adds the second variable, and so on — building up to a five-variable model. *(Hint: think about how you can use a local macro inside the loop to accumulate the variable list across iterations.)*

- **Hint 1 (Task 1)**: A local macro is defined with `local macroname "contents"` and referenced later with backtick–name–apostrophe syntax: `` `macroname' ``. Use `display` with that reference to print its contents.

- **Hint 2 (Task 3)**: In `forvalues i = 34/46 { ... }`, the loop counter inside the `if` condition is written as `` `i' `` — make sure the quotes around the value are handled by Stata's macro substitution, not hard-coded. No quotes are needed around a numeric value in an `if` expression.

- **Hint 3 (Task 4)**: You can loop over the words inside a local macro with `foreach var of local controls { ... }`. Each iteration, `var` takes on one word from the macro. A `display` statement like `display "--- Regression on `var' ---"` prints a readable header before each model.

- **Hint 4 (Task 5, Bonus)**: Inside the loop, maintain a second local macro (e.g., `varlist`) that starts empty and gets a new variable appended each iteration: `` local varlist "`varlist' `nextvar'" ``. Then run `regress wage `varlist'` inside the loop body.
