# Day 32: Loops and Macros — Automating Repetitive Analysis

**Dataset**: `sysuse auto`
**Estimated time**: ~25 minutes
**Difficulty**: ⬛⬛⬛⬛⬜

## Background
The `auto` dataset contains 1978 automobile data on 74 cars, covering price, fuel efficiency, weight, and other characteristics across domestic and foreign models. Loops and macros are essential tools for quantitative research because they let you apply the same operation across many variables or values without rewriting code — a habit that reduces errors and makes your do-files scalable.

## Your tasks

1. **Define and display a local macro** — Define a local macro called `outcome` that stores the variable name `price`. Then use `display` to print the message: *"The outcome variable is: price"* by referencing the macro (not by typing the word "price" directly).

2. **Loop over a list of variables with `foreach`** — Use a `foreach` loop to calculate and display the mean of each of the following variables: `price`, `mpg`, `weight`, `length`, and `gear_ratio`. Inside the loop, use `summarize` with the `meanonly` option and then `display` the result stored in `r(mean)`, labeling each line so the output is readable (e.g., *"Mean of price: ..."*).

3. **Loop over a numeric range with `forvalues`** — Use a `forvalues` loop to summarize `mpg` separately for each value of `rep78` from 1 to 5. Before each summary, display a header line identifying which repair-record group is being shown. (*Note: `rep78` has 5 missing observations — your loop will naturally skip them since `summarize` with `if` only uses non-missing values.*)

4. **Combine a global macro with a `foreach` loop** — Define a global macro called `controls` that stores the list: `weight length displacement headroom trunk`. Then write a `foreach` loop that iterates over `$controls` and, for each variable, runs a simple regression of `price` on that single variable. Display a separator line (e.g., using `display "---"`) between regressions so the output is easy to read.

5. *(Bonus)* **Build variable labels programmatically** — Use a `forvalues` loop over values 1 to 5 to construct a local macro inside the loop that holds the string `"Repair record: "` concatenated with the loop counter. Use this macro to `display` a custom header, and then use `summarize price if rep78 == \`i'` to report the mean price for each repair-record group. Finally, after the loop, define a local macro `best` equal to `5` and use it in a single `summarize` command (with `detail`) to examine the price distribution among the highest-rated cars.

- **Hint 1 (Task 1)**: A local macro is defined with `local macroname "value"` and referenced with a backtick–apostrophe pair: `` `macroname' ``. Make sure you use the correct opening character (backtick `` ` ``, not a regular apostrophe).

- **Hint 2 (Task 2)**: After `summarize varname, meanonly`, Stata stores the mean in the return scalar `r(mean)`. You can display it with `display "Mean of `var': " r(mean)` inside the loop — notice that `var` here is the loop iterator name you chose in your `foreach` statement.

- **Hint 3 (Task 3)**: The syntax for a `forvalues` loop over integers is `forvalues i = 1/5 { ... }`. To restrict `summarize` to one group at a time, use `summarize mpg if rep78 == \`i'`.

- **Hint 4 (Task 4)**: A global macro is defined with `global macroname "var1 var2 ..."` and referenced with a dollar sign: `$macroname`. When you iterate `foreach v of global controls`, Stata automatically expands the global for you. Inside the loop, your regression command will be `regress price \`v'`.
