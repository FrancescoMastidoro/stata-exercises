# Day 33: Loops and Macros — Automating Repetitive Analysis

**Dataset**: `sysuse census`
**Estimated time**: ~25 minutes
**Difficulty**: ⬛⬛⬛⬛⬜

## Background
The 1980 Census dataset contains population and demographic information for all 50 U.S. states, including regional groupings, age structure, and vital statistics such as marriages and divorces. Loops and macros are essential tools in labor economics research: they eliminate copy-paste errors, make code scalable across many variables or subgroups, and allow you to produce systematic comparisons with very few lines of code.

## Your tasks

1. **Define and display a local macro** — Define a `local` macro called `popvars` that contains the variable names `pop poplt5 pop5_17 pop18p pop65p`. Then use `display` to print the contents of `popvars` to confirm it stored correctly. Finally, use `summarize \`popvars'` to summarize all five variables in a single command.

2. **Loop over variables with `foreach`** — Using a `foreach` loop that iterates over the same five population variables (`pop poplt5 pop5_17 pop18p pop65p`), display the variable name on each iteration using `display` and then compute the mean of that variable using `summarize`, restricting the output to just the mean (use the `meanonly` option). Inside the loop, display the result stored in `r(mean)` with a label so the output is readable.

3. **Loop over values with `forvalues`** — The variable `region` takes integer values 1 through 4. Use a `forvalues` loop to iterate over regions 1–4. Inside each iteration, display which region you are in and use `summarize medage if region == \`r'` to report median age statistics for that region. This replicates a stratified summary without writing four separate `summarize` commands.

4. **Combine a local macro and a nested concept** — Define a local macro called `outcomes` containing `death marriage divorce`. Then write a `foreach` loop over `\`outcomes'` that, for each variable, runs a simple linear regression of that outcome on `pop` and `medage`. Use `display` at the start of each iteration to print a separator line (e.g., `"=== Regression for: [varname] ==="`) so the output is clearly labeled. This simulates a common research workflow where you run the same model across multiple dependent variables.

5. *(Bonus)* **Define a global macro and build a dynamic regression** — Define a `global` macro called `controls` containing `medage popurban`. Then write a `foreach` loop over the three outcome variables `death marriage divorce`. Inside the loop, regress each outcome on `pop` and `$controls`, and after each regression use `display` to print the number of observations (`e(N)`) and the R-squared (`e(r2)`) with clear labels. Reflect: what is the practical difference between using a `local` versus a `global` macro for storing a control list?

## Hints

- **Hint 1 (Task 1)**: A local macro is defined with `` local macroname "contents" `` and recalled with backtick–apostrophe notation: `` `macroname' ``. You can pass it directly to `summarize` because Stata expands the macro before executing the command.

- **Hint 2 (Task 2)**: After `summarize varname, meanonly`, the mean is stored in `r(mean)`. Inside the loop your variable is stored in the loop iterator (e.g., `var`), so you would write `` summarize `var', meanonly `` and then `` display "Mean of `var': " r(mean) ``.

- **Hint 3 (Task 3)**: In a `forvalues` loop the syntax is `forvalues r = 1/4 { ... }`. Inside, refer to the current value with `` `r' ``. Remember to close the loop with `}`.

- **Hint 4 (Task 4)**: You can nest the `foreach` loop directly after defining the local. The `regress` command accepts `` `outcome' `` as the dependent variable: `` regress `outcome' pop medage ``. The display separator trick uses `display` with a string before calling `regress`.

- **Hint 5 (Bonus)**: After `regress`, estimation scalars are available via `e()`. Try `ereturn list` after a regression to see what is stored. Global macros are recalled with `$globalname` (no closing apostrophe), unlike locals.
