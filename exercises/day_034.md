# Day 34: Loops and Macros — Automating Repetitive Work

**Dataset**: `webuse psidextract`
**Estimated time**: ~25 minutes
**Difficulty**: ⬛⬛⬛⬛⬜

## Background
The PSID extract contains 4,165 observations from a panel of workers observed across up to 7 time periods, with variables covering wages, employment characteristics, and demographics. Loops and macros are essential tools in labor economics research because they let you apply the same operation across many variables or groups without copy-pasting code — making your scripts shorter, more readable, and less error-prone.

## Your tasks

1. **Define and display a local macro** — Define a local macro called `outcome` that stores the string `"lwage"`. Then use `display` to print the message `"Our outcome variable is: lwage"` by referencing the macro (not by typing the word directly). Confirm the macro works by also running `summarize \`outcome\``.

2. **Loop over a list of binary variables** — Use `foreach` to loop over the variables `occ`, `ind`, `south`, `smsa`, `ms`, `fem`, `union`, and `blk`. Inside the loop, display the variable's name and then run `tabulate` on it so you get a frequency table for each variable in a single compact block of code.

3. **Loop over years with `forvalues`** — The variable `t` takes integer values from 1 to 7, representing the seven time periods. Use `forvalues` to loop over `t` from 1 to 7. Inside the loop, display the message `"Period: #"` (replacing `#` with the loop counter) and compute the mean of `lwage` for observations where `t` equals that period using `summarize` with an `if` condition.

4. **Build variable names dynamically inside a loop** — Define a local macro called `controls` containing `ed exp wks`. Write a `foreach` loop over the contents of `controls`. Inside the loop, use the loop variable to: (a) display a label line such as `"Summary for variable: [varname]"`, and (b) run `summarize` with the `detail` option. Then, *outside the loop*, use a `global` macro called `ctrl_list` to store the same three variable names and verify it works by running `regress lwage $ctrl_list`.

5. *(Bonus)* **Nested loops for group-specific summaries** — Write a nested loop: the outer loop uses `forvalues` over `t` (1 to 7), and the inner `foreach` loop iterates over `occ` and `union`. For each combination, display a single line identifying the period and variable, then compute the mean of that variable restricted to that period using `summarize` with an `if` condition. You should see 14 summary outputs in total (7 periods × 2 variables).

- **Hint 1 (Task 1)**: A local macro is defined with `local macroname "value"` and referenced with backtick–apostrophe syntax: `` `macroname' ``. You can pass a macro wherever Stata expects a variable name.

- **Hint 2 (Task 2)**: The syntax for a `foreach` loop over a variable list is `foreach v of varlist var1 var2 ... { }`. Inside the loop body, refer to the current item as `` `v' ``.

- **Hint 3 (Task 3)**: Inside a `forvalues` loop, the counter macro (e.g., `` `i' ``) is available both in `display` strings (use double quotes and embed `` `i' `` inside) and in `if` conditions such as `if t == \`i'`.

- **Hint 4 (Task 4)**: A global macro is defined with `global macroname "value"` and referenced with `$macroname` (no backtick needed). Remember that `foreach v of local controls` iterates over the contents of a local macro, while `$ctrl_list` is how you expand a global in a command.
