# Day 35: Loops and Macros — Automating Repetitive Analysis

**Dataset**: `sysuse nlsw88`
**Estimated time**: ~25 minutes
**Difficulty**: ⬛⬛⬛⬛⬜

## Background
The NLSW 1988 extract contains labour market data on 2,246 working women, covering wages, experience, education, and job characteristics. Loops and macros are essential tools for any quantitative researcher: they eliminate copy-paste errors, make code easier to update, and allow you to scale an analysis across many variables or values with just a few lines.

## Your tasks

1. **Define and display a local macro** — Using `local`, store the string `"age ttl_exp wage"` in a macro called `keyvars`. Then use `display` to print each variable name stored in the macro to the Results window (in a single `display` call that references the macro).

2. **Loop over a list of variables with `foreach`** — Write a `foreach` loop that iterates over `age`, `ttl_exp`, and `wage`, and inside the loop runs `summarize` on each variable. Confirm that all three summary tables appear in sequence in the Results window.

3. **Reuse your macro inside a loop** — Replace the hard-coded variable list from Task 2 with your `keyvars` macro. That is, write a `foreach` loop whose `of varlist` argument is `` `keyvars' `` rather than the explicit names. The output should be identical to Task 2.

4. **Combine `forvalues` with a conditional summary** — Use `forvalues` to loop over the integer values 1, 2, and 3 (which correspond to the three values of `race`). Inside each iteration, store the current race value in a local macro called `r`, display a clear label such as `"--- Race = [value] ---"`, and then run `summarize wage` with the condition `if race == \`r'`. This lets you inspect the wage distribution separately for each racial group without repeating code three times.

5. *(Bonus)* **Build a results table using a global macro as a running log** — Define a global macro called `logvars` that starts empty. Then write a `foreach` loop over `married`, `south`, `collgrad`, and `smsa`. Inside the loop: (a) run a regression of `wage` on the current indicator variable, (b) append the variable name to `\$logvars`, and (c) after the loop ends, display the sentence `"Regressions completed for: \$logvars"`. This combines globals, foreach, and regression in a single workflow.

- **Hint 1 (Task 1)**: The syntax to define a local is `local macroname "content"`. To reference it later, wrap the name in a backtick and a single quote: `` `macroname' ``. You can pass this reference directly inside `display`.

- **Hint 2 (Task 4)**: Inside a `forvalues` loop the counter variable is itself a local macro. To use it as a numeric condition in `if`, write something like `if race == \`r'` — make sure there is no quotation mark around the local reference when comparing to a number.
