## Background
The 1978 automobile dataset contains price, fuel efficiency, weight, and other characteristics for 74 car models, making it a classic sandbox for regression analysis. Learning to export and visualise regression output with tools like `outreg2`, `estout`, and `coefplot` is essential for producing publication-ready tables and figures in empirical labor and applied economics research.

## Your tasks

1. **Run baseline regressions** — Load the dataset and run two separate OLS regressions: (a) `price` on `mpg` and `weight`; (b) `price` on `mpg`, `weight`, `length`, and `foreign`. Store each set of estimates using `estimates store` with names `m1` and `m2`.

2. **Export a comparison table with `estout`** — Using the stored estimates `m1` and `m2`, call `estout` to display a side-by-side coefficient table in the Results window. Include the number of observations and R-squared for each model, and request standard errors (not t-statistics) in parentheses below each coefficient.

3. **Write the table to a file with `esttab`** — Use `esttab m1 m2` to export the same comparison table to a plain-text file called `auto_results.txt`. Add a title "Price regressions — 1978 automobiles", include stars for statistical significance, and suppress the display of the intercept's standard error label (use the `label` option if variable labels are available, otherwise `varlabels()` to rename at least one regressor).

4. **Visualise coefficients with `coefplot`** — After restoring the stored estimates, call `coefplot m1 m2` to plot the coefficients and 95% confidence intervals for both models side by side. Drop the constant from the plot, add a vertical reference line at zero, and give the graph a descriptive title. Save the graph as `coefplot_auto.png`.

5. *(Bonus)* **Standardised coefficients** — Re-run model `m2` on standardised (mean-zero, unit-variance) versions of all continuous regressors using `egen` and `gen` to create z-scored variables before the regression. Store results as `m2_std`, then use `coefplot` to overlay `m2` and `m2_std` on the same graph so you can compare raw and standardised magnitudes. Comment in your do-file on which predictor has the largest standardised effect on price.

## Hints
<details>
<summary>Click to reveal hints (try first!)</summary>

- **Hint 1 (Task 1)**: `estimates store` must come *immediately* after `regress` — before any other estimation command — to capture the correct results. Give each stored model a short, memorable name like `m1`.

- **Hint 2 (Task 2)**: `estout` accepts the stored model names as positional arguments. The option `se` inside `stats()` or as a standalone option controls what appears in parentheses; check `help estout` for the exact syntax of `cells()` to request coefficients and standard errors together.

- **Hint 3 (Task 3)**: `esttab` is a user-friendly wrapper around `estout`. Pass `using "auto_results.txt"` right after the model names, and use `title()`, `star`, and `nolegend` options. If you want to rename a variable in the table without changing the dataset, look at the `coeflabels()` option.

- **Hint 4 (Task 4)**: `coefplot` is a user-written command (install with `ssc install coefplot` if needed). The `drop(_cons)` option removes the intercept, `xline(0)` adds the vertical reference line, and `title()` sets the heading. Use `graphregion()` or `scheme` options to improve appearance if you like.

- **Hint 5 (Bonus)**: To standardise a variable `x`, compute `gen x_z = (x - r(mean)) / r(sd)` after `summarize x`. The `egen` command with `std()` function is a convenient shortcut: `egen x_z = std(x)`.
