# Day 42: Exporting and Visualizing Regression Results

**Dataset**: `webuse psidextract`
**Estimated time**: ~25 minutes
**Difficulty**: ⬛⬛⬛⬛⬜

## Background
The PSID extract contains 4,165 person-period observations on wages, demographics, and job characteristics for a panel of workers observed over up to 7 periods. Presenting regression results in publication-quality tables and plots is an essential skill in labor economics, where you routinely compare multiple specifications side by side.

## Your tasks

1. **Baseline regression** — Load the dataset and run a simple OLS regression of `lwage` on `ed`, `exp`, and `wks`. Store the estimates under the name `m1` using `estimates store`.

2. **Extended model with `estout`** — Add `union`, `fem`, and `blk` as controls and run a second regression. Store it as `m2`. Then use `estout m1 m2` to display both models in the Results window, showing coefficients and standard errors beneath each coefficient (use the `se` option inside `stats()` or `cells()`).

3. **Export a formatted table with `outreg2`** — Using the two stored models, export a Word-compatible table (`.doc`) with `outreg2` that includes: the coefficient, its standard error, the number of observations, and the R-squared. Name the output file `wage_table.doc`. Remember that `outreg2` works by running regressions sequentially — the first call uses `replace`, the second uses `append`.

4. **Coefficient plot with `coefplot`** — Use `coefplot m1 m2` to display the point estimates and 95% confidence intervals for both models side by side. Exclude the constant from the plot using the `drop()` option. Add a vertical reference line at zero using the `xline()` option, and give the plot a descriptive title.

5. *(Bonus)* **Customised `estout` table** — Re-display the two-model table using `estout`, but this time: (a) rename the variables to readable labels using the `varlabels()` option, (b) add stars for statistical significance with `starlevels(* 0.10 ** 0.05 *** 0.01)`, and (c) suppress the display of the constant row using `drop(_cons)`. Explain in a comment what each option does.

## Hints

- **Hint 1 (Task 1–2)**: After running a regression, `estimates store <name>` saves the current results in memory. You can then refer to stored estimates by name in `estout`. To show standard errors below coefficients, look into `cells(b(fmt(3)) se(fmt(3) par))` — `par` wraps the SE in parentheses.

- **Hint 2 (Task 3)**: `outreg2` is not a built-in command — install it first with `ssc install outreg2`. The typical workflow is: run regression 1, call `outreg2 using wage_table.doc, replace ...`; run regression 2, call `outreg2 using wage_table.doc, append ...`. The options `r2` and `nocons` may be useful.

- **Hint 3 (Task 4)**: `coefplot` also requires installation (`ssc install coefplot`). The syntax `coefplot m1 m2` overlays both models. To drop the intercept, use `drop(_cons)`. The `xline(0)` option draws a vertical line — think about why zero is a meaningful reference point for regression coefficients.
