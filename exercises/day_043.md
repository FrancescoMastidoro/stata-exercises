# Day 43: Exporting Regression Tables with `estout` and `coefplot`

**Dataset**: `sysuse nlsw88`
**Estimated time**: ~25 minutes

## Background
The NLSW 1988 dataset contains detailed labor market information for 2,246 women, including wages, education, experience, and demographics. Producing clean, publication-ready regression tables is an essential skill in applied labor economics — `estout`/`esttab` and `coefplot` are the standard tools for this in Stata.

## Your tasks

1. **Install and load packages** — Install `estout` and `coefplot` if not already installed (`ssc install estout` and `ssc install coefplot`). Then load the dataset and run a baseline OLS regression of `wage` on `ttl_exp`, `collgrad`, and `south`. Store the results using `estimates store baseline`.

2. **Add a second model** — Run a second OLS regression of `wage` on `ttl_exp`, `collgrad`, `south`, `smsa`, and `married`. Store the results as `estimates store extended`. Use `esttab baseline extended` in the console to display both models side by side — note how sample sizes and R² compare.

3. **Export a formatted table** — Use `esttab baseline extended` with options to display star significance levels, standard errors in parentheses (not t-statistics), and two decimal places. Export the table to a plain-text file called `table1.txt` using the `using` option.

4. **Visualise coefficients with `coefplot`** — Use `coefplot baseline extended` to plot the point estimates and 95% confidence intervals for both models in a single graph. Drop the constant from the plot using the `drop(_cons)` option, and add a vertical reference line at zero with `xline(0)`.

5. *(Bonus)* **Customise and export the coefficient plot** — Modify the `coefplot` command to: (a) rename the two model legends to `"Baseline"` and `"Extended"`, (b) add a title `"Wage Determinants — NLSW 1988"`, and (c) export the graph to a `.png` file using `graph export`. Inspect whether the confidence intervals for `south` overlap with zero in either model.

## Hints

- **Hint 1 (Tasks 1–2)**: `estimates store` must come *immediately* after the regression command — each new `regress` overwrites the active stored results in memory until you call `estimates store`. Check `estimates dir` to confirm both models are stored before proceeding.

- **Hint 2 (Task 3)**: In `esttab`, look at the options `se`, `star`, `b(%9.2f)`, and `using "table1.txt"` — you can combine several options in one call. The `replace` sub-option prevents an error if the file already exists.

- **Hint 3 (Task 4)**: `coefplot` accepts stored estimate names directly: `coefplot baseline extended`. The `drop()` option takes the coefficient name as listed in `e(b)` — for the constant, the exact name Stata uses is `_cons`.
