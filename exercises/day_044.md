# Day 44: Exporting and Visualising Regression Output

**Dataset**: `webuse mroz87`
**Estimated time**: ~25 minutes
**Difficulty**: ⬛⬛⬛⬛⬜

## Background
The Mroz (1987) dataset is a classic in labour economics, containing detailed information on married women's labour supply, wages, and household characteristics from the PSID. Presenting regression results cleanly — in publication-ready tables and coefficient plots — is an essential skill for any quantitative researcher who needs to communicate findings clearly.

## Your tasks

1. **Run baseline and extended wage regressions** — Load the dataset and run two OLS regressions with `wwage76` as the outcome: (a) a baseline model regressing `wwage76` on `wedyrs` and `wexper`; (b) an extended model that adds `kl6`, `k618`, and `smsa`. Store both results using `estimates store`.

2. **Export a comparison table with `outreg2`** — Using `outreg2`, export the two stored models side-by-side to a Word or plain-text file called `wage_table.doc` (or `.txt`). Include the number of observations and R-squared. Make sure both models appear in the same table (use the `append` option for the second model).

3. **Export the same table with `esttab`** — Using `esttab` (part of the `estout` package), re-export the two stored models to a file called `wage_table_esttab.rtf`. Display standard errors in parentheses, two decimal places, and add a title "Determinants of Women's Wages (1976)".

4. **Produce a coefficient plot with `coefplot`** — Using `coefplot`, plot the coefficients from both models on the same graph. Exclude the constant from the plot. Add a vertical reference line at zero, and use distinct colours or symbols to distinguish the two models. Label the plot clearly with a title.

5. *(Bonus)* **Customise and export the coefficient plot** — Restrict the `coefplot` to display only the education and experience variables (`wedyrs`, `wexper`). Add 95% confidence intervals, rescale the x-axis so the reference line at zero is clearly visible, and export the figure as a `.png` file using `graph export`. Briefly comment in your do-file why the confidence intervals for the two models differ in width despite using the same variables.

- **Hint 1 (Task 1)**: After each `regress` command, use `estimates store modelname` to save the results in memory — you will need two stored estimates (e.g., `baseline` and `extended`) before calling any export command.

- **Hint 2 (Task 2)**: With `outreg2`, run it once after the first regression with `replace` to create the file, then again after the second regression with `append` to add the column — or pass both stored estimates using `estimates restore` before each call. Check `help outreg2` for the `stats(coef se)` and `addstat` options.

- **Hint 3 (Task 3)**: `esttab baseline extended using wage_table_esttab.rtf` will target both stored models at once. Look at the `se`, `b()`, and `title()` options in `help esttab` — no need to restore estimates individually.

- **Hint 4 (Task 4)**: `coefplot baseline extended` will overlay both models. The option `drop(_cons)` removes the constant, `xline(0)` adds the vertical reference, and you can use `ciopts()` or `mcolor()` to distinguish models visually.
