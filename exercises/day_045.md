## Background
The NLSY80 dataset contains a 1980 cross-section of workers with information on wages, education, cognitive ability, and labor market experience — a classic setup for human capital wage regressions. Presenting regression output cleanly is a core skill in quantitative research: reviewers, coauthors, and thesis supervisors expect formatted tables and coefficient plots, not raw Stata output pasted into documents.

## Your tasks

1. **Run and store two wage regressions** — Regress `lwage` on `educ`, `exper`, and `tenure` in a first model. In a second model, add `iq`, `married`, `black`, and `south`. Store both results using `estimates store`.

2. **Export a formatted comparison table with `esttab`** — Using the two stored estimates, produce a side-by-side table with `esttab` that shows coefficients and standard errors (in parentheses), adds significance stars, includes the number of observations and R², and uses descriptive column titles such as "Baseline" and "Extended".

3. **Export the same table to a plain-text file** — Redirect the `esttab` output to a file called `wage_table.txt` using the `using` option. Verify the file was created by opening it outside Stata.

4. **Draw a coefficient plot with `coefplot`** — Using `coefplot`, plot the point estimates and 95% confidence intervals from both stored models side by side on the same graph. Exclude the constant from the plot. Give the graph a title and label the two model series clearly.

5. *(Bonus)* **Customize the `esttab` table for near-publication quality** — Re-run `esttab` adding: (a) a note at the bottom explaining the significance stars, (b) formatted variable labels using the `label` option or explicit `varlabels()`, (c) only two decimal places throughout, and (d) export the table as a `.rtf` file that could be inserted directly into a Word document.
