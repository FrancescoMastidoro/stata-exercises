# Day 47: Panel Data Fundamentals — Fixed Effects and Within Estimation

**Dataset**: `webuse psidextract`
**Estimated time**: ~25 minutes

## Background
The PSID extract contains wage and employment records for 595 individuals observed over 7 time periods, making it a balanced panel ideal for studying earnings dynamics. Panel methods like fixed effects allow you to control for unobserved, time-invariant individual characteristics — a core tool in labor economics when randomization is not possible.

## Your tasks

1. **Declare the panel structure** — Load the dataset and use `xtset` to declare the panel identifier and time variable. Then run `xtdescribe` to verify the panel is balanced (every individual is observed in all 7 periods).

2. **Summarize within-person variation** — Run `xtsum` on `lwage`, `union`, and `south`. Compare the *overall*, *between*, and *within* standard deviations. Which variable has the most within-person variation relative to its overall variation?

3. **Estimate a pooled OLS and a fixed effects model** — Regress `lwage` on `exp`, `wks`, `union`, `south`, and `ms` first using plain `reg`, then using `xtreg` with the fixed effects (`fe`) option. Compare the coefficients on `union` across the two models and comment on the direction and magnitude of the difference.

4. **Absorb fixed effects with `areg`** — Re-estimate the fixed effects model from Task 3 using `areg` with `absorb(id)`. Confirm that the coefficients on the time-varying regressors match those from `xtreg, fe`. Then check the reported R-squared values: why does `areg` report a higher R-squared than `xtreg, fe`?

5. *(Bonus)* **Between and random effects** — Estimate the same model using `xtreg, be` (between estimator) and `xtreg, re` (random effects). Run the Hausman test comparing the random effects and fixed effects estimates. Based on the test result, which estimator is more appropriate, and what assumption does the test evaluate?

## Hints

<summary>Click to reveal hints (try first!)</summary>

- **Hint 1 (Task 1)**: Look at the variable list — the panel ID variable and the time variable are both documented in the dataset description above. `xtset` takes the individual identifier first, then the time variable.
- **Hint 2 (Task 2)**: `xtsum` produces three rows per variable labeled "overall", "between", and "mean". The *within* standard deviation tells you how much a variable moves *for the same person* over time — a small within SD means the variable barely changes for any individual.
- **Hint 3 (Task 3)**: Fixed effects removes all time-invariant individual characteristics. If `union` membership shifts substantially within individuals over time, the FE estimate will differ notably from OLS, which conflates between-person and within-person variation.
- **Hint 4 (Task 4)**: `areg` with `absorb(id)` treats the individual dummies as nuisance parameters and partial them out — it is algebraically equivalent to `xtreg, fe`. The R-squared difference comes from what each command counts in the denominator when computing R².
