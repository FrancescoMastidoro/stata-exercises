## Background
The Grunfeld dataset contains annual investment, market value, and capital stock data for 10 large US firms from 1935 to 1954, making it a classic panel used in econometrics teaching. Difference-in-differences (DiD) is a cornerstone method in labor and applied economics for estimating causal effects when a natural experiment assigns treatment to some units but not others.

## Your tasks

1. **Explore the panel structure** — Load the dataset and use `xtset` to declare it as a panel with `company` as the unit identifier and `year` as the time variable. Then use `xtdescribe` to confirm the panel is strongly balanced.

2. **Create a treatment indicator** — Suppose a policy change took place in 1945 that affected only companies 1–5 (the "treated" group). Create a binary variable `treated` equal to 1 if `company <= 5`, and a binary variable `post` equal to 1 if `year >= 1945`. Then create the DiD interaction term `did = treated * post`.

3. **Run a basic DiD regression** — Regress `invest` on `treated`, `post`, and `did` using `xtreg` with fixed effects (`fe`). Interpret the coefficient on `did` as the average treatment effect on the treated (ATT). Note why including `treated` as a standalone regressor is redundant under fixed effects — does Stata drop it?

4. **Add a control variable and cluster standard errors** — Re-run the fixed-effects regression from Task 3, adding `mvalue` and `kstock` as controls, and clustering standard errors at the `company` level using `vce(cluster company)`. Compare the standard error on `did` with the unclustered version from Task 3.

5. *(Bonus)* **Test the parallel trends assumption visually** — Using only the pre-treatment period (`year < 1945`), collapse the data to compute the mean of `invest` by `company` and `year`, then construct a variable indicating whether a company is treated. Plot the average investment trends separately for treated and control companies over the pre-period using `twoway line` and assess whether the trends look parallel before 1945.

## Hints

- **Hint 1 (Task 1)**: After `webuse grunfeld`, the command `xtset company year` declares the panel structure. `xtdescribe` will then show you whether all company–year combinations are present.
- **Hint 2 (Task 2)**: Use `gen treated = (company <= 5)` and `gen post = (year >= 1945)`. The interaction term is simply the product of the two indicators — Stata treats multiplication of binary variables naturally.
- **Hint 3 (Task 3)**: With `xtreg invest treated post did, fe`, Stata will absorb company fixed effects. Think about what happens to a time-invariant variable like `treated` inside a within-estimator — does it have any within-company variation?
- **Hint 4 (Task 4)**: The clustering option goes inside the regression command as `, fe vce(cluster company)`. With only 10 clusters, note that clustered SEs may behave unusually — this is worth commenting on.
- **Hint 5 (Bonus)**: Use `keep if year < 1945` on a preserved copy (or use `preserve`/`restore`). Then `collapse (mean) invest, by(company year treated)` and `twoway (line invest year if treated==1) (line invest year if treated==0)` gives a rough parallel-trends plot.
