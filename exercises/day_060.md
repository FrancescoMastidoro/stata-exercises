## Background
The `regsmpl` dataset is a panel of NLS women observed across survey years from 1968 to 1988, containing wages, education, experience, and demographic variables. Difference-in-Differences (DiD) is one of the most widely used quasi-experimental strategies in labor economics, allowing you to estimate causal effects by comparing treated and control groups before and after a policy change.

## Your tasks

1. **Load and inspect the panel** — Load the dataset, then use `xtset` to declare the panel structure using `idcode` as the individual identifier and `year` as the time variable. Confirm the declaration with `xtdescribe` and report how many individuals and periods are in the dataset.

2. **Create a treatment indicator** — Define a binary variable `treated` equal to 1 if an individual's `black` equals 1 (the "treated" group), and 0 otherwise. Then create a binary variable `post` equal to 1 if `year` is greater than or equal to 78 (post-1978), and 0 otherwise. Tabulate both variables to verify their distributions.

3. **Construct the DiD interaction term and run a basic DiD regression** — Generate an interaction variable `did = treated * post`. Regress `ln_wage` on `treated`, `post`, and `did`. Interpret the coefficient on `did` as the DiD estimate. Use `vce(cluster idcode)` to account for within-individual correlation.

4. **Add controls and fixed effects** — Re-run the regression from Task 3 adding `ttl_exp`, `grade`, and `tenure` as controls, and include individual fixed effects using `xtreg` with the `fe` option and `vce(cluster idcode)`. Compare the DiD coefficient to the one from Task 3 and comment briefly on whether it changes.

5. *(Bonus)* **Test the parallel trends assumption informally** — Restrict the sample to the pre-treatment period (`year < 78`). Create year-specific interaction terms between `treated` and dummies for each `year` value (e.g., `treated_y68`, `treated_y70`, etc.). Regress `ln_wage` on these interactions plus year dummies, clustering by `idcode`. If parallel trends held pre-treatment, the interaction coefficients should be statistically indistinguishable from zero — inspect and comment.

## Hints
<details>
<summary>Click to reveal hints (try first!)</summary>

- **Hint 1 (Task 1)**: The syntax for declaring a panel is `xtset panelvar timevar`. After declaring, `xtdescribe` gives you a compact summary of the panel's balance and coverage — look at the "individuals" and "T =" lines.
- **Hint 2 (Task 3)**: You can generate the interaction manually with `gen did = treated * post` before including it in the regression. Remember that in a basic DiD, you need all three terms: the level of `treated`, the level of `post`, and their product `did`.
- **Hint 3 (Task 4)**: When using `xtreg, fe`, Stata automatically absorbs individual fixed effects, so you no longer need to include `treated` as a standalone regressor (it is time-invariant and gets differenced out). Check whether `treated` is dropped and why.
- **Hint 4 (Bonus)**: Use `tab year` first to see which years exist in the data. Then create interactions like `gen treated_y70 = treated * (year == 70)`. You will need one for each pre-treatment year except a reference year — think about which year to omit to avoid perfect collinearity.
