# Day 62: Instrumental Variables (IV) with `ivregress`

**Dataset**: `webuse laborsup`
**Estimated time**: ~25 minutes
**Difficulty**: ⬛⬛⬛⬛⬛

## Background
The `laborsup` dataset contains information on 500 women's labor supply decisions, including their own education, their partner's education, number of children, and income variables. Instrumental variables estimation is a cornerstone of causal inference in labor economics, allowing researchers to isolate exogenous variation in an endogenous regressor using a valid instrument.

## Your tasks

1. **Explore the data** — Load the dataset and run `describe` and `summarize`. Identify which variables could plausibly serve as instruments for `fem_educ` when modeling `fem_inc` as the outcome. Write a brief comment (using `//` or `/* */`) explaining your intuition for instrument relevance and exclusion.

2. **OLS baseline** — Regress `fem_inc` on `fem_educ`, `kids`, and `other_inc` using OLS (`regress`). Note the coefficient on `fem_educ` and its standard error. Save the estimate using `estimates store ols_model`.

3. **2SLS via `ivregress`** — Instrument `fem_educ` with `male_educ` using `ivregress 2sls`. Include `kids` and `other_inc` as exogenous controls. Store the result with `estimates store iv_model`, then use `estimates table ols_model iv_model` to compare the two sets of coefficients side by side.

4. **First-stage diagnostics** — After your `ivregress` command, run `estat firststage` to retrieve the first-stage F-statistic. Then manually run the first-stage regression (`regress fem_educ male_educ kids other_inc`) and check whether `male_educ` is a strong predictor. Comment in your do-file on whether the instrument appears weak or strong according to the conventional F > 10 threshold.

5. *(Bonus)* **Overidentification and LIML** — Add `kids` as a second instrument alongside `male_educ` (re-run `ivregress 2sls` with both instruments). Then run `estat overid` to perform the Sargan–Hansen overidentification test and interpret the p-value. Finally, re-estimate using `ivregress liml` with both instruments and compare the LIML coefficient on `fem_educ` to the 2SLS coefficient — do they differ meaningfully?
