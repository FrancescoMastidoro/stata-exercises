## Background
The `regsmpl` dataset is a panel of NLS women observed across survey years from 1968 to 1988, containing wages, education, work experience, and geographic variables. Difference-in-differences (DiD) is a core identification strategy in labor economics that exploits variation across groups and time to estimate causal effects of policy changes or treatments.

## Your tasks

1. **Load and inspect the panel structure** — Load the dataset, then use `xtset` to declare the panel structure using `idcode` and `year`. Confirm the panel is set correctly and examine how many distinct years appear in the data using `tabulate year`.

2. **Create a post-treatment indicator** — Generate a binary variable called `post` equal to 1 for observations where `year >= 78` (i.e., from 1978 onward) and 0 otherwise. Then generate a binary variable called `treated` equal to 1 if an individual's average value of `black` equals 1 across all their observations (hint: use `egen` with `mean` grouped by `idcode`, then round or threshold). Tabulate both new variables to check your work.

3. **Construct the DiD interaction term** — Generate a variable called `did` as the product of `treated` and `post`. Then run a basic DiD regression of `ln_wage` on `treated`, `post`, and `did`. Report and interpret the sign and magnitude of the coefficient on `did` in a comment.

4. **Add controls and fixed effects** — Re-run the DiD regression from Task 3, this time adding `ttl_exp`, `grade`, and `south` as controls, and absorbing individual fixed effects using `xtreg, fe`. Note that time-invariant variables like `treated` will be dropped — explain in a comment why this happens with fixed effects estimation.

5. *(Bonus)* **Event-study style leads and lags** — Instead of a single `post` indicator, generate a set of year dummies interacted with `treated` for years 1975, 1978, 1980, 1983, 1985, and 1988. Run an `xtreg, fe` regression of `ln_wage` on these interaction terms plus `ttl_exp` and `grade`. Plot or tabulate the coefficients and discuss whether pre-treatment trends appear parallel (i.e., are the pre-1978 interaction coefficients close to zero?).

- **Hint 1 (Task 2)**: To identify whether an individual is always in the `black == 1` group, use `egen treated = mean(black), by(idcode)` — since `black` is 0/1 with no missing values, the mean over a person's records will equal 1 if and only if they are always coded as Black. You can then threshold with `replace treated = (treated == 1)`.
- **Hint 2 (Task 4)**: The `xtreg, fe` estimator demeans each variable within individuals, which removes all time-invariant variation. A variable like `treated` that never changes within a person is perfectly collinear with the individual fixed effects and therefore cannot be identified — Stata will drop it automatically.
