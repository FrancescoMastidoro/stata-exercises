## Background
The PSID extract contains 4,165 observations tracking 595 individuals across up to 7 periods, with information on wages, union status, occupation, and demographics. Difference-in-differences (DiD) is a cornerstone method in labor economics for estimating causal effects when treatment assignment is non-random but follows a clear before/after pattern across groups.

## Your tasks

1. **Load and inspect the panel structure** — Load `webuse psidextract`, then use `xtset` to declare the panel using `id` as the individual identifier and `t` as the time variable. Confirm the panel is balanced by running `xtdescribe`.

2. **Create a treatment indicator** — Define a binary variable `treated` equal to 1 if an individual is ever observed in a union (`union == 1`) in **any** period. Use `egen` with the `max()` function, grouped by `id`, to construct this "ever-treated" variable correctly across all observations for the same individual.

3. **Define a post period and run a basic DiD** — Create a binary variable `post` equal to 1 when `t >= 4` (the second half of the panel). Then run an OLS regression of `lwage` on `treated`, `post`, and their interaction `treated#post`. Interpret the coefficient on the interaction term as the DiD estimate.

4. **Add individual and time fixed effects** — Re-estimate the model using `xtreg lwage post treated#post, fe` (within estimator). Add `i.t` to also absorb time fixed effects. Compare this two-way fixed effects estimate to the simple DiD from Task 3 — does controlling for unobserved individual heterogeneity change the result?

5. *(Bonus)* **Test the parallel trends assumption visually** — Compute the mean of `lwage` for each combination of `treated` and `t` using `collapse` (save a copy with `preserve`/`restore`). Then use `twoway` to plot the mean wage trends for treated and untreated groups over time on the same graph. Do the pre-treatment trends look parallel before `t = 4`?

- **Hint 1 (Task 2)**: `egen treated = max(union), by(id)` will assign each individual the maximum value of `union` they ever hold — think about why `max()` achieves the "ever treated" logic here.
- **Hint 2 (Task 3)**: In Stata, `treated#post` inside a regression requires `i.treated#i.post` when both are binary — or you can manually generate `gen interaction = treated * post` and include it directly.
- **Hint 3 (Task 4)**: The `fe` option in `xtreg` absorbs individual fixed effects; adding `i.t` as a regressor absorbs period fixed effects on top of that. Check whether `treated` can still be included when using `fe` — and think about why or why not.
