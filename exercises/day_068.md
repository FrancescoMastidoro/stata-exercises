## Background
The Grunfeld dataset contains investment, market value, and capital stock data for 10 large US firms observed annually from 1935 to 1954 — a classic balanced panel used in econometrics textbooks. Difference-in-Differences (DiD) is a cornerstone of modern causal inference in labor economics and program evaluation, exploiting variation across units and time to identify treatment effects.

## Your tasks

1. **Declare the panel structure** — Load the dataset and declare it as a panel using `xtset`, identifying the cross-sectional unit (company) and the time variable (year). Summarize the key variables `invest`, `mvalue`, and `kstock` to understand their scale and distribution.

2. **Create a treatment indicator** — Define a binary variable `treated` equal to 1 for companies with `company <= 5` (the "treated" group) and 0 for the remaining five companies. Then create a post-period indicator `post` equal to 1 for years 1945 and later, and 0 otherwise. Tabulate both indicators to verify the split is balanced.

3. **Construct the interaction term and run a basic DiD regression** — Generate the DiD interaction variable `did = treated * post`. Regress `invest` on `treated`, `post`, and `did` using OLS (`regress`). Report and interpret the coefficient on `did` — what does it estimate?

4. **Improve the DiD with fixed effects** — Re-run the DiD using `xtreg` with firm fixed effects (`fe`). Include `post` and `did` in the model (note: `treated` drops out with firm FEs — explain why). Compare the DiD coefficient from this specification to the one from Task 3 and comment on any differences in magnitude or standard error.

5. *(Bonus)* **Parallel trends inspection** — Using `egen`, compute the mean of `invest` by `company` and `year` group, then collapse the data to a year-level dataset separately for treated and control firms (mean investment per group per year). Plot the two time series using `twoway line` and visually assess whether the parallel trends assumption appears plausible in the pre-1945 period.
