# Day 69: LASSO for Variable Selection in Labor Economics

**Dataset**: `webuse mroz87`
**Estimated time**: ~25 minutes

## Background
The Mroz 1987 PSID dataset contains rich information on married women's labor supply decisions, wages, and household characteristics — a classic workhorse of labor economics. LASSO (Least Absolute Shrinkage and Selection Operator) is a powerful regularization technique that automatically selects relevant predictors from a large candidate set, which is invaluable when theory alone does not dictate a parsimonious model.

## Your tasks

1. **Load and explore the candidate predictors** — Load the dataset and run `describe` and `summarize` on the following candidate regressors for the outcome `wwage76` (wife's hourly wage in 1976): `wedyrs`, `wexper`, `wifeage`, `kl6`, `k618`, `hedyrs`, `hwage75`, `mtr`, `unemprt`, `smsa`, `faminc`, `nwinc`. Report the range of `wwage76` and confirm that all listed variables have no missing values.

2. **Estimate a standard OLS baseline** — Regress `wwage76` on the twelve candidate predictors listed in Task 1. Note the number of statistically significant predictors (at the 5% level) and the R². This gives you a benchmark before regularization.

3. **Run LASSO with cross-validation** — Use Stata's `lasso linear` command to regress `wwage76` on the same twelve predictors, letting Stata choose the penalty parameter λ via cross-validation (the default). After estimation, use `lassocoef` to display which coefficients survive the penalization. Compare the selected subset to the significant predictors from Task 2.

4. **Post-LASSO OLS and coefficient comparison** — After running LASSO, use `lasso linear` followed by the `coefpath` plot to visualize how coefficients shrink as λ increases. Then use `lassoselect` (or inspect the `e(selected)` macro) to identify the selected variables, and manually re-run OLS using only those selected variables. Compare the coefficients and standard errors of the selected variables between this post-LASSO OLS and the full OLS from Task 2 — what happens to precision?

5. *(Bonus)* **Rigorous LASSO (rlasso) and inference** — Install the `lassopack` package (`ssc install lassopack`) and use `rlasso` to run the rigorous LASSO (Belloni–Chernozhukov plug-in penalty) on the same specification. Compare the selected variables with the cross-validated LASSO from Task 3. Then use `pdslasso` to obtain post-double-selection estimates of the effect of `wedyrs` on `wwage76`, partialling out all other candidate predictors as controls — discuss why post-double-selection is preferred to simple post-LASSO OLS for causal inference.

- **Hint 1 (Task 3)**: The syntax for LASSO in Stata 16+ is `lasso linear depvar varlist`. After estimation, `lassocoef` displays the nonzero coefficients — look at which predictors survive and compare to your OLS significant ones. You do not need to specify λ manually; cross-validation is the default selection method.

- **Hint 2 (Task 4)**: The `coefpath` command works directly after `lasso linear` and requires no additional arguments. To retrieve the list of selected variables programmatically, try `display e(selected)` after estimation — this macro contains the variable names that received nonzero coefficients under the chosen λ.
