# Day 71: Instrumental Variables (IV) with `ivregress`

**Dataset**: `webuse laborsup`
**Estimated time**: ~25 minutes

## Background
The `laborsup` dataset contains 500 observations on female labor supply, including women's and men's education, earnings, and number of children. Instrumental variables estimation is a cornerstone technique in labor economics when OLS suffers from endogeneity — making this dataset an ideal sandbox for practicing IV with `ivregress`.

## Your tasks

1. **Explore the data** — Load the dataset with `webuse laborsup`. Run `describe` and `summarize` to understand the variables. Pay close attention to the ranges of `fem_inc`, `other_inc`, `kids`, `fem_educ`, and `male_educ`. Note which variable is the binary outcome `fem_work`.

2. **Estimate an OLS baseline** — Regress `fem_inc` on `kids`, `fem_educ`, and `other_inc` using OLS (`regress`). Interpret the coefficient on `kids`: what sign do you get, and does it make economic sense as a naïve estimate?

3. **Run a 2SLS IV regression** — Re-estimate the same model using `ivregress 2sls`, treating `kids` as endogenous and using `male_educ` as an instrument. Write down the IV coefficient on `kids` and compare its magnitude and sign to the OLS estimate from Task 2.

4. **Test instrument relevance and run diagnostics** — After the `ivregress` command, use `estat firststage` to inspect the first-stage F-statistic. Then run `estat endogenous` to test whether `kids` is in fact endogenous. Report what both tests tell you about the validity of your IV strategy.

5. *(Bonus)* **Compare 2SLS and LIML** — Re-run the IV regression from Task 3 using the `liml` estimator instead of `2sls`. Compare the point estimates and standard errors between the two estimators. Under what conditions would LIML be preferred over 2SLS, and do your results suggest a meaningful difference here?
