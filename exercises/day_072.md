## Background
The NLSY 1980 dataset contains cross-sectional information on 935 workers, including wages, education, IQ, and family background variables. Instrumental Variables (IV) estimation is a cornerstone technique in labor economics for addressing endogeneity — for example, when education is correlated with unobserved ability in a wage equation.

## Your tasks

1. **Explore the data** — Load the dataset and run `describe` and `summarize` on `lwage`, `educ`, `exper`, `tenure`, `iq`, `meduc`, and `feduc`. Note which variables have missing values and how many observations you will actually be working with.

2. **OLS baseline** — Regress `lwage` on `educ`, `exper`, `tenure`, `iq`, `black`, `south`, and `urban` using OLS. Store the results using `estimates store ols`. Note the coefficient and standard error on `educ`.

3. **First-stage check** — Before running IV, assess instrument relevance. Regress `educ` on your proposed instrument `meduc` plus all the other exogenous regressors from Task 2 (`exper`, `tenure`, `iq`, `black`, `south`, `urban`). Check whether `meduc` is statistically significant and note the F-statistic for the first stage (use `test meduc` after the regression).

4. **IV estimation** — Estimate the wage equation via two-stage least squares (2SLS) using `meduc` as an instrument for `educ`. Use `ivregress 2sls` with the same controls as Task 2. Store results as `estimates store iv`. Then use `estimates table ols iv, b se` to compare the OLS and IV coefficients on `educ` — comment in a code note (`//`) on the direction and magnitude of any change.

5. *(Bonus)* **Test for endogeneity and over-identification** — Re-run the IV regression adding `feduc` as a second instrument for `educ` (note: `feduc` has 194 missing values, so your sample will shrink). After `ivregress`, run `estat endogenous` to test whether OLS or IV is preferred, and `estat overid` to test the validity of the over-identifying restriction. Interpret both test p-values in a comment.

- **Hint 1 (Task 3)**: A weak instrument rule of thumb is that the first-stage F-statistic should exceed 10. After regressing `educ` on all regressors including `meduc`, use `test meduc` to get an F-statistic for that single instrument — not the overall model F.

- **Hint 2 (Task 4)**: In `ivregress 2sls`, the syntax separates endogenous regressors from instruments inside parentheses: `ivregress 2sls lwage exper tenure iq black south urban (educ = meduc)`. The variables listed outside the parentheses are treated as exogenous controls; the parenthetical tells Stata which variable is endogenous and what instruments it.
