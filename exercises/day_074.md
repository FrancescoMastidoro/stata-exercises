## Background
The PSID extract contains 4,165 observations tracking 595 individuals over 7 time periods, with information on wages, employment characteristics, and demographics. Difference-in-differences (DiD) is a cornerstone identification strategy in labor economics, allowing researchers to estimate causal effects by comparing treated and untreated groups before and after a policy change.

## Your tasks

1. **Explore the panel structure** — Load the dataset and declare it as a panel using `xtset`. Then use `xtdescribe` to verify the panel is balanced. Report how many individuals (`id`) and time periods (`t`) are present.

2. **Create a treatment indicator** — Define a "post" dummy equal to 1 when `t >= 5` and 0 otherwise. Then define a "treated" dummy equal to 1 for individuals who are union members (`union == 1`) in the *first* period (`t == 1`). To assign this group membership to all observations for each individual, use `egen` with the `max()` function, grouping by `id`.

3. **Estimate a basic DiD** — Run a regression of `lwage` on `treated`, `post`, and their interaction (`treated#post` or manually as `treated_post = treated * post`). Interpret the coefficient on the interaction term as the DiD estimate. Does union membership appear to raise wages after period 5?

4. **Add fixed effects and controls** — Re-estimate the DiD using `xtreg lwage treated post c.treated#c.post exp wks occ, fe`. Compare the interaction coefficient to the simpler model in Task 3. Then use `estimates store` to save both models and display them side-by-side with `esttab` or `estimates table`.

5. *(Bonus)* **Parallel trends check** — Restrict the sample to `t <= 4` (the pre-treatment window). Regress `lwage` on `treated`, period dummies (`i.t`), and their interactions (`treated#i.t`) using `xtreg, fe`. If parallel trends holds, the interaction coefficients should all be statistically indistinguishable from zero. Interpret what you find and explain why this is important for DiD validity.

- **Hint 1 (Task 2)**: To assign a time-invariant group membership based on a condition in a single period, the pattern is `bysort id: egen treated = max(condition)` — where `condition` evaluates to 1 only when `t == 1` and the unit satisfies your criterion, and 0 otherwise. `max()` propagates that 1 across all rows for the same individual.

- **Hint 2 (Task 3)**: You can either create an explicit interaction variable with `gen treated_post = treated * post`, or use Stata's factor variable notation `c.treated#c.post` (since `treated` and `post` are continuous 0/1 variables here rather than declared factors). Either approach works, but check how Stata labels the coefficient in the output.

- **Hint 3 (Task 4)**: When you use `xtreg, fe`, Stata absorbs the individual fixed effects automatically — you do not need to include `i.id` manually. Note that `treated` (which is time-invariant within individuals) will be dropped by the within estimator; only `post` and the interaction survive alongside time-varying controls.

- **Hint 4 (Task 5)**: The pre-trend test is sometimes called a "placebo test in time." You are checking whether treated and control groups were already diverging *before* the treatment. Use `keep if t <= 4` (or a temporary restriction with `if`) and interact `treated` with each time dummy individually.
