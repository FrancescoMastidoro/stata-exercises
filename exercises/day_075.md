## Background
The `regsmpl` dataset is a panel of NLS women observed from 1968 to 1988, containing information on wages, education, work experience, and location. Difference-in-Differences (DiD) is one of the most widely used causal inference strategies in labor economics, allowing researchers to estimate treatment effects by comparing changes over time across groups.

## Your tasks

1. **Load and explore the panel** — Load `webuse regsmpl`, declare the panel structure using `xtset` with `idcode` as the individual identifier and `year` as the time variable, then tabulate `year` to see which years are present in the data.

2. **Define a treatment indicator** — Create a binary variable called `post` equal to 1 if `year` >= 78 (i.e., from 1978 onward) and 0 otherwise. Then create a binary variable called `treated` equal to 1 if `black == 1` and 0 otherwise. Tabulate both new variables to confirm they look correct.

3. **Construct the DiD interaction term** — Generate a variable called `did` as the product of `treated` and `post`. Then run a basic DiD regression of `ln_wage` on `treated`, `post`, and `did`. Report what the coefficient on `did` represents in words.

4. **Add controls and fixed effects** — Re-run the DiD regression adding `ttl_exp`, `grade`, and `tenure` as controls. Then run a third specification that additionally includes individual fixed effects using `xtreg, fe`. Compare how the coefficient on `did` changes across the three specifications and explain why individual fixed effects absorb the `treated` main effect.

5. *(Bonus)* **Event-study plot** — Instead of a single `post` dummy, create a set of year-specific interaction dummies between `treated` and each distinct `year` value (omitting one pre-treatment year as the baseline). Run `xtreg ln_wage` with these interaction dummies and individual fixed effects, then use `coefplot` (if installed) or `marginsplot` to visualize the dynamic treatment effects over time and assess whether the parallel trends assumption appears plausible in the pre-period.

- **Hint 1 (Tasks 1–2)**: After `webuse regsmpl`, use `xtset idcode year` to declare the panel. For the `post` variable, `generate post = (year >= 78)` works because Stata evaluates the logical expression and assigns 1/0 automatically — no `if` needed.

- **Hint 2 (Task 3)**: The DiD coefficient on `did` captures the *differential change* in `ln_wage` for the treated group relative to the control group after the policy date — it is your estimate of the average treatment effect on the treated (ATT), under the parallel trends assumption.

- **Hint 3 (Task 4)**: For individual fixed effects use `xtreg ln_wage treated post did ttl_exp grade tenure, fe`. Notice that `treated` drops out in the FE model — think about *why* a time-invariant variable cannot be identified within an individual fixed-effects estimator. Also be aware that `grade` and `tenure` have some missing values, so your sample size may shrink slightly.

- **Hint 4 (Bonus)**: To create year-specific interaction dummies efficiently, consider `forvalues y = 68(2)88 { generate interact_`y' = treated * (year == `y') }` and then drop the baseline year you choose. `coefplot` is a community-written package installable with `ssc install coefplot`.
