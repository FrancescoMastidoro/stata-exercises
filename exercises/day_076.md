## Background
The PSID extract contains 4,165 observations on workers observed across up to 7 time periods, with information on wages, occupation, industry, union status, and demographics. Difference-in-Differences (DiD) is a cornerstone method in labor economics for estimating causal effects when randomized experiments are infeasible, exploiting variation in treatment timing across groups and time.

## Your tasks

1. **Load and declare panel structure** — Load the dataset with `webuse psidextract`, then declare the panel structure using `xtset`. Confirm the panel identifier and time variable by inspecting the variables `id` and `t`. How many unique individuals are in the dataset?

2. **Create a post-period indicator** — The panel covers 7 periods (`t` runs from 1 to 7). Create a binary variable called `post` equal to 1 if `t >= 4` and 0 otherwise. This will serve as your "after" indicator in the DiD design. Tabulate `post` to verify the split.

3. **Define treatment and control groups** — Use union membership (`union`) as the treatment indicator. Define `treated` as a variable equal to 1 if a worker is in a union (`union == 1`) and 0 otherwise. Then construct the DiD interaction term `did = post * treated`. Tabulate `did` to check how many observations fall into each cell.

4. **Estimate the DiD model** — Regress log wage (`lwage`) on `post`, `treated`, and the interaction term `did`, controlling for education (`ed`), experience (`exp`), and whether the worker lives in the south (`south`). Use `xtreg` with fixed effects (`fe`) to absorb individual-level unobserved heterogeneity. Interpret the coefficient on `did`: what does it represent in this context?

5. *(Bonus)* **Event-study style check** — Instead of a single `post` dummy, create period dummies for each value of `t` (1 through 7), omitting `t == 3` as the baseline. Interact each period dummy with `treated` and run the fixed-effects regression again. Plot the coefficients on these interaction terms using `coefplot` (if installed) or inspect them manually. Do pre-period coefficients appear close to zero, supporting the parallel trends assumption?

- **Hint 3 (Task 4)**: `xtreg lwage post treated did ed exp south, fe` is the general structure — but think carefully about which variables a fixed-effects estimator can actually identify (time-invariant variables will be absorbed). Check what happens to `south` and `treated` in the output and why.
