## Background
The Grunfeld dataset contains firm-level investment, market value, and capital stock for 10 US companies observed annually from 1935 to 1954 — a classic balanced panel used in econometrics. Difference-in-Differences (DiD) is a cornerstone method in labor and applied economics for estimating causal effects when treatment assignment is not random but follows a before/after × treated/control structure.

## Your tasks

1. **Declare the panel structure** — Load the dataset, then use `xtset` to declare it as a panel with `company` as the unit identifier and `year` as the time variable. Summarize `invest`, `mvalue`, and `kstock` to get a feel for the data.

2. **Create a treatment indicator** — Define a binary variable `treated` equal to 1 for companies with `company` ≤ 5 (the "treated" group) and 0 otherwise. Then create a binary variable `post` equal to 1 for years 1945 and later, and 0 for years before 1945. Display the cross-tabulation of `treated` and `post` to verify the four DiD cells are balanced.

3. **Run the baseline DiD regression** — Create the interaction term `did = treated × post`. Regress `invest` on `treated`, `post`, and `did`. Report and interpret the coefficient on `did` — what does it represent in a DiD framework?

4. **Add firm and year fixed effects** — Re-estimate the DiD model using `xtreg` with the `fe` option (absorbing firm fixed effects) and include year dummies via `i.year`. Compare the coefficient on the interaction term to your result from Task 3 and briefly comment on what changes and why.

5. *(Bonus)* **Test the parallel trends assumption graphically** — Compute the mean of `invest` by `year` separately for the treated and control groups using `collapse` (or `egen`). Plot both series over time on the same graph using `twoway line`. Does the pre-1945 trend look parallel between the two groups?

- **Hint 1 (Task 2)**: You can create `treated` with `gen treated = (company <= 5)` — Stata evaluates the logical expression and assigns 1 if true, 0 if false. For `post`, apply the same logic using the `year` variable and the threshold 1945.

- **Hint 2 (Task 3)**: The DiD estimator is the coefficient on the interaction `treated × post`. Before creating it manually with `gen did = treated * post`, make sure both variables are coded as 0/1 so the product behaves correctly. Then use `reg invest treated post did`.

- **Hint 3 (Task 4)**: With `xtreg, fe`, Stata automatically absorbs the firm-level fixed effects captured by `company`. Add year dummies by including `i.year` as a regressor. The interaction `did` still identifies the average treatment effect on the treated in the post period, but year FE control for aggregate time shocks that would otherwise confound `post`.

- **Hint 4 (Bonus)**: Use `preserve` before `collapse` so you can restore the original data afterwards. The syntax `collapse (mean) invest, by(year treated)` produces one row per year-group cell, which you can then plot with `twoway (line invest year if treated==1) (line invest year if treated==0)`.
