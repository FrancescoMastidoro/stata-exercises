## Background
The `regsmpl` dataset is an NLS women panel covering 1968–1988, making it well-suited for studying how policy changes or labor market shocks affect wages over time. Difference-in-Differences (DiD) is a cornerstone technique in labor economics for estimating causal effects when random assignment is not feasible.

## Your tasks

1. **Load and explore** — Load the dataset with `webuse regsmpl`. Tabulate `year` to see which survey years are present, and check `xtset` to confirm the panel structure (use `idcode` and `year`). Report how many individuals appear in the data.

2. **Define treatment and post periods** — Create a binary variable `treated` equal to 1 if `black == 1` (the treatment group), and a binary variable `post` equal to 1 if `year >= 78` (post-1978). Verify both variables by running `tabulate treated post`.

3. **Construct the interaction term and run a basic DiD** — Generate an interaction variable `did = treated * post`. Regress `ln_wage` on `treated`, `post`, and `did`. Interpret the coefficient on `did`: what does it represent in a DiD framework?

4. **Add controls and fixed effects** — Re-run the DiD regression adding `ttl_exp`, `tenure`, `grade`, and `south` as controls, and include `year` fixed effects using `i.year`. Compare the coefficient on `did` to the one from Task 3 and note whether it changes substantially.

5. *(Bonus)* **Parallel trends check** — To probe the parallel trends assumption, restrict the sample to pre-1978 observations only. Create a variable `year_trend = year - 68` and regress `ln_wage` on `treated`, `year_trend`, and `c.treated#c.year_trend`. If the interaction is close to zero and statistically insignificant, this is consistent with (but does not prove) parallel pre-trends. Run this regression and comment on the result.

- **Hint 1 (Task 1)**: After `webuse regsmpl`, use `xtset idcode year` to declare the panel. Then `tabulate year` will show you the distinct survey waves. To count unique individuals, try `distinct idcode` or `egen tag = tag(idcode)` followed by `count if tag == 1`.

- **Hint 2 (Task 3)**: The coefficient on `did` is the canonical DiD estimator — it captures the *differential* change in `ln_wage` for the treated group relative to the control group, going from pre- to post-period. It equals (Δmean for treated) − (Δmean for controls).

- **Hint 3 (Task 4)**: To include year fixed effects flexibly, write `i.year` in the regress command. Remember that `tenure` and `grade` have some missing values in this dataset, so your sample may shrink slightly — note the number of observations used.

- **Hint 4 (Bonus)**: Use `keep if year < 78` (or `if year < 78` as a sample restriction) before or within the regression. Centering year at the start of the sample (`year_trend = year - 68`) avoids a large constant and makes the interaction easier to interpret.
