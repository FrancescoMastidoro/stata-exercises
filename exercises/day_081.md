## Background
The PSID extract contains 4,165 observations tracking 595 workers over 7 time periods, with information on wages, employment characteristics, union status, and demographics. Difference-in-differences (DiD) is a cornerstone identification strategy in labor economics, allowing researchers to estimate causal effects by comparing treated and control groups before and after an event.

## Your tasks

1. **Load and explore the panel structure** — Load `webuse psidextract`, then use `xtset` to declare the panel structure using `id` as the unit identifier and `t` as the time variable. Confirm the balanced structure by tabulating how many observations each individual contributes.

2. **Construct a DiD indicator** — Define a "post" period as `t >= 5` and a "treated" group as workers in the industrial sector (`ind == 1`). Create two new indicator variables: `post` (equals 1 if `t >= 5`, 0 otherwise) and `treat` (equals 1 if `ind == 1`, 0 otherwise). Then construct the DiD interaction term `did = post * treat`.

3. **Run a basic DiD regression** — Regress log wages (`lwage`) on `treat`, `post`, and `did`. Interpret the coefficient on `did` as the DiD estimate. Does union membership in the industrial sector appear to have changed log wages in the post period relative to the pre-period?

4. **Add individual and time fixed effects** — Re-estimate the DiD model using `xtreg` with the `fe` option to absorb individual fixed effects, then add time dummies by including `i.t` as a regressor. Compare the coefficient on `did` with the estimate from Task 3 and comment on how controlling for unobserved individual heterogeneity changes the estimate.

5. *(Bonus)* **Parallel trends inspection** — Generate period-specific interaction terms between `treat` and each value of `t` (i.e., `treat#i.t`) and include them in a regression of `lwage` on individual fixed effects (`xtreg, fe`) along with these interactions. Plot the coefficients using `coefplot` (if installed) or inspect them manually. Do pre-treatment coefficients look close to zero, as parallel trends would require?
