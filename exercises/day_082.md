## Background
The Grunfeld dataset tracks investment, market value, and capital stock for 10 large US firms from 1935 to 1954 — a classic panel used to study corporate investment behavior. Difference-in-Differences (DiD) is a cornerstone identification strategy in labor economics and applied microeconomics, exploiting variation across groups and over time to recover causal effects.

## Your tasks

1. **Load and explore** — Load the dataset with `webuse grunfeld`. Declare the panel structure using `xtset`, then summarize all variables. Confirm that `company` ranges from 1 to 10 and `year` from 1935 to 1954 with no missing values.

2. **Create a treatment indicator** — Using `gen`, create a binary variable called `treated` equal to 1 for companies with `company <= 5` (the "treated" group) and 0 otherwise. Then create a `post` variable equal to 1 for years from 1945 onward and 0 for earlier years. Verify your coding with `tabulate treated post`.

3. **Construct the interaction term and run DiD** — Generate an interaction variable `did = treated * post`. Run an OLS regression of `invest` on `treated`, `post`, and `did`. Interpret the coefficient on `did`: what does it represent in a DiD framework?

4. **Improve the specification** — Re-run the DiD regression using `xtreg` with firm fixed effects (`fe`) instead of the `treated` dummy, and include the `post` and `did` variables. Compare the coefficient on `did` to your Task 3 result, and use `vce(robust)` to obtain robust standard errors. Does the point estimate change? Why might it differ?

5. *(Bonus)* **Event-study style plot** — Instead of a single `post` dummy, create a separate dummy for each year relative to the treatment cutoff (1945), ranging from −5 to +5 years. Run a fixed-effects regression of `invest` on this set of year dummies interacted with `treated`, plus firm fixed effects. Use `coefplot` (if installed) or manually inspect the coefficients to assess whether the parallel trends assumption looks plausible in the pre-treatment period.

- **Hint 1 (Tasks 2–3)**: The DiD estimator is the coefficient on the interaction term `treated × post`. Think carefully about what `treated` captures on its own versus what the interaction adds — you do not need to include `treated` in the `xtreg fe` model because firm fixed effects already absorb all time-invariant firm-level differences.
- **Hint 2 (Task 4)**: With `xtreg, fe`, Stata demeans each variable within firms, so the level of `treated` is collinear with the firm fixed effect and will be dropped automatically. You only need `post` and `did` in that specification. For robust standard errors, add `vce(robust)` as an option at the end of the `xtreg` command.
