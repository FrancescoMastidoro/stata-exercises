## Background
The Mroz 1987 PSID dataset contains information on married women's labor supply decisions, earnings, and household characteristics in the mid-1970s. Difference-in-differences is one of the most widely used quasi-experimental designs in labor economics, and understanding how to implement and interpret it correctly is essential for causal inference with observational data.

## Your tasks

1. **Construct a treatment indicator** — Create a binary variable called `treated` equal to 1 if a woman has at least some college education (`wedyrs >= 14`) and 0 otherwise. Tabulate `treated` and confirm that both groups contain a meaningful number of observations.

2. **Create a simulated post-period** — Create a binary variable called `post` equal to 1 if `wexper` (wife's years of experience) is greater than its median value, and 0 otherwise. This simulates a "before/after" split based on accumulated experience. Report how many observations fall in each period using `tabulate`.

3. **Construct the interaction term and run a basic DiD regression** — Generate an interaction variable `did = treated * post`. Regress `wwage76` (wife's 1976 hourly wage) on `treated`, `post`, and `did`. Report and interpret the coefficient on `did`: what does it represent in a DiD framework?

4. **Add controls and use robust standard errors** — Re-run the DiD regression from Task 3, this time adding `wifeage`, `kl6`, `k618`, and `smsa` as controls. Use `vce(robust)` to obtain heteroskedasticity-robust standard errors. Compare the DiD coefficient to the one obtained in Task 3 and comment on whether it changes meaningfully.

5. *(Bonus)* **Test the parallel trends assumption informally** — Restrict the sample to observations where `post == 0` (the "pre-period" only). Regress `wwage76` on `treated` and `wexper` interacted with `treated` (`c.wexper#i.treated`). If the parallel trends assumption held, what sign and magnitude would you expect on the interaction term? Interpret the output.
