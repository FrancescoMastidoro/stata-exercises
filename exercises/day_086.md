## Background
The PSID extract contains 4,165 observations tracking workers across 7 time periods, with variables covering wages, employment characteristics, union status, and demographics. Difference-in-differences (DiD) is a cornerstone method in labor economics for estimating causal effects when random assignment is impossible — making this panel well-suited for practicing the technique.

## Your tasks

1. **Load and explore the panel structure** — Load the dataset with `webuse psidextract`. Declare the panel structure using `xtset id t`. Then use `xtdescribe` to confirm the panel is balanced. Report how many individuals and time periods are present.

2. **Define a pseudo-treatment** — Create a binary variable called `treated` equal to 1 if `union == 1` in period `t == 1` (the worker's baseline union status) and 0 otherwise. Use `bysort id` and `egen` to assign this baseline value to *all* observations for each individual, so every row for a given worker carries the same `treated` indicator.

3. **Define a post-period and estimate a naive DiD** — Create a binary variable `post` equal to 1 if `t >= 4` and 0 otherwise. Then estimate a simple DiD regression of `lwage` on `treated`, `post`, and their interaction `treated#post` (or construct the interaction manually as `did = treated * post`). Interpret the sign of the interaction coefficient.

4. **Add controls and fixed effects** — Re-estimate the DiD model using `xtreg lwage treated##i.post i.t exp wks occ ind south smsa ms fem blk ed, fe`. Discuss: why does the `treated` main effect drop out under within-estimator fixed effects? What does the coefficient on the interaction term now represent relative to the simpler model in Task 3?

5. *(Bonus)* **Parallel trends check** — Generate a set of period-specific interaction dummies by interacting `treated` with each value of `t` (excluding the reference period `t == 3`, which is just before your `post` cutoff). Run a regression of `lwage` on these interactions plus individual and time fixed effects (use `xtreg, fe` and `i.t#c.treated`). Plot or inspect the pre-period coefficients (t = 1, 2) to assess whether the parallel trends assumption is plausible.
