# Day 87: LASSO for Variable Selection in Wage Equations

**Dataset**: `webuse nlsy80`
**Estimated time**: ~25 minutes

## Background
The NLSY 1980 dataset contains cross-sectional information on wages, education, cognitive ability, and family background for 935 workers — a classic setting for earnings regressions in labor economics. LASSO (Least Absolute Shrinkage and Selection Operator) is a regularized regression method that automatically selects relevant predictors by shrinking some coefficients exactly to zero, which is invaluable when a researcher faces many candidate regressors and wants to avoid overfitting.

## Your tasks

1. **Load and inspect** — Load the dataset with `webuse nlsy80`. Use `describe` and `summarize` to get a feel for the variables. Note which variables have missing values (`brthord`, `meduc`, `feduc`) and which do not. Pay attention to the outcome variable `lwage` (log monthly wage).

2. **Run a baseline OLS** — Regress `lwage` on the full set of continuous and binary predictors available without missing values: `hours`, `iq`, `kww`, `educ`, `exper`, `tenure`, `age`, `married`, `black`, `south`, `urban`, `sibs`, `pcollege`, `college`, `fcollege`. Note which coefficients are statistically significant at the 5% level.

3. **Run LASSO** — Use Stata's `lasso linear` command to regress `lwage` on the same set of predictors you used in Task 2. Allow Stata to choose the penalty parameter via cross-validation by specifying the `selection(cv)` option. After estimation, use `lassocoef` to display which variables LASSO retained with non-zero coefficients.

4. **Post-LASSO OLS** — Use the `lasso postestimation` workflow: after your `lasso linear` estimation, run `lassoselect` (or inspect `e(allvars_sel)`) to identify the selected variables, then manually run an OLS regression (`regress`) using only the LASSO-selected predictors. Compare the coefficients and standard errors of the selected variables to those from the full OLS in Task 2 — do the magnitudes change meaningfully?

5. *(Bonus)* **Partialling-out LASSO for inference** — Use the `xporegress` command (cross-fit partialling-out LASSO) to estimate the causal effect of `educ` on `lwage`, controlling for all other predictors in the dataset that have no missing values. Compare the point estimate and confidence interval to the coefficient on `educ` from your baseline OLS in Task 2 and briefly comment (in a code comment) on whether the two approaches agree.

## Hints

- **Hint 1 (Task 3)**: The syntax for cross-validation LASSO in Stata 16+ is `lasso linear depvar varlist, selection(cv)` — after estimation, `lassocoef` with the `, display` option shows the retained variables clearly.
- **Hint 2 (Task 4)**: After `lasso linear`, the macro `e(allvars_sel)` stores the names of selected variables as a string; you can use it directly inside a `regress` command by writing `` regress lwage `e(allvars_sel)' `` — but make sure you do this immediately before running any other estimation command that would overwrite `e()`.
