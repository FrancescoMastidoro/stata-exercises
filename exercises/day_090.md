## Background
The PSID extract contains 595 individuals observed across up to 7 time periods, with information on wages, union status, occupation, and demographics — a classic structure for panel-based causal inference. Difference-in-Differences (DiD) exploits variation in treatment timing or status across groups and over time to identify causal effects, and is one of the most widely used methods in labor economics.

## Your tasks

1. **Load and explore the panel** — Load `webuse psidextract`, declare the panel using `xtset`, and use `xtdescribe` to confirm the panel is balanced. Report how many individuals and time periods are in the data.

2. **Define treatment and post indicators** — Union membership (`union`) is your treatment variable. Create a binary variable `ever_union` equal to 1 if an individual was ever in a union across all their observations (hint: think about `egen` and its `max` function). Also create a binary variable `post` equal to 1 if `t >= 4` (the second half of the panel).

3. **Compute group-time means manually** — Using `tabstat lwage`, compute the average log wage separately for the four cells of a 2×2 DiD table: (ever_union × post). Report the four means and compute the DiD estimate by hand: (treated post − treated pre) − (control post − control pre).

4. **Estimate DiD by regression** — Run an OLS regression of `lwage` on `ever_union`, `post`, and their interaction `ever_union#post`. Then re-run the same regression adding individual and time fixed effects using `areg` or `xtreg, fe` together with `i.t`. Compare the interaction coefficient across the two specifications and comment on how controlling for fixed effects changes the estimate.

5. *(Bonus)* **Parallel trends check** — Restrict the sample to the pre-treatment periods only (`t < 4`). Regress `lwage` on the interaction of `ever_union` with each time period indicator (`i.t#c.ever_union`) using `xtreg, fe`. If parallel trends holds, the interaction coefficients should be jointly insignificant — test this with `testparm`. Report whether you can reject parallel trends.

- **Hint 1 (Task 2)**: `egen ever_union = max(union), by(id)` will compute the within-individual maximum of `union` across all periods — since `union` is 0/1, this equals 1 if the individual was ever unionised.

- **Hint 2 (Task 3)**: You can use `tabstat lwage, by(post) statistics(mean)` separately for each `ever_union` group, or combine conditions with `if`. The DiD estimate is simply the difference in differences of the four cell means — write it out explicitly in a comment line in your do-file.

- **Hint 3 (Task 4)**: To include the interaction in the regression, you can either generate it manually as `gen inter = ever_union * post` or use Stata's factor variable syntax `i.ever_union##i.post`. For the fixed-effects version, `xtreg lwage i.post ever_union#i.post, fe` absorbs individual fixed effects automatically (note: time-invariant `ever_union` will be absorbed too — think about what this means for interpretation).

- **Hint 4 (Task 5)**: After restricting with `if t < 4`, the syntax `xtreg lwage i.t#c.ever_union, fe` estimates a separate slope on `ever_union` for each pre-period. `testparm i.t#c.ever_union` then performs a joint F-test on all those interactions.
