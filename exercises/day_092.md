## Background
The Grunfeld dataset records annual investment, firm market value, and capital stock for 10 large US firms over 20 years (1935–1954), making it a classic panel used in econometrics teaching. Difference-in-Differences (DiD) is a cornerstone identification strategy in labor and applied economics: it recovers causal effects by comparing changes over time across treated and untreated groups.

## Your tasks

1. **Load and inspect the panel structure** — Load the dataset, then use `xtset` to declare it as a panel with `company` as the panel identifier and `year` as the time variable. Run `xtdescribe` to confirm the panel is balanced.

2. **Create a treatment indicator** — Define a binary variable `post` equal to 1 for years 1945 and later (i.e., the post-WWII period), and 0 otherwise. Then define a binary variable `treated` equal to 1 for companies 1–5 and 0 for companies 6–10. These will serve as your DiD building blocks.

3. **Construct the interaction term and run a basic DiD regression** — Create an interaction variable `did = treated * post`. Regress `invest` on `treated`, `post`, and `did` using `xtreg` with fixed effects (`fe`). Report and interpret the coefficient on `did` in a comment.

4. **Add a control variable and cluster standard errors** — Re-run the fixed-effects regression from Task 3, adding `mvalue` and `kstock` as controls. Cluster standard errors at the `company` level using the `vce(cluster company)` option. Compare the standard error on `did` to the unclustered version and note any difference in a comment.

5. *(Bonus)* **Event-study style leads and lags** — Instead of a single `post` dummy, generate year-relative dummies for each year from 1935 to 1954, using 1944 as the omitted base year. Regress `invest` on the full set of `treated × year` interactions (excluding the 1944 interaction), controlling for `mvalue` and `kstock`, with company fixed effects and clustered SEs. Plot the coefficients using `coefplot` (if installed) or `marginsplot` and comment on whether pre-trends look flat before 1945.

- **Hint 1 (Task 2)**: Use `generate post = (year >= 1945)` — Stata evaluates the logical expression and assigns 1 if true, 0 if false. The same logic applies to `treated`.
- **Hint 2 (Task 3)**: When you use `xtreg, fe`, Stata automatically absorbs the panel-level fixed effects, so you do not need to include `treated` as a separate regressor — think about why that is before running the regression.
- **Hint 3 (Task 4)**: Clustering at the level of treatment assignment (here, the company) is standard practice in DiD to account for within-group serial correlation; the syntax is `xtreg invest post did mvalue kstock, fe vce(cluster company)`.
- **Hint 4 (Task 5)**: Use `forvalues` to loop over years and generate dummies like `gen inter_1935 = treated * (year == 1935)`, then list all interaction terms in the regression while omitting `inter_1944`. A flat pre-trend (coefficients near zero before 1945) supports the parallel-trends assumption.
