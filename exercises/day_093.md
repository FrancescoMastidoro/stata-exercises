# Day 93: LASSO for Variable Selection in Labor Economics

**Dataset**: `webuse nlsy80`
**Estimated time**: ~25 minutes
**Difficulty**: ⬛⬛⬛⬛⬛

## Background
The NLSY 1980 dataset contains a rich cross-section of 935 young workers with variables spanning wages, education, cognitive ability, family background, and demographics. LASSO (Least Absolute Shrinkage and Selection Operator) is increasingly used in labor economics to select predictors from a large covariate set in a data-driven way, reducing the risk of overfitting and researcher degrees of freedom.

## Your tasks

1. **Load and explore** — Load the dataset, then use `describe` and `summarize` to get acquainted with the outcome variable `lwage` and the potential predictors: `educ`, `exper`, `tenure`, `iq`, `kww`, `hours`, `age`, `married`, `black`, `south`, `urban`, `sibs`. Confirm that none of these variables have missing values before proceeding.

2. **Run a standard OLS baseline** — Regress `lwage` on all twelve predictors listed in Task 1 using `regress`. Note the R-squared and which coefficients are statistically significant at the 5% level. This is your benchmark model.

3. **Run LASSO** — Use Stata's `lasso linear` command to estimate a LASSO model with `lwage` as the outcome and the same twelve predictors as in Task 2. After estimation, use `lassoselect` (or inspect the output) to identify which variables survive into the selected model. Compare the selected set to the significant predictors from your OLS.

4. **Post-LASSO OLS** — After LASSO has selected a subset of predictors, run a post-LASSO OLS regression using `lassocoef` to retrieve the selected variables, or manually regress `lwage` on only the variables that LASSO retained. Compare the post-LASSO coefficients on `educ` and `iq` to their OLS counterparts from Task 2. Which estimate changes more, and in which direction?

5. *(Bonus)* **Cross-validated LASSO** — Re-run `lasso linear` adding the option `selection(cv)` to choose the penalty parameter λ via 10-fold cross-validation instead of the default BIC. Use `cvplot` to visualise the cross-validation curve. Does the cross-validated model select more or fewer variables than the BIC-selected model from Task 3?
