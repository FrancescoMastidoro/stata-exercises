## Background
The PSID extract contains 4,165 observations tracking 595 individuals over up to 7 time periods, with information on wages, union status, occupation, and demographic characteristics. Difference-in-differences (DiD) is a cornerstone method in labor economics for estimating causal effects when treatment assignment is not random but follows a before/after, treated/control structure.

## Your tasks

1. **Load and declare the panel** — Load `webuse psidextract`, then use `xtset` to declare the panel structure using the individual identifier `id` and time variable `t`. Confirm the panel is balanced or unbalanced by inspecting the output.

2. **Create a treatment indicator** — Define a binary treatment variable called `treated` equal to 1 if a worker is ever observed in a union (`union == 1`) in *any* period, and 0 otherwise. Use `egen` with an appropriate function grouped by `id` to construct this. Then tabulate `treated` to see how many workers are in the treated group.

3. **Define a post-period and estimate a simple DiD** — Create a variable `post` equal to 1 for periods `t >= 4` and 0 otherwise. Then manually construct the four DiD group-period means of `lwage` (treated×post, treated×pre, control×post, control×pre) using `tabstat`, and compute the DiD estimate by hand from those means.

4. **Estimate DiD with a regression** — Run an OLS regression of `lwage` on `treated`, `post`, their interaction `treated#post` (using factor variable notation), and the controls `ed`, `exp`, `blk`, and `fem`. Interpret the coefficient on the interaction term as your DiD estimate and compare it to the manual calculation from Task 3.

5. *(Bonus)* **Add individual fixed effects** — Re-estimate the DiD model using `xtreg, fe` with the same controls, replacing the `treated` main effect (which is now absorbed by fixed effects) with the `post` indicator and the `treated#post` interaction. Explain why the `treated` dummy drops out and what changes in the interaction coefficient relative to Task 4.

- **Hint 1 (Task 2)**: `egen` has a function that computes the maximum value of a variable within groups — if a worker is *ever* in a union, the maximum of `union` across their observations will equal 1. Think about which `egen` function achieves this and how to use `bysort`.

- **Hint 2 (Task 4)**: In Stata, factor variable interactions use the `#` operator — `i.treated#i.post` creates the interaction of two binary variables. You can also write `i.treated##i.post` to include both main effects and the interaction in one expression, which is cleaner than listing them separately.
