## Background
The `regsmpl` dataset is a panel of NLS women observed between 1968 and 1988, containing wages, education, experience, and geographic indicators. Difference-in-differences (DiD) is a cornerstone method in labor economics for estimating causal effects by comparing changes over time across groups that differ in their exposure to some treatment.

## Your tasks

1. **Load and inspect the panel** — Load the dataset, declare it as a panel using `xtset`, and tabulate `year` to understand the time dimension. Report how many distinct individuals (`idcode`) are in the data.

2. **Create a post-period indicator** — Define a binary variable `post` equal to 1 if `year` is 1980 or later, and 0 otherwise. Then create a "treatment" indicator `treated` equal to 1 if `black == 1`, and 0 otherwise. Verify the two variables with `tabulate`.

3. **Construct the DiD interaction term** — Generate an interaction variable `did = treated * post`. Run a pooled OLS regression of `ln_wage` on `treated`, `post`, and `did`. Interpret the coefficient on `did` as the DiD estimate of the wage gap change for Black women after 1980.

4. **Upgrade to a two-way fixed effects (TWFE) model** — Re-estimate the DiD using `xtreg` with individual fixed effects (`fe`) and add `i.year` to absorb time fixed effects. Compare the coefficient on `did` (or equivalently `treated#post`) from this TWFE specification to the pooled OLS result from Task 3, and note whether individual-level unobservables appear to matter.

5. *(Bonus)* **Event-study plot** — Instead of a single post-period dummy, generate a set of year dummies interacted with `treated` (omitting one pre-period year as the reference category). Run the TWFE regression with these interaction terms and plot the coefficients against year using `coefplot` (if installed) or manually using `matrix` commands. Comment on whether the parallel-trends assumption looks plausible in the pre-period.
