## Background
The NLSY 1980 dataset contains cross-sectional data on 935 workers, including wages, education, cognitive ability, and family background, making it a classic setting for wage equation estimation. LASSO (Least Absolute Shrinkage and Selection Operator) is increasingly used in labor economics to select predictors from large covariate sets without relying solely on researcher discretion.

## Your tasks

1. **Load and explore the data** — Load `webuse nlsy80`, then run `describe` and `summarize` to get familiar with the variables. Note which variables have missing values (`brthord`, `meduc`, `feduc`) and which do not. Run a simple OLS regression of `lwage` on `educ`, `exper`, `tenure`, `iq`, and `kww` to establish a baseline.

2. **Run a LASSO regression** — Use `lasso linear` to regress `lwage` on the full set of numeric predictors available without missing values: `educ`, `exper`, `tenure`, `iq`, `kww`, `hours`, `age`, `married`, `black`, `south`, `urban`, `sibs`, `pcollege`, `college`, `fcollege`. Allow Stata to choose the penalty parameter automatically via cross-validation. After fitting, display the selected variables with `lassocoef`.

3. **Inspect the regularization path** — After the LASSO fit, use `lassoknots` to inspect how many variables are active at different values of the penalty parameter λ. Then use `cvplot` to visualize how cross-validation prediction error varies across the λ grid. Describe in a comment what the plot tells you about model complexity.

4. **Post-LASSO OLS estimation** — Use `lasso postestimation` tools to run an OLS regression using only the variables selected by the LASSO. Specifically, after `lasso linear`, type `lassoselect` followed by running `reg lwage` with the selected variables (retrieve them with `` `e(othervars_sel)' `` and `` `e(varslist_sel)' `` or use `coefpath`). Compare the post-LASSO OLS coefficients on `educ` and `iq` to those from your baseline OLS in Task 1. Write a comment explaining what changes and why.

5. *(Bonus)* **Cross-validated LASSO with `cv lasso`** — Re-run the LASSO using `cv lasso linear lwage ...` (same predictors as Task 2) explicitly requesting 10-fold cross-validation with the option `folds(10)`. Compare the λ chosen here against the one stored after Task 2's automatic selection. Then use `plugin lasso linear lwage ...` to run the rigorous (plug-in) λ variant and compare which predictors it retains versus the cross-validated version. Comment on which approach you would prefer for a labor economics paper and why.

- **Hint 1** *(Task 2)*: The `lasso linear` command syntax follows `lasso linear depvar varlist`. After estimation, `lassocoef` displays which variables survived penalization — check the Stata 17+ documentation if `lasso` is not found; it requires Stata 16+.

- **Hint 2** *(Task 3)*: `lassoknots` prints a table of "knots" in the regularization path; look for the column that tells you how many predictors are active. `cvplot` is a post-estimation command that requires no additional arguments.

- **Hint 3** *(Task 4)*: After `lasso linear`, typing `estimates store lasso_est` and then using `coefpath` shows the full path. To run post-LASSO OLS automatically, consider the `lasso postestimation` approach: Stata stores selected variable names in macros accessible via `e()` — type `ereturn list` to see what is available, and look for `e(varlist_sel)`.

- **Hint 4** *(Bonus)*: The `plugin` λ method is theoretically motivated and tends to be more conservative (fewer variables selected) than cross-validation. Think about the bias–variance tradeoff when writing your comment.
