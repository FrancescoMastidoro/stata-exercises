## Background
The PSID extract contains 4,165 observations tracking 595 individuals over 7 periods, with information on wages, occupation, union status, and demographics. Difference-in-differences (DiD) is a cornerstone identification strategy in labor economics, allowing you to estimate causal effects by comparing changes over time between a treated and a control group.

## Your tasks

1. **Explore the panel structure** — Load the dataset, declare it as a panel using `xtset`, and summarize the variables `lwage`, `union`, `south`, and `fem`. Report how many unique individuals (`id`) and time periods (`t`) are in the data.

2. **Define a pseudo-treatment** — Create a binary variable called `treat` equal to 1 if `union == 1` and `fem == 1` (unionized women), and 0 if `union == 0` and `fem == 1` (non-unionized women). Keep only observations where `fem == 1` for the rest of the analysis, and verify the share of treated observations.

3. **Construct a post indicator and compute group means** — Create a binary variable `post` equal to 1 if `t >= 4` and 0 otherwise. Then use `tabstat lwage, by(treat) statistics(mean)` separately for `post == 0` and `post == 1`. Manually compute the DiD estimate from the four group-period means.

4. **Estimate the DiD regression** — Run an OLS regression of `lwage` on `treat`, `post`, and their interaction `treat#post` (or equivalently `c.treat#c.post`). Interpret the coefficient on the interaction term. Then add individual fixed effects using `xtreg, fe` and compare the interaction coefficient to the OLS result.

5. *(Bonus)* **Assess parallel trends visually** — Collapse the data to cell means of `lwage` by `treat` and `t`. Plot both series on the same graph using `twoway line`, and comment on whether the parallel trends assumption appears plausible in the pre-period (`t < 4`).

- **Hint 1 (Task 1)**: Use `xtset id t` to declare the panel. The `xtdescribe` command is useful for checking balance across periods.

- **Hint 2 (Task 2)**: You can use `gen treat = (union == 1)` conditional on `fem == 1`. After keeping only `fem == 1`, double-check with `tab treat` that both groups are populated.

- **Hint 3 (Task 3)**: `tabstat lwage if post == 0, by(treat) stat(mean)` gives you the pre-period means. The DiD estimate is (mean_treated_post − mean_treated_pre) − (mean_control_post − mean_control_pre).

- **Hint 4 (Task 4)**: In `regress`, write `i.treat##i.post` to get main effects and the interaction automatically. For the fixed-effects version, `xtreg lwage i.treat##i.post, fe` absorbs individual-level time-invariant heterogeneity — notice which coefficient changes and think about why.
