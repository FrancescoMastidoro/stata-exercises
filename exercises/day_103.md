## Background
The PSID extract contains 4,165 person-year observations tracking workers across 7 time periods, with information on wages, union status, occupation, and demographics. Difference-in-differences (DiD) is a cornerstone identification strategy in labor economics, exploiting variation in treatment timing across groups to estimate causal effects while controlling for time-invariant unobservables.

## Your tasks

1. **Load and explore the panel structure** — Load `webuse psidextract`, then use `xtset` to declare the panel with `id` as the individual identifier and `t` as the time variable. Confirm the structure by running `xtdescribe` and report how balanced the panel is.

2. **Create a treatment indicator** — Define a DiD treatment group as workers who are unionized (`union == 1`) in period `t == 4` or later. Create a binary variable called `treated` equal to 1 if `union == 1`, and a binary variable called `post` equal to 1 if `t >= 4`. Then create the interaction term `did = treated * post` manually (do not use `##` yet). Tabulate `treated` and `post` separately to verify they have meaningful variation.

3. **Run a basic DiD regression** — Regress `lwage` on `treated`, `post`, and `did` using `regress`. Interpret the coefficient on `did`: what does it estimate, and what assumptions must hold for it to be a valid causal estimate? Also add `south`, `smsa`, and `ed` as controls and note how the DiD coefficient changes.

4. **Extend to two-way fixed effects** — Re-estimate the DiD model using `xtreg, fe` to absorb individual fixed effects, with `post` and `did` as regressors (note: `treated` drops out because it is time-invariant within the individual FE framework). Then add `i.t` to absorb time fixed effects as well. Compare the DiD estimate across the three specifications (pooled OLS, individual FE only, two-way FE).

5. *(Bonus)* **Test the parallel trends assumption visually** — Using `collapse (mean) lwage, by(treated t)`, compute the average log wage by treatment group and period. Then use `twoway (line lwage t if treated==1) (line lwage t if treated==0)` to plot the trends for both groups across all 7 periods. Do the pre-treatment trends (periods 1–3) look parallel? Save the graph as `did_trends.png`.

- **Hint 1 (Task 1)**: After `xtset id t`, the command `xtdescribe` will tell you whether every individual appears in all 7 time periods — a balanced panel has no gaps.
- **Hint 2 (Task 3)**: In a classic 2×2 DiD, the coefficient on the interaction term captures the average treatment effect on the treated (ATT) under parallel trends — think about what each of the three main regressors controls for individually before interpreting the interaction.
- **Hint 3 (Task 4)**: When you include individual fixed effects with `xtreg, fe`, any variable that does not vary over time for a given individual is perfectly collinear with the fixed effects and will be automatically dropped — think carefully about which of your three DiD regressors this applies to.
