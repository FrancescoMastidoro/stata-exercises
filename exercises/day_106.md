**Dataset**: `webuse nlsy80`

## Background
The NLSY 1980 cross-section contains 935 observations on wages, education, cognitive ability, and demographic characteristics for young workers in the United States. LASSO (Least Absolute Shrinkage and Selection Operator) is increasingly used in labor economics to select predictors from a rich covariate set in a data-driven way, avoiding the arbitrary pre-specification of control variables.

## Your tasks

1. **Inspect the data** — Load the dataset, run `describe` and `summarize wage educ iq kww exper tenure age` to familiarize yourself with the variables. Note the range of `wage` (monthly earnings, 115–3,078) and confirm there are no missing values in these variables.

2. **Fit a standard OLS baseline** — Regress `lwage` on `educ`, `iq`, `kww`, `exper`, `tenure`, `age`, `married`, `black`, `south`, and `urban`. Store the results using `estimates store ols_baseline` and note which coefficients are statistically significant at the 5% level.

3. **Run LASSO with `lasso linear`** — Use Stata's `lasso linear` command to predict `lwage` using all ten regressors from Task 2. Let Stata choose the penalty parameter automatically via cross-validation by specifying `selection(cv)`. After estimation, type `lassocoef` to see which variables survive the LASSO shrinkage.

4. **Compare selected variables and refit OLS** — Identify the variables retained by LASSO using `lassoselected` (or read from `lassocoef` output). Then run a post-LASSO OLS regression by regressing `lwage` on only the LASSO-selected variables. Store this as `estimates store postlasso` and use `estimates table ols_baseline postlasso, star` to compare coefficient estimates side by side.

5. *(Bonus)* **Add quadratic and interaction terms, then re-run LASSO** — Generate `exper2 = exper^2`, `tenure2 = tenure^2`, and an interaction term `educ_iq = educ * iq`. Re-run `lasso linear lwage educ iq kww exper exper2 tenure tenure2 age married black south urban educ_iq, selection(cv)`. Discuss in a comment (`//`) whether the richer set of variables changes which predictors survive penalization, and whether the cross-validated MSE improves.

## Hints
<details>
<summary>Click to reveal hints (try first!)</summary>

- **Hint 1 (Task 3)**: The `lasso linear` command syntax follows `lasso linear depvar varlist, selection(...)`. The `selection(cv)` option tells Stata to pick the penalty λ by cross-validation rather than using the default BIC criterion — check `help lasso` for the exact option spelling.

- **Hint 2 (Task 4)**: After `lasso linear`, you can type `lassocoef` to display surviving coefficients, and the macro `e(allvars_sel)` stores the names of selected variables. To quickly refit OLS on just the selected variables you can write `regress lwage \`e(allvars_sel)'` immediately after the LASSO — but be careful to capture the macro *before* running any other estimation command, as `e()` will be overwritten.
