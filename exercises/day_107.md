# Day 107: Difference-in-Differences with Panel Data

**Dataset**: `webuse psidextract`
**Estimated time**: ~25 minutes

## Background
The PSID extract contains 4,165 observations on workers observed across up to 7 time periods, with information on wages, union membership, occupation, industry, and demographics. Difference-in-Differences (DiD) is a cornerstone of modern labor economics, allowing researchers to estimate causal effects by exploiting variation in treatment timing across groups.

## Your tasks

1. **Explore the panel structure** — Load the dataset and declare it as a panel using `xtset`. Confirm the panel identifier and time variable, then use `xtdescribe` to summarize how balanced the panel is across individuals and periods.

2. **Define treatment and control groups** — In this exercise, treat union membership (`union`) as a "treatment." Tabulate `union` by `t` (time period) to examine how union membership varies across periods. Then create a dummy variable called `post` equal to 1 when `t >= 4` and 0 otherwise, which will serve as the post-treatment indicator.

3. **Estimate a basic DiD regression** — Run a pooled OLS regression of `lwage` on `union`, `post`, and their interaction (`union#post` or manually as `c.union#c.post`). Interpret the coefficient on the interaction term as the DiD estimate. Use `vce(cluster, id)` to cluster standard errors at the individual level.

4. **Add individual and time fixed effects** — Re-estimate the model using `xtreg` with the `fe` option to absorb individual fixed effects, controlling also for `exp`, `wks`, `occ`, `ind`, `south`, `smsa`, and `blk`. Add time fixed effects by including `i.t`. Compare the interaction coefficient with the result from task 3 and comment on why the estimate changes.

5. *(Bonus)* **Parallel trends check** — Create a set of period-specific interaction dummies between `union` and each value of `t` (e.g., `union#i.t`). Run a fixed-effects regression of `lwage` on these interactions plus `i.t`, excluding the period just before `post == 1` (i.e., `t == 3`) as the reference category. Plot or tabulate the coefficients to visually assess whether the parallel trends assumption holds in the pre-treatment periods (`t < 4`).

- **Hint 1 (Task 1)**: The panel is structured with `id` as the individual identifier and `t` as the time variable — pass both to `xtset` in that order before running any `xt` commands.
- **Hint 2 (Task 3)**: You can create the interaction manually with `gen union_post = union * post` and include it alongside the two main effects, or use Stata's factor-variable notation `c.union#c.post` directly in the regression formula.
- **Hint 3 (Task 4)**: With `xtreg, fe`, Stata automatically demeans by individual, so you do not need to include individual dummies manually — just add `i.t` to capture time fixed effects on top of the individual fixed effects.
- **Hint 4 (Task 5)**: Set the reference period with `ib3.t` in the factor-variable interaction so that `t == 3` (the last pre-treatment period) is the omitted category, making it easy to judge whether pre-trends are flat.
