## Background
The NLSY 1980 dataset contains cross-sectional information on wages, education, cognitive ability, and family background for nearly 1,000 workers, making it a natural playground for wage equation research. LASSO (Least Absolute Shrinkage and Selection Operator) is increasingly used in labor economics to select predictors from large covariate sets in a data-driven, principled way — reducing the risk of ad hoc model specification.

## Your tasks

1. **Load and inspect** — Load the dataset with `webuse nlsy80`. List all variable names and their types with `describe`. Note which variables have missing values (`brthord`, `meduc`, `feduc`) and which do not. Display summary statistics for `lwage`, `educ`, `iq`, `exper`, and `tenure`.

2. **Run a standard OLS baseline** — Regress `lwage` on `educ`, `exper`, `tenure`, `iq`, `kww`, `age`, `married`, `black`, `south`, `urban`, and `sibs`. Store the results with `estimates store ols_baseline`. Note the coefficient on `educ` and the R².

3. **Run LASSO with cross-validation** — Use `lasso linear lwage educ exper tenure iq kww age married black south urban sibs` to let Stata select the penalization parameter via cross-validation (the default). After the command finishes, display the selected variables with `lassocoef` and compare the retained predictors to your OLS model.

4. **Post-LASSO OLS** — Use `lasso linear lwage educ exper tenure iq kww age married black south urban sibs` followed by `lassoselect` to identify the chosen lambda, then run a standard OLS regression using only the variables that LASSO retained (those with non-zero coefficients). Compare the `educ` coefficient and R² with your baseline OLS from Task 2. Does LASSO shrink the set of predictors relative to OLS?

5. *(Bonus)* **Handle missing values and expand the candidate set** — Drop observations where `brthord`, `meduc`, or `feduc` are missing (use `drop if missing(...)`). Then rerun the LASSO from Task 3 but add `brthord`, `meduc`, `feduc`, `hours`, `pcollege`, `college`, and `fcollege` to the predictor list. Use `lassocoef, display(coef, penalized)` to inspect shrinkage. Does including family background variables change which core variables survive?

## Hints

- **Hint 1 (Task 3)**: The `lasso linear` command in Stata 16+ performs cross-validated LASSO by default. After running it, `lassocoef` (with no options) prints the coefficients at the selected lambda — a zero coefficient means that variable was excluded by LASSO's penalty.

- **Hint 2 (Task 4)**: To run the post-LASSO OLS cleanly, you can use `lassocoef, nopenalized` to see which variables had non-zero coefficients, then manually include those in a `regress` command. Alternatively, `lasso linear ..., postselection` followed by `regress` with `, vce(robust)` lets you assess standard errors after selection.
