## Background
The Grunfeld dataset tracks investment, market value, and capital stock for 10 large US firms across 20 years (1935–1954), making it a classic panel for studying firm-level investment behaviour. Difference-in-differences (DiD) designs exploit variation across groups and time to estimate causal effects, a workhorse method in modern labour and corporate economics.

## Your tasks

1. **Load and explore the panel structure** — Load the dataset, then use `xtset` to declare the panel structure with `company` as the unit and `year` as the time variable. Confirm the setup by typing `xtdescribe` and note how many firms and time periods are present.

2. **Create a treatment indicator** — Define a binary variable called `treated` equal to 1 for companies with `company` ≤ 5 (the "treated group") and 0 otherwise. Then create a binary `post` variable equal to 1 for years 1945 and later, and 0 for years before 1945. Verify both variables with `tabulate`.

3. **Compute group-time means manually** — Using `egen`, compute the mean of `invest` for each combination of `treated` and `post`. Store these as a new variable called `mean_invest`. Then use `tabulate treated post, summarize(invest)` to display a 2×2 table of average investment. Calculate the DiD estimate by hand from the four cell means and store it in a local macro.

4. **Estimate the DiD regression** — Run an OLS regression of `invest` on `treated`, `post`, and their interaction (`treated × post`). The coefficient on the interaction term is your DiD estimate. Then re-run the regression adding `mvalue` and `kstock` as controls. Compare the interaction coefficient across the two specifications using `estimates store` and `esttab` (or `estimates table`).

5. *(Bonus)* **Add firm and year fixed effects** — Re-estimate the DiD model using `xtreg, fe` to absorb firm fixed effects, and include year dummies using `i.year`. Compare this two-way fixed effects estimate of the interaction term to the estimate from Task 4. Discuss briefly in a comment why the TWFE estimate may differ from the simple DiD.

## Hints

<summary>Click to reveal hints (try first!)</summary>

- **Hint 1 (Task 2)**: To create binary indicators based on conditions, try `generate treated = (company <= 5)` — Stata evaluates the logical expression and assigns 1 if true, 0 if false. Do the same pattern for `post` using a threshold on `year`.

- **Hint 2 (Task 3)**: `egen mean_invest = mean(invest), by(treated post)` will assign the group-time mean to every observation in that cell. To compute the DiD by hand, recall the formula: (mean_treated_post − mean_treated_pre) − (mean_control_post − mean_control_pre). You can extract scalar values with `summarize invest if treated==1 & post==1` and read `r(mean)`.

- **Hint 3 (Task 4)**: The interaction term in Stata regression syntax is written as `c.treated#c.post` for continuous variables, but since both are binary you can also use `treated##post` with factor-variable notation — this automatically includes the main effects and the interaction. Check `help fvvarlist` if unsure.

- **Hint 4 (Task 5)**: `xtreg invest i.year c.treated#c.post, fe` absorbs firm fixed effects via the within transformation. Note that `treated` alone is collinear with firm fixed effects (it is time-invariant within a firm), so Stata will drop it — this is expected behaviour, not an error.
