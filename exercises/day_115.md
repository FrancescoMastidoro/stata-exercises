## Background
The NLSY 1980 dataset contains cross-sectional data on 935 workers, including wages, education, cognitive scores, and family background variables — a classic setup for wage equation estimation. LASSO (Least Absolute Shrinkage and Selection Operator) is increasingly used in labor economics to perform data-driven variable selection when the set of potential predictors is large relative to the sample size.

## Your tasks

1. **Load and explore** — Load the dataset with `webuse nlsy80`. Use `describe` and `summarize` to familiarise yourself with the variables. Then run a standard OLS regression of `lwage` on `educ`, `exper`, `tenure`, `iq`, `kww`, `age`, `married`, `black`, `south`, `urban`, and `sibs`. Note the coefficient on `educ` and the R².

2. **Run a LASSO regression** — Use Stata's `lasso linear` command to regress `lwage` on the same set of predictors listed in Task 1. Use the default cross-validation method for penalty selection (no extra options needed). After the command, type `lassoinfo` and report which variables were selected and which were shrunk to zero.

3. **Post-selection OLS** — After the LASSO, run `lasso linear` again but this time add the option `selection(cv)` explicitly, then use `lassocoef` to display the selected coefficients. Next, run a post-selection OLS using `estimates store` logic: type `lasso postselection` (or use the appropriate post-LASSO command) to obtain the unpenalised OLS estimates on the LASSO-selected variables. Compare the coefficient on `educ` to what you found in Task 1.

4. **Add interaction terms as candidates** — Now expand the candidate variable list. Create two new variables: `exp_educ = exper * educ` and `iq_educ = iq * educ`. Re-run `lasso linear` with `lwage` as the outcome and the original predictors *plus* `exp_educ` and `iq_educ` as additional candidates. Does LASSO select either interaction? Interpret what this implies about wage returns.

5. *(Bonus)* **Cross-validation plot and penalty choice** — After running any `lasso linear` model, use `cvplot` to display the cross-validation function against the log penalty parameter λ. Identify the λ that minimises the CV mean squared error versus the λ chosen by the "one standard error" rule (the default). Re-run `lasso linear` with `selection(cv, serule(0))` to force the minimum-CV choice and compare the number of selected variables to the default run. Why might a researcher prefer the more conservative (one SE) rule?

- **Hint 1 (Tasks 2–3)**: The LASSO command in Stata follows the syntax `lasso linear depvar varlist`. After fitting, `lassoinfo` summarises the selected model, and `lasso postselection` re-estimates OLS using only the variables LASSO retained — this two-step procedure is sometimes called "post-double selection OLS."

- **Hint 2 (Task 4)**: You can generate the interaction variables with `gen exp_educ = exper * educ` before calling `lasso linear`. Simply include the new variable names in the varlist — LASSO treats them like any other candidate predictor and decides whether their coefficients should be non-zero.
