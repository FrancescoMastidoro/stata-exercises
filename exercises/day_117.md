# Day 117: Difference-in-Differences with Panel Data

**Dataset**: `webuse grunfeld`
**Estimated time**: ~25 minutes
**Difficulty**: ⬛⬛⬛⬛⬜

## Background
The Grunfeld dataset contains firm-level investment, market value, and capital stock data for 10 large US companies observed annually from 1935 to 1954. Difference-in-differences (DiD) is a cornerstone of modern causal inference in labor and industrial economics, allowing researchers to estimate treatment effects by comparing changes over time across treated and untreated groups.

## Your tasks

1. **Load and explore the panel structure** — Load the dataset, then use `xtset` to declare the panel structure with `company` as the panel variable and `year` as the time variable. Run `xtdescribe` to confirm the panel is strongly balanced.

2. **Create a treatment indicator** — Define a binary variable `treated` equal to 1 for companies with `company` number greater than 5 (your "treated" group), and 0 otherwise. Then create a `post` indicator equal to 1 for years 1945 and later, and 0 for years before 1945. Print a frequency table of each variable using `tabulate`.

3. **Construct the interaction term and run a basic DiD regression** — Create the interaction variable `did = treated * post`. Regress `invest` on `treated`, `post`, and `did` using `regress`. Identify and interpret the coefficient on `did`: what does it represent in a DiD framework?

4. **Improve the specification with two-way fixed effects** — Instead of manually including `treated` and `post`, use `xtreg` with the `fe` option to absorb company fixed effects, and add `i.year` to control for time fixed effects. Include `post`, `did`, and `mvalue` as regressors. Compare the DiD estimate to the one from Task 3 — does controlling for firm fixed effects and market value change the result meaningfully?

5. *(Bonus)* **Test the common trends assumption graphically** — Using `collapse`, compute the mean of `invest` by `company` group (treated vs. untreated) and `year`. Then use `twoway` to plot both group means over time on the same graph. Do investment trends for the two groups look parallel in the pre-1945 period?

## Hints
<details>
<summary>Click to reveal hints (try first!)</summary>

- **Hint 1 (Task 1)**: After `webuse grunfeld`, the command `xtset company year` declares the panel. `xtdescribe` will show you whether every company-year cell is observed — look for the word "balanced" or check that gaps equal zero.

- **Hint 2 (Task 3)**: In a canonical DiD setup, the coefficient on the interaction term `did` captures the average treatment effect on the treated (ATT) — it measures how much more (or less) the treated group's outcome changed after the treatment period, relative to the control group's change. Think about what the `treated` and `post` coefficients represent on their own.

- **Hint 3 (Task 4)**: With `xtreg, fe`, Stata automatically absorbs the company-level fixed effect, so you no longer need `treated` as a separate regressor (it is collinear with the firm fixed effect). To add year fixed effects, include `i.year` in the regressor list alongside `post`, `did`, and `mvalue`.

- **Hint 4 (Task 5)**: Use `gen treated_group = (company > 5)` before collapsing. In `collapse (mean) invest, by(treated_group year)` you reduce the data to group-year means. For the plot, `twoway (line invest year if treated_group==0) (line invest year if treated_group==1)` is a useful starting template.
