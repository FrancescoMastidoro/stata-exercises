## Background
The `regsmpl` dataset is a panel of NLS women observed from 1968 to 1988, containing wages, education, and labor market characteristics across multiple time periods. Difference-in-differences (DiD) is a cornerstone identification strategy in labor economics, allowing researchers to estimate causal effects by comparing changes over time between treated and untreated groups.

## Your tasks

1. **Load and explore the panel** — Load the dataset with `webuse regsmpl`. Declare the panel structure using `xtset` with `idcode` as the individual identifier and `year` as the time variable. Then tabulate `year` to see how many observations fall in each survey year, and report the range of `ln_wage`.

2. **Define a treatment indicator** — Create a binary variable `post` equal to 1 if `year >= 78` (post-1978) and 0 otherwise. Then create a binary variable `treated` equal to 1 if `black == 1` and 0 otherwise. Tabulate both new variables to verify they look sensible.

3. **Construct the DiD interaction term** — Generate a variable `did` as the product of `post` and `treated`. This interaction term is the DiD estimator. Then run a pooled OLS regression of `ln_wage` on `treated`, `post`, and `did`, reporting the coefficient on `did` and its interpretation.

4. **Control for individual characteristics and fixed effects** — Re-run the regression from Task 3, but now add `ttl_exp`, `grade`, `south`, and `not_smsa` as controls, and include `year` fixed effects using `i.year`. Use `vce(cluster idcode)` for standard errors clustered at the individual level. Compare the DiD coefficient to the simpler estimate from Task 3.

5. *(Bonus)* **Two-way fixed effects DiD** — Use `xtreg ln_wage post##treated ttl_exp i.year, fe vce(cluster idcode)` to estimate a two-way fixed effects version of the DiD (individual FE + year FE). Note that individual fixed effects will absorb the time-invariant `treated` variable — explain in a code comment why `treated` drops out and what the `post##treated` interaction still captures. Compare this coefficient to Task 4.

- **Hint 1 (Task 1)**: After `webuse regsmpl`, use `xtset idcode year` to declare the panel. Then `tab year` and `sum ln_wage` will give you what you need — recall from the reference that `ln_wage` has no missing values and ranges from 0 to 5.26.

- **Hint 2 (Task 3)**: The DiD interaction can be generated as `gen did = post * treated`. In the regression `regress ln_wage treated post did`, the coefficient on `did` represents the average differential change in log wages for black women after 1978, relative to non-black women — this is your causal estimate under the parallel trends assumption.

- **Hint 3 (Task 4)**: When adding `i.year` as year fixed effects in `regress`, Stata will automatically create dummies for each year. Remember that `grade` has 2 missing values and `not_smsa` has 8 missing values according to the reference, so your estimation sample will be slightly smaller — check with `e(N)` after the regression.

- **Hint 4 (Bonus)**: In `xtreg` with the `fe` option, all time-invariant variables are swept out by the within-transformation. Since `treated` (i.e., `black`) never changes for an individual across years, it is collinear with the individual fixed effects and drops. The interaction `post#treated` identifies the DiD coefficient because it varies both across individuals and over time.
