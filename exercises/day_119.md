# Day 119: LASSO for Variable Selection in Labor Economics

**Dataset**: `webuse nlsy80`

## Background
The NLSY 1980 dataset contains cross-sectional data on 935 workers, including wages, cognitive ability scores, education, experience, and family background variables — a classic setting for earnings regressions. LASSO (Least Absolute Shrinkage and Selection Operator) is increasingly used in empirical labor economics to select predictors in high-dimensional settings, helping researchers avoid ad-hoc variable inclusion decisions.

## Your tasks

1. **Load and explore** — Load `webuse nlsy80`. Use `describe` and `summarize` to get acquainted with the dataset. Identify which variables have missing values (`brthord`, `meduc`, `feduc`) and note the outcome variable `lwage` (log monthly earnings). How many complete observations are there once you drop all rows with any missing value across `brthord`, `meduc`, and `feduc`?

2. **OLS benchmark** — Run an OLS regression of `lwage` on `educ`, `exper`, `tenure`, `iq`, `kww`, `age`, `married`, `black`, `south`, `urban`, `sibs`, `brthord`, `meduc`, and `feduc`, using only complete cases (restrict the sample by adding `if !missing(brthord, meduc, feduc)` to your regression). Record the coefficient on `educ` and the R².

3. **Run LASSO** — Using the same sample restriction and the same set of predictors, run a LASSO regression of `lwage` on all the predictors listed in Task 2 using Stata's `lasso linear` command. After the estimation, use `lassocoef` to display which variables were retained and what coefficients were selected. Which variables did LASSO shrink to zero?

4. **Post-LASSO OLS** — After running LASSO, use the `lassoselect` and `coefpath` workflow — or simply re-run OLS manually using only the variables that LASSO retained — to obtain a "post-LASSO OLS" estimate. Compare the coefficient on `educ` (if retained) to the full OLS from Task 2. Does restricting to LASSO-selected variables change the education return?

5. *(Bonus)* **Cross-validated LASSO** — Re-run `lasso linear` with the option `rseed(42)` and use cross-validation to select the penalty parameter (Stata's default uses cross-validation automatically; explore how `lasso linear, selection(cv) folds(10)` differs from the default `selection(plugin)`). Use `cvplot` to visualize the cross-validation curve and report whether the set of selected variables changes relative to Task 3.
