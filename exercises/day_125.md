## Background
The NLSY 1980 dataset contains cross-sectional information on wages, education, cognitive ability, and family background for 935 workers, making it a classic laboratory for wage equation research. LASSO (Least Absolute Shrinkage and Selection Operator) is increasingly used in labor economics to perform principled variable selection when the number of candidate regressors is large relative to the signal in the data.

## Your tasks

1. **Explore the outcome and candidate predictors** — Load the dataset and summarize `lwage` alongside the following candidate regressors: `educ`, `exper`, `tenure`, `iq`, `kww`, `hours`, `age`, `married`, `black`, `south`, `urban`, `sibs`. Report how many observations are available (remember: `brthord`, `meduc`, and `feduc` have missing values — avoid them here to keep the sample clean).

2. **Run a standard OLS benchmark** — Regress `lwage` on all twelve candidate regressors listed in Task 1 using `regress`. Note the R², the number of observations used, and which coefficients are statistically significant at the 5% level. This will serve as the benchmark for comparison.

3. **Fit a LASSO model** — Use Stata's `lasso linear` command to fit a LASSO regression of `lwage` on the same twelve predictors. Allow Stata to choose the penalty parameter λ via cross-validation by specifying `selection(cv)`. Display the selected model with `lassocoef` and note which variables survive the shrinkage.

4. **Compare OLS and LASSO coefficient paths** — After `lasso linear`, use `lassoknots` to display the knot table showing how variables enter the model as λ decreases. Then run a post-LASSO OLS regression using `lasso postselection` (or equivalently, retrieve the selected variables with `lassoselect` and re-estimate with `regress`) and compare its coefficients and R² to your Task 2 OLS benchmark. Discuss briefly: did LASSO drop any variable that OLS found significant?

5. *(Bonus)* **Cross-validated MSE plot and alternative selection rule** — Re-run `lasso linear` but this time compare two selection rules side by side: `selection(cv)` and `selection(adaptive)`. Use `cvplot` after the CV model to visualize the mean squared error across λ values. Do the two rules select the same set of variables? Comment on any differences in terms of parsimony versus in-sample fit.

- **Hint 1 (Task 3)**: The syntax for Stata's built-in LASSO is `lasso linear depvar varlist, selection(cv)` — this requires Stata 16 or later. After estimation, `lassocoef` displays which predictors were retained with their shrunk coefficients, and `, display(coef)` controls what is shown.

- **Hint 2 (Task 4)**: To run post-LASSO OLS, type `lasso postselection` immediately after the LASSO estimation, or use `lassoselect` to store the selected variable list and then feed it manually into `regress`. Pay attention to whether the R² rises, falls, or stays similar relative to the full OLS — a large drop would suggest the shrunk model is missing important variance.
