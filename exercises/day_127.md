# Day 127: Difference-in-Differences with Panel Data

**Dataset**: `webuse psidextract`
**Estimated time**: ~25 minutes

## Background
The PSID extract contains 4,165 observations tracking 595 individuals over 7 time periods, with information on wages, employment conditions, demographics, and union status. Difference-in-differences (DiD) designs are central to modern labor economics, allowing researchers to estimate causal effects by comparing changes in outcomes across groups over time — making this panel a natural sandbox for practicing the technique.

## Your tasks

1. **Load and inspect the panel** — Load the dataset, then declare it as a panel using `xtset` with `id` as the panel identifier and `t` as the time variable. Verify the structure by running `xtdescribe` and report how balanced the panel is.

2. **Define treatment and post indicators** — In this dataset, `union` equals 1 if the worker is covered by a union contract. Create a binary variable called `post` that equals 1 for time periods `t >= 4` and 0 otherwise. Then create a DiD interaction term called `union_post` as the product of `union` and `post`. Tabulate `union` and `post` jointly to confirm the cell counts look reasonable.

3. **Run a basic DiD regression** — Regress `lwage` on `union`, `post`, and `union_post` using `regress`. Interpret the coefficient on `union_post` as the DiD estimate: what does it say about the effect of union coverage in the post period? Also note the coefficient on `union` and `post` separately.

4. **Add individual fixed effects and cluster standard errors** — Re-estimate the DiD model using `xtreg, fe`, which absorbs individual fixed effects, and cluster standard errors at the `id` level using `vce(cluster id)`. Include `post` and `union_post` as regressors (the `union` main effect is absorbed by fixed effects). Compare the DiD coefficient and its standard error to the estimate from Task 3 — does accounting for individual heterogeneity change the conclusion?

5. *(Bonus)* **Assess parallel trends visually** — Restrict the sample to `t <= 3` (the pre-period only). Within this window, regress `lwage` on `union`, a full set of time dummies (`i.t`), and the interaction `union#i.t` using OLS. If the parallel trends assumption holds, the interaction coefficients should be jointly insignificant. Run an `F`-test using `testparm` on the interaction terms and comment on what you find.

- **Hint 1 (Task 1)**: After `webuse psidextract`, the command `xtset id t` declares the panel. `xtdescribe` then summarises how many individuals appear in how many periods — a perfectly balanced panel means every individual appears in all 7 periods.

- **Hint 2 (Task 2)**: Use `generate post = (t >= 4)` to create the binary post indicator. The interaction term can be created with `generate union_post = union * post`. Remember that both `union` and `post` are 0/1 variables, so their product is also 0/1.

- **Hint 3 (Task 3)**: The DiD estimator in a two-way table is: (mean outcome for treated post) − (mean outcome for treated pre) − [(mean outcome for control post) − (mean outcome for control pre)]. The `union_post` regression coefficient gives you exactly this quantity under OLS.

- **Hint 4 (Task 4)**: With `xtreg lwage post union_post, fe vce(cluster id)`, the `union` main effect drops out because it is time-invariant at the individual level and is absorbed by the fixed effect. Compare the `union_post` coefficient here to Task 3 — fixed effects remove omitted variable bias from stable individual characteristics.

- **Hint 5 (Bonus)**: After restricting to `t <= 3` with `if t <= 3`, run `regress lwage union i.t union#i.t`. Then use `testparm union#i.t` to jointly test whether the pre-period interaction terms are zero — a large p-value supports the parallel trends assumption.
