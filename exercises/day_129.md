## Background
The Mroz 1987 PSID dataset is a classic labor economics resource containing detailed information on 753 married women's labor supply decisions, wages, and household characteristics. LASSO (Least Absolute Shrinkage and Selection Operator) is a powerful regularization method that automatically selects relevant predictors from a large candidate set — an increasingly important skill in empirical economics where researchers face high-dimensional covariate spaces.

## Your tasks

1. **Load and explore the candidate predictors** — Load `webuse mroz87`. Among women who participated in the labor force (`lfp == 1`), summarize the following potential wage determinants: `wedyrs`, `wexper`, `husage`, `hedyrs`, `kl6`, `k618`, `mtr`, `unemprt`, `smsa`. Report how many observations have non-missing `wwage76` among working women.

2. **Estimate a standard OLS baseline** — Restrict your sample to women who participated in the labor force (`lfp == 1`). Regress `wwage76` (wife's 1976 hourly wage) on the nine predictors listed in Task 1 using OLS. Note the R-squared and which coefficients are statistically significant at the 5% level.

3. **Run a LASSO regression** — Using the same sample and outcome variable as Task 2, run `lasso linear wwage76` with the same nine predictors. After estimation, display the selected variables using `lassocoef` and count how many predictors LASSO retains compared to the nine you started with.

4. **Select the penalty parameter and compare coefficients** — Use `cvlasso` (or `lasso linear` with `selection(cv)`) to choose the optimal penalty via cross-validation. Then run `lassocoef, display(coef, penalized)` to view the post-LASSO coefficients. Compare which variables survive LASSO selection against the OLS significant predictors from Task 2 — do the two methods agree on the important regressors?

5. *(Bonus)* **Post-LASSO OLS inference** — After LASSO selects a subset of variables, use `lasso postselection ols` (or manually run OLS on only the LASSO-selected variables) to obtain unpenalized OLS estimates on the selected model. Discuss in a comment why running OLS after LASSO — rather than reading coefficients directly from LASSO — gives better-calibrated standard errors for inference.
