## Background
The NLSY 1980 cross-section contains 935 observations on wages, education, cognitive ability, and demographic characteristics for a cohort of American workers. LASSO (Least Absolute Shrinkage and Selection Operator) is increasingly used in labor economics to select predictors from a rich set of covariates without overfitting, making it a valuable complement to traditional OLS.

## Your tasks

1. **Load and explore the data** — Load `webuse nlsy80`, then summarize the variables `lwage`, `educ`, `iq`, `kww`, `exper`, `tenure`, `married`, `black`, `south`, `urban`, and `sibs`. Note the ranges and confirm there are no missing values in these variables before proceeding.

2. **Run a standard OLS benchmark** — Regress `lwage` on the full set of predictors listed in Task 1 (excluding `lwage` itself and any raw wage variable). Store the results and note which coefficients are statistically significant at the 5% level.

3. **Run LASSO with default settings** — Use `lasso linear lwage` with the same predictor set as in Task 2. Allow Stata to choose the penalty parameter (λ) automatically via cross-validation. After the LASSO runs, display the selected variables using `lassocoef`.

4. **Compare OLS and LASSO selections** — Use `lasso linear lwage` again, but this time add the option `selection(cv, folds(10))` to perform 10-fold cross-validation explicitly. Then run a post-LASSO OLS regression using only the variables LASSO selected (use `lassoselect` followed by `lasso postselection`). Compare the post-LASSO OLS coefficients to your benchmark OLS from Task 2 — which predictors survived selection, and do the coefficient magnitudes change meaningfully?

5. *(Bonus)* **Penalized estimation with a manual lambda grid** — Use `lasso linear lwage (educ iq kww exper tenure married black south urban sibs), grid(50)` to evaluate 50 values of λ. Then use `cvplot` to visualize the cross-validation error as a function of log(λ). Interpret where the optimal λ sits on the regularization path: is the model closer to OLS (small penalty) or a heavily shrunken solution?
