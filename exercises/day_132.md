## Background
The Grunfeld dataset contains firm-level investment panel data for 10 US companies observed annually from 1935 to 1954, making it a classic benchmark for panel econometrics. Difference-in-differences (DiD) is one of the most widely used quasi-experimental methods in labor and industrial economics, allowing researchers to estimate causal effects by comparing treated and control groups before and after an intervention.

## Your tasks

1. **Load and explore** — Load the dataset with `webuse grunfeld`. Declare the panel structure using `xtset`, then use `xtdescribe` to confirm that the panel is strongly balanced (every company observed in every year).

2. **Create a treatment indicator** — Suppose a hypothetical policy was introduced in 1945 that affected only companies 1–5 (the "treated" group). Create a binary variable `treated` equal to 1 for companies 1–5 and 0 otherwise. Then create a binary variable `post` equal to 1 for years 1945 and later, and 0 for years before 1945.

3. **Compute group-period means** — Using `collapse` (or `tabstat`), compute the mean of `invest` separately for the four DiD cells: (treated × pre), (treated × post), (control × pre), (control × post). Report these four means and manually compute the DiD estimate: (treated post − treated pre) − (control post − control pre).

4. **Estimate the DiD regression** — Run a two-way fixed-effects DiD regression of `invest` on the interaction `treated#post`, controlling for company fixed effects (`i.company`) and year fixed effects (`i.year`). Interpret the coefficient on the interaction term and compare it to your manual calculation from Task 3. Why do the two estimates differ once fixed effects are included?

5. *(Bonus)* **Event-study plot** — Instead of a single post dummy, create a set of year-relative-to-treatment dummies (e.g., `rtime = year - 1945`) and interact each with `treated`. Run this event-study regression using `i.rtime#treated` (omitting the reference year, e.g., 1944), and use `coefplot` (if installed) to visualise the pre-trends and post-treatment dynamics. What would a flat pre-trend look like, and why does it matter for DiD validity?

- **Hint 1** (Task 2): To create `treated`, think about using `gen treated = (company <= 5)` — Stata evaluates the Boolean expression in parentheses as 1 if true and 0 if false. The same logic applies to `post`.

- **Hint 2** (Task 3): `tabstat invest, by()` only allows one grouping variable. Consider using `gen cell = treated*10 + post` to create a four-category grouping variable, or use `collapse` on a copy of the data (remember to `preserve` and `restore` so you don't lose the original).

- **Hint 3** (Task 4): In Stata factor-variable notation, `treated#post` gives you the interaction. Since `treated` is a continuous 0/1 variable you created (not declared with `i.`), write the interaction as `c.treated#c.post` or simply include `treated`, `post`, and `treated_post` (their product) as separate variables. Company and year FE are absorbed with `i.company i.year`.

- **Hint 4** (Task 5): Create `gen rtime = year - 1945` so that rtime = 0 corresponds to the treatment year. Use `xi` or factor notation carefully, and omit the rtime = -1 category (the year just before treatment) as your baseline by specifying `ib(-1).rtime` in the interaction.
