## Background
The `regsmpl` dataset is a panel of NLS women observed across survey years from 1968 to 1988, containing wages, education, experience, and geographic indicators. Difference-in-differences (DiD) is a cornerstone method in labor economics for estimating causal effects of policy changes by comparing treated and control groups before and after a treatment event.

## Your tasks

1. **Load and inspect the panel structure** — Load the dataset with `webuse regsmpl`. Declare the panel structure using `xtset` with `idcode` as the individual identifier and `year` as the time variable. Then use `xtdescribe` to verify how balanced the panel is across years.

2. **Create a treatment indicator** — Define a binary variable called `treated` equal to 1 if a woman is `black`, and 0 otherwise. Then define a binary `post` variable equal to 1 if `year` is greater than or equal to 78 (i.e., 1978 onward), and 0 otherwise. Tabulate both variables to confirm their distributions.

3. **Construct the DiD interaction term and run the baseline regression** — Generate an interaction variable `did = treated * post`. Regress `ln_wage` on `treated`, `post`, and `did`. Report and interpret the coefficient on `did`: what does it represent in a DiD framework?

4. **Add controls and fixed effects** — Re-run the DiD regression adding `ttl_exp`, `grade`, and `tenure` as controls (note: `grade`, `tenure` have missing values — use `if e(sample)` carefully). Also add individual fixed effects using `xtreg, fe` instead of `regress`. Compare the coefficient on `did` between the two specifications and briefly note what changes.

5. *(Bonus)* **Event-study plot** — Instead of a single `post` dummy, generate a set of year dummies relative to 1978 (the "event year") and interact each with `treated`. Run an `xtreg, fe` regression with these interaction terms (omitting the year immediately before 1978 as the reference). Use `coefplot` (if installed) or manually extract coefficients with `lincom` for two pre- and two post-event years to assess whether pre-trends exist between Black and non-Black women.

- **Hint 1 (Tasks 2–3)**: The DiD estimator is the coefficient on the interaction of `treated` and `post`. When you generate `did = treated * post`, make sure both component variables are numeric 0/1 before multiplying — check with `tab treated` and `tab post` first.
- **Hint 2 (Task 4)**: `xtreg ln_wage treated post did ttl_exp grade tenure, fe` absorbs individual fixed effects. Because `treated` is time-invariant (a woman's race does not change), it will be dropped automatically by the within-transformation — this is expected and tells you something important about identification in a two-way FE model.
