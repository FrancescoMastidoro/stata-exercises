## Background
The NLSY 1980 dataset contains a rich cross-section of 935 workers with earnings, cognitive test scores, education, and demographic characteristics — exactly the kind of high-dimensional setting where LASSO shines. LASSO (Least Absolute Shrinkage and Selection Operator) is increasingly used in labor economics to select controls from a large covariate set before estimating a causal effect, following the "double-selection" approach of Belloni, Chernozhukov, and Hansen.

## Your tasks

1. **Explore the outcome and candidate regressors** — Load the dataset and summarize `lwage`, `educ`, `exper`, `tenure`, `iq`, `kww`, `hours`, `age`, `sibs`, `married`, `black`, `south`, and `urban`. Report the number of observations, means, and standard deviations. Note which variables are binary and which are continuous.

2. **Run a baseline OLS regression** — Regress `lwage` on `educ`, `exper`, `tenure`, `iq`, `kww`, `hours`, `age`, `married`, `black`, `south`, and `urban`. Report the coefficient on `educ` and its standard error. This is your benchmark.

3. **Run a LASSO regression for prediction** — Use Stata's `lasso linear` command to regress `lwage` on the same set of regressors as Task 2. Display the selected variables using `lassocoef` and note which regressors LASSO retains and which it shrinks to zero.

4. **Post-LASSO OLS and compare** — After the `lasso linear` estimation, use `lasso linear` with the `selection(cv)` option (cross-validated lambda) to select variables, then run an OLS regression using only the LASSO-selected variables by combining `lasso linear` with `lassoknots` or by manually running `regress` on the selected set. Compare the coefficient on `educ` to the OLS benchmark from Task 2 — does variable selection change the estimated return to education?

5. *(Bonus)* **Double-selection LASSO for causal inference** — Use `dsregress` to estimate the effect of `educ` on `lwage`, controlling for `exper`, `tenure`, `iq`, `kww`, `hours`, `age`, `married`, `black`, `south`, and `urban` as potential controls. Compare the `dsregress` coefficient and confidence interval on `educ` to both your baseline OLS (Task 2) and your post-LASSO OLS (Task 4). Explain in a comment why double-selection provides better inferential guarantees than simply running OLS on LASSO-selected variables.

## Hints
<details>
<summary>Click to reveal hints (try first!)</summary>

- **Hint 1 (Task 3)**: The syntax for LASSO in Stata is `lasso linear depvar varlist`. After estimation, `lassocoef` displays non-zero coefficients. Look at the Stata 16+ documentation for `lasso` — it lives under the `elasticnet` suite. The default selection criterion is the plugin estimator; try `lasso linear lwage educ exper ... , selection(plugin)` first.

- **Hint 2 (Task 4)**: After `lasso linear` with `selection(cv)`, you can retrieve the selected variables programmatically. The macro `e(allvars_sel)` or the command `lassoselected` (depending on your Stata version) stores the selected variable names. You can then pass these directly to `regress`. Check `` `e(varlist_sel)' `` inside a local macro.

- **Hint 3 (Bonus)**: The `dsregress` command syntax is `dsregress depvar treatvar, controls(varlist)`. It runs two LASSO regressions internally — one for the outcome and one for the treatment — and takes the union of selected controls before running the final OLS. This "double-selection" avoids omitted variable bias that can arise if LASSO drops a control that affects the treatment but not enough of the outcome to survive a single penalised regression.
