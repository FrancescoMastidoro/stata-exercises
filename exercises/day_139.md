## Background
The `laborsup` dataset contains 500 observations on female labor supply, including women's income, education, and fertility variables. Instrumental variables (IV) estimation is a cornerstone technique in labor economics for recovering causal effects when a key regressor is endogenous — here, we explore whether `kids` can be instrumented to identify its effect on female income.

## Your tasks

1. **Explore the data** — Load the dataset, run `describe` and `summarize`, and confirm the ranges of `fem_inc`, `kids`, `fem_educ`, and `male_educ`. Note which variables are binary and which are continuous.

2. **OLS benchmark** — Regress `fem_inc` on `kids` and `fem_educ` using OLS. Report the coefficient on `kids` and briefly interpret its sign and magnitude in a comment.

3. **First-stage regression** — Regress `kids` on `male_educ` and `fem_educ` using OLS. Interpret whether `male_educ` appears to be a relevant instrument by examining its t-statistic. Save this first-stage result mentally for comparison with the IV output.

4. **IV estimation with `ivregress`** — Estimate the effect of `kids` on `fem_inc`, controlling for `fem_educ`, using `male_educ` as an instrument for `kids`. Use the 2SLS estimator (`ivregress 2sls`). Compare the IV coefficient on `kids` to the OLS coefficient from Task 2 — does the direction or magnitude change, and what might explain this?

5. *(Bonus)* **Test instrument relevance and run the Hausman test** — After the IV regression, use `estat firststage` to retrieve the first-stage F-statistic and assess instrument strength (a common rule of thumb is F > 10). Then use `hausman` to formally test whether `kids` is endogenous by comparing the IV and OLS estimates. Interpret what the p-value tells you about the need for IV in this context.

- **Hint 1 (Task 3)**: A strong instrument must be correlated with the endogenous regressor (`kids`). Look at the coefficient and t-statistic on `male_educ` in the first-stage regression — statistical significance is a necessary (but not sufficient) condition for relevance.

- **Hint 2 (Task 4)**: The syntax for `ivregress 2sls` follows the pattern `ivregress 2sls depvar exogenous_controls (endogenous_var = instrument)`. Make sure `fem_educ` appears as an exogenous control *outside* the parentheses, while `kids` and `male_educ` go *inside*.

- **Hint 3 (Task 5)**: To use `hausman`, you need to store both the IV and OLS estimates. Run the consistent estimator (IV) first and store it with `estimates store`, then run OLS and store it, then call `hausman iv_estimates ols_estimates`. Check the Stata help for the correct ordering of arguments.
