## Background
The Grunfeld dataset tracks investment, market value, and capital stock for 10 large US firms across 20 years (1935–1954), making it a classic panel for studying firm-level investment dynamics. Difference-in-differences (DiD) is a cornerstone identification strategy in labor and industrial economics, and this panel structure makes it ideal for practicing the method in a controlled setting.

## Your tasks

1. **Declare the panel structure** — Load the dataset and declare it as a panel using `xtset`. Confirm the panel is balanced by checking that every firm-year combination is present. Then tabulate how many observations belong to each company.

2. **Create a treatment indicator** — Define a binary variable called `treated` equal to 1 for companies with `company` ≤ 5 (call these the "treated group") and 0 otherwise. Then create a binary variable called `post` equal to 1 for years after 1944 (i.e., `year` > 1944) and 0 otherwise. Verify the counts for each group using `tabulate`.

3. **Construct the interaction term and run a basic DiD regression** — Generate a variable `did` as the product of `treated` and `post`. Regress `invest` on `treated`, `post`, and `did` using OLS (`regress`). Report and interpret the coefficient on `did`: what does it represent in the DiD framework?

4. **Add firm fixed effects and cluster standard errors** — Re-run the DiD regression using `xtreg, fe` with standard errors clustered at the company level (`vce(cluster company)`). Include `post` and `did` as regressors (note: `treated` drops out with firm fixed effects — explain why). Compare the coefficient on `did` to the result from Task 3.

5. *(Bonus)* **Event-study plot** — Instead of a single `post` dummy, create a set of year-relative-to-cutoff dummies (omitting the year just before the cutoff, 1944, as the reference category). Run the firm-fixed-effects regression including these dummies interacted with `treated`, and use `coefplot` (if installed) or manually inspect coefficients to assess whether pre-trends appear parallel for the two groups before 1945.

- **Hint 1 (Task 1)**: The `xtset` command takes the panel identifier and the time identifier in that order. To check balance, think about whether `xtdescribe` or a simple `tabulate company` can reveal gaps in the panel.

- **Hint 2 (Task 3)**: The DiD coefficient on `did` captures the average change in `invest` for the treated group *relative* to the control group after the cutoff — it is the "treatment effect" under the parallel trends assumption. Make sure you generate `did` before running the regression rather than relying on `c.treated#c.post` notation, so the interpretation stays transparent.

- **Hint 3 (Task 4)**: With firm fixed effects, any variable that does not vary *within* a firm over time is perfectly collinear with the firm dummies and will be automatically dropped. Think about which of your three regressors (`treated`, `post`, `did`) is constant within each firm across all years.
