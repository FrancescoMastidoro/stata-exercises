# Day 141: Instrumental Variables with LASSO-Selected Instruments

## Background
The NLSY 1980 cross-section tracks 935 individuals with information on wages, education, cognitive ability, and family background, making it a classic playground for causal wage equations in labor economics. Instrumental Variables (IV) estimation is essential when explanatory variables like education are suspected to be endogenous — and LASSO can help select instruments from a larger candidate pool in a principled, data-driven way.

## Your tasks

1. **Explore potential instruments** — Load the dataset and summarize `educ`, `lwage`, `iq`, `kww`, `sibs`, `meduc`, and `feduc`. Note which of these have missing values according to the reference tables, then `drop` observations with any missing values in those variables. Report how many observations remain.

2. **Run a naive OLS baseline** — Regress `lwage` on `educ`, `exper`, `tenure`, `black`, `south`, and `urban`. Interpret the coefficient on `educ` and explain in a comment why it may be biased upward.

3. **Estimate a 2SLS model by hand** — Use `ivregress 2sls` to instrument `educ` with `sibs`, `meduc`, and `feduc` (family background variables arguably excluded from the wage equation), keeping the same controls as Task 2. Compare the IV coefficient on `educ` to the OLS estimate — is it larger or smaller, and what does that suggest?

4. **Test instrument validity** — After the `ivregress` command, run `estat firststage` to assess instrument strength and `estat overid` to test the overidentifying restrictions. Report the first-stage F-statistic and interpret the Sargan–Hansen p-value: do the instruments appear valid?

5. *(Bonus)* **LASSO-assisted instrument selection** — Using `lasso linear educ sibs meduc feduc iq kww` (with the same controls partialled out via `partialled()`), let LASSO select among the candidate instruments. Then re-run `ivregress 2sls` using only the LASSO-selected instruments and compare the first-stage F-statistic to Task 4's result. Does instrument strength improve or worsen?

## Hints

<summary>Click to reveal hints (try first!)</summary>

- **Hint 1 (Task 1)**: Use `misstable summarize` or `sum brthord meduc feduc` to see which variables have missing values — the reference tables confirm `meduc` (78 missing) and `feduc` (194 missing) are affected. Use `keep if !missing(meduc, feduc)` rather than dropping one variable at a time.
- **Hint 2 (Task 3)**: The syntax for `ivregress 2sls` places endogenous variables and their instruments in parentheses: `ivregress 2sls lwage controls (educ = sibs meduc feduc)`. A downward-biased IV estimate relative to OLS could suggest ability bias was inflating OLS.
- **Hint 3 (Task 4)**: `estat firststage` is available only after `ivregress` — look for the partial F-statistic on excluded instruments; a value above 10 is a common rule-of-thumb threshold for instrument relevance. `estat overid` tests whether the excluded instruments are uncorrelated with the structural error.
- **Hint 4 (Bonus)**: In `lasso linear`, the `partialled()` option removes the influence of control variables from both the outcome and the regressors before LASSO penalizes — this mirrors the Frisch-Waugh logic used inside 2SLS.
