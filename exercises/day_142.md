## Background
The PSID extract contains 4,165 observations tracking 595 individuals across 7 time periods, with variables covering wages, employment conditions, and demographic characteristics. Difference-in-differences (DiD) is a cornerstone identification strategy in labor economics, allowing researchers to estimate causal treatment effects by comparing changes over time across groups.

## Your tasks

1. **Explore the panel structure** — Load the dataset, declare it as a panel using `xtset` with `id` as the panel variable and `t` as the time variable. Then use `xtdescribe` to verify the panel is balanced and confirm there are 595 individuals observed across exactly 7 periods.

2. **Define treatment and post variables** — Create a binary variable `treated` equal to 1 if the individual belongs to a union (`union == 1`) in period `t == 1` (their baseline status), assigning this baseline value to all periods for the same individual using `egen`. Then create a binary variable `post` equal to 1 for periods `t >= 4` and 0 otherwise.

3. **Construct the interaction term and run a basic DiD** — Generate an interaction variable `did = treated * post`. Regress `lwage` on `treated`, `post`, and `did` using `reg`. Interpret the coefficient on `did` as the DiD estimate and note its sign and magnitude.

4. **Upgrade to a two-way fixed effects estimator** — Re-estimate the DiD using `xtreg lwage treated post did, fe` to absorb individual fixed effects. Compare the coefficient on `did` to the result from Task 3 and explain in a comment why controlling for individual fixed effects matters here. Also add `south`, `smsa`, and `union` as time-varying controls.

5. *(Bonus)* **Test the parallel trends assumption visually** — Using `collapse`, compute the mean of `lwage` separately by `treated` and `t`. Then use `twoway line` to plot the average log-wage trajectory for treated and control groups over the 7 periods on the same graph. Comment in your do-file on whether the pre-treatment trends (periods 1–3) look parallel.
