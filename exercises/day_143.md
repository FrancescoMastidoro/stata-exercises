## Background
The `regsmpl` dataset is a panel of NLS women observed across survey years from 1968 to 1988, containing wages, education, experience, and demographic characteristics. Difference-in-differences (DiD) is a cornerstone identification strategy in labor economics, used to estimate causal effects by comparing treated and control groups before and after a policy change.

## Your tasks

1. **Load and explore the panel structure** — Load the dataset with `webuse regsmpl`, then use `xtset` to declare the panel (id variable: `idcode`, time variable: `year`). Report the number of unique individuals and the range of years using `xtdescribe` or `tab year`.

2. **Create a treatment indicator** — Define a binary variable `post` equal to 1 if `year >= 78` (i.e., on or after 1978) and 0 otherwise. Then create a treatment group indicator `treated` equal to 1 if `black == 1` and 0 otherwise. Confirm your construction with `tab post treated`.

3. **Construct the DiD interaction term and run the baseline regression** — Generate an interaction variable `did = post * treated`. Regress `ln_wage` on `post`, `treated`, and `did` using `xtreg` with fixed effects (`fe`). Report and interpret the coefficient on `did` — what does it represent in this DiD framework?

4. **Add controls and cluster standard errors** — Re-estimate the fixed-effects DiD model adding `ttl_exp` and `tenure` as controls. Cluster standard errors at the `idcode` level using the `vce(cluster idcode)` option. Compare the standard error on `did` to the unclustered version from Task 3 and explain why clustering matters for panel data.

5. *(Bonus)* **Parallel trends check via leads** — Construct a variable `pre_trend = (year == 68 | year == 70) * treated` to test for differential pre-trends in the earliest two periods. Add `pre_trend` to your Task 4 regression. If the DiD assumption holds, what would you expect the coefficient on `pre_trend` to look like, and why?

- **Hint 1 (Task 2)**: You can generate binary indicators with `gen post = (year >= 78)` — Stata evaluates the logical expression and assigns 1 if true, 0 if false. Do the same for `treated`.
- **Hint 2 (Task 3)**: After generating `did`, the syntax for a within-estimator is `xtreg ln_wage post treated did, fe` — remember that `xtreg, fe` absorbs individual fixed effects, so time-invariant variables like `treated` (perfectly collinear with the fixed effects) will be dropped. Think carefully about what this implies for interpreting `treated` in your output.
- **Hint 3 (Task 4)**: `tenure` has 433 missing values according to the dataset reference — check whether listwise deletion materially changes your sample size and note it in your comments. To cluster, add `vce(cluster idcode)` at the end of your `xtreg` command.
- **Hint 4 (Bonus)**: A parallel-trends test adds pre-period interaction terms to the regression. If the treated and control groups were evolving similarly *before* the "treatment" period, the coefficient on any pre-period interaction should be statistically indistinguishable from zero.
