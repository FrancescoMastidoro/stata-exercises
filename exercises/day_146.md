# Day 146: Difference-in-Differences with Panel Data

**Dataset**: `webuse psidextract`
**Estimated time**: ~25 minutes
**Difficulty**: ⬛⬛⬛⬛⬛

## Background
The PSID extract contains 4,165 observations on 595 workers observed across up to 7 time periods, with information on wages, union status, occupation, and demographics. Difference-in-Differences (DiD) is a cornerstone method in labor economics for estimating causal effects when treatment is not randomly assigned but varies across units and over time.

## Your tasks

1. **Load and inspect the panel structure** — Load `webuse psidextract`, then declare the panel using `xtset`. Confirm that `id` is the individual identifier and `t` is the time variable (ranging 1–7). Run `xtdescribe` to check how balanced the panel is.

2. **Create a treatment indicator** — Define a binary variable `treated` equal to 1 if a worker is ever observed in a union (`union == 1`) at any point in the panel. Use `egen` with the `max()` function over the `id` groups to create this "ever-treated" indicator. Tabulate `treated` to see how many workers are in each group.

3. **Define a post-period and construct the DiD interaction** — Create a binary variable `post` equal to 1 for periods `t >= 4` (the second half of the panel). Then construct the DiD interaction term `did = treated * post`. Verify the three variables — `treated`, `post`, and `did` — with `tabulate` or `table`.

4. **Estimate the DiD model** — Run a two-way fixed effects regression of `lwage` on `did`, controlling for both individual fixed effects (`id`) and time fixed effects (`t`). Use `xtreg lwage did i.t, fe` and interpret the coefficient on `did`. Then also add `union`, `occ`, `south`, and `smsa` as time-varying controls and compare results.

5. *(Bonus)* **Event-study plot** — Instead of collapsing the treatment timing into a single `post` dummy, create interactions between `treated` and each period indicator (`i.t`) and regress `lwage` on these interactions plus individual and time fixed effects (omitting one period as the baseline, e.g. `t == 3`). Use `coefplot` (if installed) or `marginsplot` after `margins` to visualize whether pre-trends are flat — a key assumption of DiD.
