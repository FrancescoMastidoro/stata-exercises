## Background
The Mroz 1987 PSID dataset contains detailed information on married women's labor force participation, wages, and family characteristics — a classic benchmark in labor economics. LASSO (Least Absolute Shrinkage and Selection Operator) is a powerful regularization technique that automatically selects relevant predictors from a large set of candidate variables, making it especially useful when theory alone does not clearly indicate which controls to include in a wage equation.

## Your tasks

1. **Load and explore** — Load the dataset with `webuse mroz87`. Use `describe` and `summarize` to get a feel for the data. Identify which variables measure the wife's human capital (education, experience, wages) and which measure family characteristics (husband's attributes, children, income).

2. **Set up the outcome and predictors** — You want to predict the wife's 1976 hourly wage (`wwage76`) using LASSO. Before running LASSO, run a standard OLS regression of `wwage76` on `wedyrs`, `wexper`, `kl6`, `k618`, `wifeage`, `hedyrs`, `hwage75`, `mtr`, `unemprt`, and `smsa`. Note the R-squared and which coefficients are statistically significant.

3. **Run LASSO** — Use Stata's `lasso linear` command to regress `wwage76` on the same set of predictors as in Task 2. After estimation, use `lassocoef` to display which variables LASSO selected and which were shrunk to zero. Compare the selected set to the significant predictors from your OLS in Task 2.

4. **Post-LASSO OLS** — After `lasso linear`, use the `coefpath` plot to visualize how coefficients shrink as the penalty parameter increases. Then use `lasso linear` with the `postselection` option (or manually run OLS using only the variables selected by LASSO) to obtain post-LASSO OLS estimates. Compare the standard errors of the selected variables to those from the full OLS in Task 2 — are they larger or smaller, and why might that be?

5. *(Bonus)* **Cross-validated LASSO** — Rerun `lasso linear` using `lasso linear wwage76 wedyrs wexper kl6 k618 wifeage hedyrs hwage75 mtr unemprt smsa, selection(cv) folds(10)` to select the penalty via 10-fold cross-validation instead of the default BIC criterion. Compare the set of selected variables and the chosen penalty (`lambda`) to the BIC-selected model. Do the two approaches agree on which predictors matter?
