## Background
The PSID extract contains 4,165 observations on workers tracked across up to 7 time periods, recording wages, employment characteristics, and demographic information. Difference-in-differences (DiD) is a cornerstone identification strategy in labor economics, exploiting variation in treatment timing across groups to isolate causal effects on outcomes like log wages.

## Your tasks

1. **Explore the panel structure** — Load the dataset and declare it as a panel using `xtset`. Confirm the panel identifier and time variable, then use `xtdescribe` to check how balanced the panel is across individuals.

2. **Define treatment and post indicators** — The variable `union` captures union membership (0/1). Create a binary variable called `post` equal to 1 for time periods `t >= 4` and 0 otherwise. Then tabulate `union` and `post` jointly to inspect the distribution across cells — you need observations in all four cells for DiD to work.

3. **Estimate a basic DiD model** — Regress `lwage` on `union`, `post`, and their interaction term `union#post` (or construct the interaction manually as `c.union#c.post`). Interpret the coefficient on the interaction term as the DiD estimate of the union wage premium.

4. **Add controls and fixed effects** — Re-run the DiD regression adding `ed`, `exp`, `occ`, `ind`, `south`, `smsa`, `blk`, and `fem` as controls, and include individual fixed effects using `xtreg, fe`. Compare the interaction coefficient to the estimate from Task 3 and explain why it changes.

5. *(Bonus)* **Parallel trends check** — Create a set of period-specific treatment indicators by interacting `union` with each value of `t` (i.e., `union × 1`, `union × 2`, … `union × 7`). Regress `lwage` on these interactions plus individual fixed effects, omitting the interaction for `t == 1` as the reference period. Plot or inspect the pre-period coefficients (`t = 2, 3`) — if they are close to zero and statistically insignificant, the parallel trends assumption gains support.

## Hints

- **Hint 1 (Task 1)**: The panel structure variables in `psidextract` are `id` and `t` — use `xtset id t` before any panel commands, and check `xtdescribe` to see how many individuals have all 7 observations.

- **Hint 2 (Task 3)**: In Stata you can either manually generate `gen union_post = union * post` and include it in `regress`, or use factor-variable notation `i.union##i.post` directly in `regress` — both approaches give the same interaction coefficient, which is your DiD estimate.

- **Hint 3 (Task 4)**: `xtreg lwage ... , fe` automatically absorbs individual-level time-invariant heterogeneity; if a control like `blk` or `fem` is time-invariant, Stata will drop it from the within estimator — don't be alarmed when that happens.

- **Hint 4 (Bonus)**: Generate interactions with `forvalues p = 1/7 { gen union_t`p' = union * (t == `p') }` then include all except `union_t1` in your regression. Comparing coefficients for `t = 2` and `t = 3` to zero is the informal parallel trends test.
