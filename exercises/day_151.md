## Background
The Grunfeld dataset contains firm-level investment panel data for 10 companies observed annually from 1935 to 1954, making it a classic testbed for panel econometrics. Difference-in-differences (DiD) methods are central to causal inference in labor and industrial economics, allowing researchers to exploit variation in treatment timing across units to isolate causal effects.

## Your tasks

1. **Declare the panel structure** — Load the dataset and declare it as a panel using `xtset`, with company as the panel identifier and year as the time variable. Then summarize `invest`, `mvalue`, and `kstock` to get a sense of their ranges.

2. **Create a treatment indicator** — Define a binary variable `treated` equal to 1 for companies with `company <= 5` (the "treated" group) and 0 for the remaining companies. Then define a post-period variable `post` equal to 1 for years after 1944 (i.e., `year > 1944`) and 0 otherwise. Tabulate both variables to confirm the cell counts.

3. **Construct the interaction term and run a basic DiD regression** — Generate an interaction variable `did = treated * post`. Run an OLS regression of `invest` on `treated`, `post`, and `did`. Interpret the coefficient on `did` as the average treatment effect on the treated (ATT) and note whether it is statistically significant.

4. **Improve the specification with fixed effects** — Re-estimate the DiD model using `xtreg` with both company fixed effects (`fe`) and clustering standard errors at the company level. Include `mvalue` and `kstock` as time-varying controls. Compare the coefficient on `did` to the result from Task 3 and reflect on why the estimates differ.

5. *(Bonus)* **Parallel trends check** — Generate a set of year-by-treatment interaction dummies (event-study style) by creating interactions between `treated` and indicators for each year from 1940 to 1954, using 1944 as the omitted reference year. Run an `xtreg, fe` regression of `invest` on these interactions plus `mvalue` and `kstock`. Plot the coefficients using `coefplot` (if installed) or inspect them manually. Do pre-treatment coefficients look close to zero, supporting the parallel trends assumption?
