## Background
The PSID extract contains 4,165 person-period observations tracking workers across up to 7 time periods, with information on wages, union status, occupation, and demographics. Difference-in-differences (DiD) is a cornerstone of modern labor economics, exploiting variation in treatment timing or status across groups to identify causal effects while controlling for time-invariant unobservables.

## Your tasks

1. **Load and explore the panel structure** — Load the dataset, then use `xtset` to declare the panel structure using `id` as the individual identifier and `t` as the time variable. Confirm the structure by running `xtdescribe` and note the number of individuals and time periods.

2. **Construct a DiD treatment indicator** — In this dataset, `union` indicates union membership (0/1). Define a "treated" group as workers who are in a union (`union == 1`) and consider the "post" period as `t >= 4`. Create two new variables: `post` (equal to 1 when `t >= 4`, 0 otherwise) and `treated` (equal to 1 if a worker is *ever* in a union across their observations, using `egen` with `max` by `id`). Then create the interaction term `did = post * treated`.

3. **Run a basic DiD regression** — Regress `lwage` on `treated`, `post`, and `did` using `regress`. Interpret the coefficient on `did` as your DiD estimate and note its sign and statistical significance.

4. **Add controls and use fixed effects** — Re-estimate the DiD model using `xtreg, fe` with `id` fixed effects. Include `post`, `did`, `ed`, `exp`, `wks`, `south`, and `union` as regressors. Compare the coefficient on `did` to the estimate from Task 3 and discuss why the fixed-effects estimate may differ.

5. *(Bonus)* **Parallel trends check** — Create period dummies for each value of `t` (using `tabulate t, gen(tdum)`) and interact each with `treated` to construct a set of interaction terms. Run an `xtreg, fe` regression of `lwage` on `ed`, `exp`, `wks`, the period dummies, and all the interaction terms (omitting the `t == 3` interaction as the reference period just before "treatment"). Plot or tabulate the coefficients on the pre-period interactions (`t == 1`, `t == 2`) and assess whether they are close to zero, as the parallel trends assumption requires.
