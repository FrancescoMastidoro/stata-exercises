## Background
The PSID extract contains 4,165 observations on 595 individuals tracked over 7 time periods, with variables capturing wages, employment characteristics, union membership, and demographics. Difference-in-Differences (DiD) is a cornerstone identification strategy in labor economics, allowing researchers to estimate causal effects by comparing changes over time across treatment and control groups.

## Your tasks

1. **Explore the panel structure** — Load the dataset and declare it as a panel using `xtset`. Then summarize `lwage`, `union`, `south`, and `ed` to get a sense of the data. How many unique individuals are there, and how many time periods?

2. **Create a post-treatment indicator** — Generate a binary variable called `post` equal to 1 if `t` is greater than 3 (i.e., the second half of the panel), and 0 otherwise. Then use `tabulate t post` to verify your construction is correct.

3. **Estimate a basic DiD** — Using `union` as the "treatment" group indicator and `post` as the time indicator, estimate a DiD regression of `lwage` on `union`, `post`, and their interaction `union#post`. Use `regress` with robust standard errors. Interpret the coefficient on the interaction term.

4. **Add controls and fixed effects** — Re-estimate the DiD model using `xtreg` with individual fixed effects (`fe`). Include `post`, `union#post`, `ed`, `south`, and `wks` as regressors, with robust standard errors. Compare the interaction coefficient to the one from Task 3 and explain why it changes.

5. *(Bonus)* **Test the parallel trends assumption visually** — Using `collapse`, compute the mean of `lwage` by `t` separately for union and non-union workers. Then use `twoway line` to plot both series on the same graph and assess whether the pre-period trends (t ≤ 3) look parallel. What do you observe?

- **Hint 1 (Task 3)**: In Stata, interaction terms in regression can be specified using factor variable notation: `c.var1#c.var2` for continuous interactions or `i.var1#i.var2` for categorical ones. Think about which type each variable is here, and remember to include both main effects separately.

- **Hint 2 (Task 4)**: With `xtreg, fe`, individual fixed effects absorb all time-invariant characteristics — this includes the `union` main effect if union status never changes for some individuals. Check whether `union` needs to be included as a main effect or whether the FE absorber handles it, and use `vce(robust)` for robust standard errors.

- **Hint 3 (Task 5)**: `collapse (mean) lwage, by(t union)` will give you a collapsed dataset. You then need to separate the two series — consider using `if union == 0` and `if union == 1` within your `twoway line` command to plot them on the same axes.
