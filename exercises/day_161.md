## Background
The NLSY 1980 dataset contains rich individual-level information on wages, education, cognitive ability, and family background for 935 workers, making it a classic laboratory for wage equation research. LASSO (Least Absolute Shrinkage and Selection Operator) is a penalized regression method that automatically shrinks irrelevant coefficients toward zero, helping researchers select parsimonious models from a large set of candidate predictors.

## Your tasks

1. **Load and explore** — Load `webuse nlsy80`, then use `describe` and `summarize` to familiarise yourself with the dataset. Note the range of `lwage` (the log monthly wage) and identify which variables have missing values (`brthord`, `meduc`, `feduc`). Drop observations with any missing values in these three variables so that LASSO operates on a complete case sample, and report how many observations remain.

2. **Run a standard OLS benchmark** — Regress `lwage` on the following predictors: `educ`, `exper`, `tenure`, `iq`, `kww`, `age`, `married`, `black`, `south`, `urban`, `sibs`, `hours`. Store the results with `estimates store ols_bench` and note which coefficients are statistically significant at the 5% level.

3. **Run LASSO with cross-validation** — Use `lasso linear lwage educ exper tenure iq kww age married black south urban sibs hours` with the default cross-validation (`cv`) selection method. After estimation, use `lassocoef` to display the selected coefficients. Compare which predictors LASSO retains versus which were significant in OLS.

4. **Retrieve the LASSO-selected variables and refit OLS** — Use `lassoselect` (or examine the `e(post_sel_cmd)` approach) together with `lasso linear` followed by `lasso postselection` to obtain the post-selection OLS estimates on the variables chosen by LASSO. Alternatively, manually note the retained variables from Task 3 and run `regress lwage [selected vars]` on the same sample. Compare the coefficient on `educ` between the full OLS model (Task 2) and this post-selection model — does variable selection change the education premium?

5. *(Bonus)* **Adaptive LASSO via plugin penalty** — Re-run the LASSO from Task 3 but this time specify the `selection(plugin)` option instead of cross-validation. Use `lassocoef, display(coef, penalized)` to inspect both retained and penalized-out variables. Discuss in a comment whether the plugin method selects a sparser or richer model than CV, and explain in one sentence why the plugin estimator may be preferred for inference in labor economics applications.
