# Day 162: Difference-in-Differences with Panel Data

**Dataset**: `webuse psidextract`
**Estimated time**: ~25 minutes

## Background
The PSID extract contains 4,165 observations on workers tracked across up to 7 time periods, with information on wages, union status, occupation, and demographics. Difference-in-differences (DiD) is a cornerstone method in labor economics for estimating causal effects by comparing changes over time between a treatment and a control group.

## Your tasks

1. **Load and explore the panel structure** — Load `webuse psidextract`, then use `xtset` to declare the panel with `id` as the individual identifier and `t` as the time variable. Summarize `lwage`, `union`, `south`, and `fem` to get a sense of the data.

2. **Define a treatment indicator and a post period** — Union membership (`union`) will serve as the "treatment." Create a binary variable `post` equal to 1 if `t >= 4` and 0 otherwise. Then create the interaction term `union_post = union * post`. Tabulate `union` and `post` to confirm the two groups exist in both periods.

3. **Run a basic DiD regression** — Regress `lwage` on `union`, `post`, and `union_post` using `xtreg` with random effects (option `re`). Interpret the coefficient on `union_post`: what does it estimate?

4. **Add controls and switch to fixed effects** — Re-estimate the DiD model using `xtreg, fe` (fixed effects), adding `occ`, `ind`, `south`, `smsa`, and `wks` as controls alongside `post` and `union_post`. Compare the coefficient on `union_post` to the random-effects estimate from Task 3. Use `hausman` to formally test whether fixed or random effects is preferred.

5. *(Bonus)* **Event-study style plot** — Instead of collapsing time into a single `post` dummy, create separate interaction terms `union_t1` through `union_t7` (i.e., `union * (t == k)` for each period k). Regress `lwage` on these interactions plus individual fixed effects (using `xtreg, fe`), omitting the interaction for `t == 3` as the reference period. Use `coefplot` (if installed) or manually extract the coefficients and confidence intervals with `lincom` to visualize parallel pre-trends.

## Hints

- **Hint 1 (Task 2)**: You can generate `post` with `gen post = (t >= 4)` — Stata evaluates logical expressions as 1/0 automatically. The interaction term is simply the product of the two binary variables.

- **Hint 2 (Task 3)**: In a DiD framework, `union` captures the pre-existing level difference between groups, `post` captures the common time trend, and `union_post` captures the *additional* change for the treated group after the cutoff — that is the DiD estimate.

- **Hint 3 (Task 4)**: With fixed effects, time-invariant regressors (like `fem` or `blk`) are absorbed and cannot be identified — focus on time-varying controls. The `hausman` command syntax is `hausman [fe_estimates] [re_estimates]`; you need to `estimates store` each model first.

- **Hint 4 (Bonus)**: Use a `forvalues` loop to generate the interactions: `forvalues k = 1/7 { gen union_t`k' = union * (t == `k') }`. Drop or omit `union_t3` in the regression to set the reference period.
