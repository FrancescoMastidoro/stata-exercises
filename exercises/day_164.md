## Background
The `regsmpl` dataset is a panel of NLS women observed from 1968 to 1988, containing wage, education, experience, and demographic information across multiple survey years. Difference-in-differences (DiD) designs are a cornerstone of modern labor economics, allowing researchers to estimate causal effects by comparing treated and control groups before and after a policy change.

## Your tasks

1. **Load and explore the panel** — Load `webuse regsmpl`, then use `xtset` to declare the panel structure using `idcode` as the individual identifier and `year` as the time variable. Report how many distinct individuals and years are in the dataset using `codebook idcode year`.

2. **Create a treatment indicator** — Construct a binary variable called `treated` equal to 1 if an observation's `black` equals 0 (i.e., non-Black women form the "treatment group" in a hypothetical policy that affected them starting in 1980). Then create a post indicator called `post` equal to 1 if `year >= 80` (the dataset encodes year as two-digit integers: 68–88). Tabulate both new variables to verify they look correct.

3. **Construct the DiD interaction term and run the baseline regression** — Generate an interaction variable `did = treated * post`. Then regress `ln_wage` on `treated`, `post`, and `did`. Interpret the coefficient on `did` as the DiD estimate — does the wage gap between groups widen or narrow after 1980?

4. **Add controls and cluster standard errors** — Re-run the DiD regression from Task 3, this time adding `ttl_exp`, `grade`, and `south` as controls, and clustering standard errors at the `idcode` level using `vce(cluster idcode)`. Compare the DiD coefficient and its standard error to the uncontrolled version from Task 3 — does adding controls change the point estimate meaningfully?

5. *(Bonus)* **Add individual fixed effects** — Replace the pooled OLS specification with a within-estimator using `xtreg ln_wage post did ttl_exp grade south, fe vce(cluster idcode)`. Note that `treated` drops out — explain in a comment why individual fixed effects absorb the time-invariant `treated` variable. Compare the `did` coefficient across all three specifications (Tasks 3, 4, and the bonus) and comment on what drives any differences.

## Hints
<details>
<summary>Click to reveal hints (try first!)</summary>

- **Hint 1 (Task 2)**: Use `generate treated = (black == 0)` and `generate post = (year >= 80)`. Remember that `year` is stored as two-digit integers (68, 70, … 88), so the threshold is `80`, not `1980`.
- **Hint 2 (Task 3)**: Once you have `treated`, `post`, and `did`, the canonical DiD regression is simply `regress ln_wage treated post did`. The coefficient on `did` captures the differential change in `ln_wage` for the treated group after the policy date.
- **Hint 3 (Task 4)**: Add `, vce(cluster idcode)` at the end of your `regress` command to cluster. Clustering at the individual level accounts for serial correlation within person over time — this often inflates standard errors relative to default OLS.
- **Hint 4 (Bonus)**: After `xtset`, use `xtreg ..., fe` to absorb individual-level means. Because `treated` is a dummy that never changes within a person (it is `black`-based), the fixed-effects transformation removes it entirely — add a comment `// treated is time-invariant, absorbed by FE` to document this.
