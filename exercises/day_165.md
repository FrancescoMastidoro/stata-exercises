## Background
The NLSY 1980 cross-section contains wage, education, experience, and cognitive ability data for 935 individuals, making it a natural playground for wage-equation estimation. LASSO (Least Absolute Shrinkage and Selection Operator) is increasingly used in labor economics to select predictors from a rich covariate set in a principled, data-driven way — helping avoid both overfitting and arbitrary specification choices.

## Your tasks

1. **Load and inspect** — Load the dataset with `webuse nlsy80`. List all variable names and use `describe` and `summarize` to get a feel for the data. Note which variables have missing values (`brthord`, `meduc`, `feduc`) and which are complete. Do not drop observations yet.

2. **Estimate a baseline OLS wage equation** — Regress `lwage` on `educ`, `exper`, `tenure`, `iq`, `kww`, `age`, `married`, `black`, `south`, `urban`, and `sibs` using `regress`. Record the R-squared and note which coefficients are statistically significant at the 5% level.

3. **Run LASSO with the same covariate set** — Use `lasso linear lwage educ exper tenure iq kww age married black south urban sibs` to let Stata select among the same predictors via cross-validation. After estimation, run `lassocoef` to inspect which variables survive the penalty. Compare the selected set to your OLS significant predictors from Task 2.

4. **Post-LASSO OLS (double-selection)** — Use `lassoselect` (or note the variables retained by LASSO) and then manually run `regress lwage` on only the variables LASSO kept. Compare the coefficient on `educ` between this post-LASSO OLS and your baseline OLS from Task 2. Does the education return change meaningfully? Explain in a comment why post-LASSO OLS is preferred over reading coefficients directly from the LASSO output.

5. *(Bonus)* **Cross-fitted Partialling-Out LASSO** — Use the `poregress` command (partialling-out LASSO) to estimate the causal effect of `educ` on `lwage`, controlling for all other complete variables (`exper`, `tenure`, `iq`, `kww`, `age`, `married`, `black`, `south`, `urban`, `sibs`). Compare the point estimate and confidence interval for `educ` to both OLS and post-LASSO OLS. Discuss in comments whether the three approaches tell a consistent story about returns to education.

- **Hint 1 (Task 3)**: The `lasso linear` command is part of Stata's `lasso` suite (available from Stata 16+). After running it, `lassocoef` displays which predictors have non-zero coefficients at the selected lambda. Look for the line `Selected lambda` in the output to understand how Stata chose the penalty strength via cross-validation.

- **Hint 2 (Task 4)**: LASSO shrinks coefficients toward zero for regularisation purposes, so you should *not* interpret LASSO coefficients as causal estimates. Instead, take the set of variables LASSO selected and re-run a plain `regress` on only those variables — this "post-LASSO OLS" recovers unbiased estimates (within the selected model). You can store selected variable names using `lassoknots` or simply read them from `lassocoef` output and type them manually.
