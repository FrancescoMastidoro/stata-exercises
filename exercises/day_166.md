## Background
The PSID extract contains 595 individuals observed across 7 time periods, with information on wages, occupation, union status, and demographic characteristics. Difference-in-differences (DiD) estimation is a cornerstone of modern labor economics, allowing researchers to identify causal effects by comparing changes across groups over time.

## Your tasks

1. **Load and explore the panel structure** — Load the dataset and use `xtset` to declare the panel structure using `id` and `t`. Then run `xtdescribe` to verify the panel is balanced (all individuals observed in all 7 periods).

2. **Create a treatment indicator** — Define a binary "post" variable equal to 1 when `t >= 4` (later periods) and 0 otherwise. Then create a "treated" group indicator equal to 1 for individuals in a blue-collar occupation (`occ == 1`). Summarize both new variables to confirm they are correctly coded.

3. **Construct the DiD interaction term and estimate the basic DiD** — Generate an interaction variable `did = treated * post`. Run a pooled OLS regression of `lwage` on `treated`, `post`, and `did`. Interpret the coefficient on `did` as your DiD estimate of the wage premium for blue-collar workers in the later periods.

4. **Run a two-way fixed effects DiD** — Estimate a within-estimator regression of `lwage` on `post`, `did`, and the controls `union`, `ed`, and `south`, absorbing individual fixed effects with `xtreg, fe`. Compare the DiD coefficient to the pooled OLS estimate from Task 3 and comment on why the two estimates differ.

5. *(Bonus)* **Test the parallel trends assumption informally** — Restrict the sample to pre-treatment periods only (`t < 4`). Interact `treated` with dummies for each period (`t == 1`, `t == 2`, `t == 3`, using `t == 1` as the baseline) and regress `lwage` on these interactions plus individual fixed effects using `xtreg, fe`. If parallel trends holds, the interaction coefficients for `t == 2` and `t == 3` should be jointly insignificant — test this with `testparm`.
