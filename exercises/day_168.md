## Background
The `regsmpl` dataset is a panel of NLS women observed between 1968 and 1988, containing wages, education, work experience, and geographic indicators across many individual-year observations. Difference-in-differences (DiD) is a cornerstone identification strategy in labor economics, exploiting variation across groups and time to estimate causal treatment effects while controlling for unobserved time-invariant heterogeneity.

## Your tasks

1. **Explore the panel structure** — Load the dataset, then use `xtset` to declare the panel structure with `idcode` as the individual identifier and `year` as the time variable. After declaring, run `xtdescribe` and report: how many individuals are in the panel, how many time periods exist, and whether the panel is balanced or unbalanced.

2. **Create a treatment indicator** — DiD requires defining a "treated group" and a "post-treatment period." Define the treated group as women with `black == 1`, and define the post period as `year >= 78`. Create two new variables: `post` (= 1 if `year >= 78`, 0 otherwise) and `treated` (= 1 if `black == 1`, 0 otherwise). Then create the interaction term `did = post * treated`. Tabulate `post` and `did` to verify they look correct.

3. **Run a basic DiD regression** — Regress `ln_wage` on `treated`, `post`, and `did` using `xtreg` with random effects (`re`). Interpret the coefficient on `did`: what does it estimate, and what identifying assumption must hold for this to be causal?

4. **Add covariates and fixed effects** — Re-estimate the DiD model using `xtreg` with **fixed effects** (`fe`), adding `ttl_exp`, `tenure`, and `grade` as controls. Note which variables drop out of the fixed-effects estimator and explain why. Compare the `did` coefficient to your random-effects estimate from Task 3 — does the sign or magnitude change substantially?

5. *(Bonus)* **Event-study plot** — Instead of a single `post` indicator, create year-specific interaction dummies between `black` and each value of `year` (excluding one pre-treatment year as the reference category, e.g., `year == 75`). Run a fixed-effects regression of `ln_wage` on all these interaction terms plus year dummies and individual fixed effects (`absorb` with `areg` or `xtreg, fe`). Plot the coefficients and their 95% confidence intervals over time using `coefplot` (if installed) or by hand with `twoway rcap`. Do the pre-treatment coefficients support the parallel trends assumption?

- **Hint 1 (Task 1)**: After `webuse regsmpl`, the command `xtset idcode year` declares the panel. `xtdescribe` then summarizes the panel structure — look at the output lines for *n* (individuals) and *T* (time periods), and note the fraction of balanced observations.

- **Hint 2 (Task 3)**: In a standard DiD setup, `treated` captures the time-invariant group difference, `post` captures the common time trend, and `did` captures the average treatment effect on the treated (ATT). The identifying assumption is **parallel trends**: absent treatment, treated and control groups would have followed the same wage trajectory over time.

- **Hint 3 (Task 4)**: With `xtreg, fe`, Stata demeans each variable within individual. Any variable that does not vary over time for a given individual — such as `black` and therefore `treated` — will be **collinear with the individual fixed effect** and will be dropped. The `did` coefficient is still identified because `post * treated` varies over time for treated individuals.

- **Hint 4 (Bonus)**: You can generate event-study interactions with a loop: `forvalues y = 68(2)88 { gen inter_`y' = (black == 1) * (year == `y') }`. Drop the reference year dummy before estimation. After `xtreg, fe`, use `estimates store` and then `coefplot` to visualize.
