**Dataset**: `webuse nlsy80`
**Estimated time**: ~25 minutes

## Background
The NLSY 1980 cross-section contains wages, education, cognitive test scores, and demographic characteristics for a sample of workers, making it ideal for studying the returns to human capital. LASSO (Least Absolute Shrinkage and Selection Operator) is a powerful regularization method that automatically selects relevant predictors from a large candidate set — a skill increasingly expected in modern empirical labor economics.

## Your tasks

1. **Load and inspect the data** — Load the dataset, then use `describe` and `summarize` to familiarize yourself with the variables. Note that `lwage` is the log monthly wage (ranging 4.74–8.03) and `iq` is a cognitive test score (ranging 50–145). How many observations are available?

2. **Run a baseline OLS regression** — Regress `lwage` on `educ`, `exper`, `tenure`, `iq`, `kww`, `married`, `black`, `south`, `urban`, and `sibs`. Interpret the coefficient on `educ` and note the overall R-squared. This Mincer-style specification is your benchmark.

3. **Run LASSO with the same regressors** — Use `lasso linear lwage educ exper tenure iq kww married black south urban sibs` to estimate a LASSO model. After estimation, use `lassoknots` to inspect how many variables survive at the selected penalty level, and use `lassocoef` to display the selected coefficients.

4. **Compare OLS and LASSO selections using `coefplot`** — Store the OLS estimates with `estimates store ols_model`. Then re-run LASSO and use `lassoselect` followed by `lasso postselection` (or the `lassocoef, display` option) to compare which variables were retained. In a comment in your `.do` file, explain which regressors LASSO shrunk to zero and why this might be economically meaningful.

5. *(Bonus)* **Cross-validated LASSO and prediction** — Run `lasso linear lwage educ exper tenure iq kww married black south urban sibs, selection(cv) folds(10)` to use 10-fold cross-validation for penalty selection. After estimation, use `predict lwage_hat` to generate fitted values, then compute the mean absolute prediction error with `gen abs_err = abs(lwage - lwage_hat)` and `summarize abs_err`. Compare this to the residual standard error from your OLS model and comment on the trade-off between interpretability and predictive accuracy.
