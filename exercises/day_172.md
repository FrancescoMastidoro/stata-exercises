## Background
The PSID extract contains 4,165 observations on workers tracked across up to 7 time periods, with information on wages, union status, industry, and demographics. Difference-in-differences (DiD) is a cornerstone of modern labor economics program evaluation, allowing researchers to estimate causal treatment effects by comparing changes over time between treated and untreated groups.

## Your tasks

1. **Load and explore** — Load the dataset with `webuse psidextract`. Declare the panel structure using `xtset` with `id` as the unit identifier and `t` as the time variable. Then use `xtdescribe` to confirm the panel is balanced and inspect how many individuals and periods are present.

2. **Define a treatment indicator** — Create a binary variable called `treated` equal to 1 if a worker is in a union (`union == 1`) and works in a blue-collar occupation (`occ == 1`), and 0 otherwise. Tabulate `treated` and compute the share of treated workers in each time period using `bysort t: tabulate treated`.

3. **Construct a simple DiD by hand** — Using `collapse` (on a copy of the data, or saving first), compute the mean of `lwage` for the four cells defined by `treated` (0/1) and an indicator for the last period (`t == 7`) versus the first period (`t == 1`). Store your results and compute the DiD estimate manually: (mean wage treated, t=7) − (mean wage treated, t=1) − [(mean wage control, t=7) − (mean wage control, t=1)].

4. **Estimate DiD with a regression** — Using the full panel but restricting to `t == 1 | t == 7`, run the two-way fixed effects DiD regression of `lwage` on `treated`, a post-period dummy (`post`, which you define as `t == 7`), their interaction `treated#post`, and control for `ed`, `blk`, `fem`, and `south`. Use `regress` with robust standard errors. Interpret the coefficient on the interaction term.

5. *(Bonus)* **Add individual and time fixed effects** — Re-estimate the model from Task 4 on the full panel (all 7 periods) using `xtreg lwage i.t treated#i.t ed south, fe vce(robust)`. Compare the interaction coefficients across periods to the simple two-period DiD from Task 4. What does the pattern of coefficients tell you about the parallel trends assumption?
