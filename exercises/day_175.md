# Day 175: LASSO for Variable Selection in Labor Economics

**Dataset**: `webuse nlsy80`
**Estimated time**: ~25 minutes
**Difficulty**: ⬛⬛⬛⬛⬛

## Background
The NLSY 1980 cross-section contains wage, education, cognitive ability, and demographic variables for 935 workers, making it an ideal sandbox for exploring data-driven model selection. LASSO (Least Absolute Shrinkage and Selection Operator) is increasingly used in labor economics to select predictors of earnings from a rich covariate set while avoiding overfitting.

## Your tasks

1. **Load and inspect the data** — Load `webuse nlsy80`, then use `describe` and `summarize` to confirm the variables available. Note that `brthord`, `meduc`, and `feduc` have missing values (83, 78, and 194 respectively). Before running any LASSO, use `misstable summarize` to document the extent of missingness in those three variables.

2. **Run a standard OLS benchmark** — Regress `lwage` on `educ`, `exper`, `tenure`, `iq`, `kww`, `age`, `married`, `black`, `south`, `urban`, and `sibs` (use only variables with no missing values so all 935 observations are retained). Store the results using `estimates store ols_bench` and note the R² for comparison later.

3. **Run LASSO with the same covariate set** — Use `lasso linear lwage educ exper tenure iq kww age married black south urban sibs` to let Stata select predictors via cross-validation. After the command completes, use `lassocoef` to display which variables survived penalization and compare the selected set to your OLS specification.

4. **Compare OLS and post-LASSO estimates** — After the LASSO command, Stata automatically fits a post-selection OLS on the chosen variables. Use `estimates store lasso_post`, then run `estimates table ols_bench lasso_post, b se` to display coefficients and standard errors side by side. Comment in your do-file (using `*` lines) on at least two differences you observe between the two models.

5. *(Bonus)* **Experiment with the penalty** — Re-run `lasso linear` on the same outcome and covariates, but this time add the option `rseed(12345)` for reproducibility and then manually inspect the cross-validation plot by typing `cvplot` immediately after. Then use `lasso linear lwage educ exper tenure iq kww age married black south urban sibs, selection(bic)` to switch from cross-validation to BIC-based selection. Store this result as `lasso_bic` and compare which predictors BIC retains versus CV using `lassocoef, display(coef, penalized)`.
