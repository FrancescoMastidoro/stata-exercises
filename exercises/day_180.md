## Background
The PSID extract contains 4,165 observations on 595 workers observed across up to 7 time periods, with information on wages, union status, occupation, and demographics. Difference-in-differences (DiD) is a cornerstone method in labor economics for estimating causal effects by comparing changes over time between a treatment and a control group.

## Your tasks

1. **Declare the panel structure** — Load the dataset, then declare the panel using `xtset` with `id` as the panel identifier and `t` as the time variable. Confirm the structure by running `xtdescribe` and report how balanced the panel is.

2. **Construct a treatment indicator** — Define a binary "post" variable equal to 1 when `t >= 4` (the second half of the panel) and 0 otherwise. Then create a DiD interaction term `union_post` equal to the product of `union` and `post`. Tabulate the joint distribution of `union` and `post` to verify your construction.

3. **Estimate a basic DiD regression** — Regress `lwage` on `union`, `post`, and `union_post` using `xtreg` with the **between** estimator (`be`). Interpret the coefficient on `union_post`: what does it represent in a DiD framework?

4. **Switch to fixed-effects DiD** — Re-estimate the same model using `xtreg` with the **fixed-effects** (`fe`) estimator. Add `ed`, `exp`, and `south` as additional controls. Compare the DiD coefficient across the between and fixed-effects specifications and explain why they may differ. Use `estimates store` to save both sets of results, then display them side by side with `esttable` or `estimates table`.

5. *(Bonus)* **Test the parallel trends assumption indirectly** — Create separate time dummies for each value of `t` (1 through 7) using `xi: tabulate t, gen(tdum)` or `i.t`. Interact each time dummy with `union` to produce a set of "event-study" coefficients. Run `xtreg lwage union##i.t ed exp south, fe` and plot or inspect the pre-period interaction coefficients (those for `t < 4`). If parallel trends holds, what pattern would you expect to see in those pre-period coefficients?
