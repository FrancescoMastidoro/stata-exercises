# Day 183: LASSO for Variable Selection in Labor Economics

**Dataset**: `webuse nlsy80`
**Estimated time**: ~25 minutes
**Difficulty**: ⬛⬛⬛⬛⬛

## Background
The NLSY 1980 cross-section contains wage, education, IQ, and work-history variables for 935 workers, making it a natural playground for wage equation estimation. LASSO (Least Absolute Shrinkage and Selection Operator) is increasingly used in labor economics to select predictors from a rich covariate set in a principled, data-driven way — avoiding the ad-hoc specification choices that plague traditional OLS.

## Your tasks

1. **Load and explore** — Load `webuse nlsy80`. List the variables available and summarize `lwage`, `educ`, `iq`, `exper`, `tenure`, `hours`, `kww`, and `sibs`. Note the ranges and whether any of these have missing values according to the reference table, then run `codebook` on `brthord`, `meduc`, and `feduc` to observe their missingness pattern.

2. **Fit a baseline OLS** — Regress `lwage` on `educ`, `exper`, `tenure`, `iq`, `kww`, `hours`, `sibs`, `married`, `black`, `south`, and `urban`. Record the coefficients and adjusted R². This is your benchmark specification.

3. **Run LASSO** — Use Stata's `lasso linear` command to fit a LASSO of `lwage` on the same eleven predictors as in Task 2. Use the default cross-validation (`cv`) selection method. After estimation, run `lassocoef` to display which variables were retained and with what coefficients. Compare the selected model to your OLS benchmark: which predictors were shrunk to zero?

4. **Post-LASSO OLS** — After the `lasso linear` command, use `lasso linear` followed by `estimates store lasso_cv`, then run `lassoselect` (or use the `post` option) to obtain the post-LASSO OLS estimates — i.e., re-estimate OLS using only the variables that LASSO retained. Store these results with `estimates store postlasso`. Then display both the full OLS (Task 2) and post-LASSO OLS side by side using `estimates table`.

5. *(Bonus)* **Adaptive LASSO / plug-in lambda** — Re-run `lasso linear lwage educ exper tenure iq kww hours sibs married black south urban` but this time use the `selection(plugin)` option instead of cross-validation. Compare the set of selected variables and the chosen penalty parameter (`e(lambda_sel)`) to the cross-validation result. Discuss in a comment why the plugin lambda might be preferred when the goal is valid post-selection inference rather than pure prediction.

- **Hint 1 (Task 3)**: The syntax for LASSO in Stata 16+ is `lasso linear depvar varlist, nfolds(#)` — the default for `cv` uses 10-fold cross-validation. After estimation, `lassocoef` accepts options like `, display(coef, penalized)` to show the penalized solution. Check `help lasso linear` for the exact syntax of the selection method option.

- **Hint 2 (Task 4)**: Post-LASSO OLS can be retrieved with `lasso postselection ols` after running `lasso linear`. Alternatively, look into the `coefpath` and the `, postselection` option. Store estimates with `estimates store` immediately after each regression so that `estimates table` can retrieve both sets of results simultaneously.
