## Background
The Grunfeld dataset contains annual investment, market value, and capital stock data for 10 large US firms over 20 years (1935–1954), making it a classic panel used in econometrics courses. Difference-in-differences (DiD) is a cornerstone identification strategy in labor and industrial economics, allowing researchers to estimate causal effects when treatment is assigned at the group level across time.

## Your tasks

1. **Declare panel structure** — Load the dataset, declare it as a balanced panel with `xtset`, and confirm the panel is indeed balanced by inspecting the output. How many firms and how many periods are there?

2. **Create a treatment indicator** — Create a binary variable `treated` equal to 1 for companies with `company` ID greater than 5, and 0 otherwise. Then create a `post` indicator equal to 1 for years after 1944 (i.e., `year >= 1945`), and 0 otherwise. Tabulate each new variable to verify the splits.

3. **Construct the interaction term and run a baseline DiD** — Generate an interaction variable `did = treated * post`. Run an OLS regression of `invest` on `treated`, `post`, and `did`. Report and interpret the coefficient on `did` — what does it represent in a DiD framework?

4. **Run a two-way fixed effects DiD** — Re-estimate the model using `xtreg` with firm fixed effects (`fe`) and add `post` and `did` as regressors. Note that with firm fixed effects, `treated` drops out — explain why. Then add `year` dummies to absorb time fixed effects (use `i.year`) and compare results with the simpler specification from Task 3.

5. *(Bonus)* **Parallel trends visualization** — Compute the mean of `invest` by `year` separately for the treated and control groups using `collapse` (or `egen`). Plot the two series over time (use `twoway line`) and visually assess whether the parallel trends assumption looks plausible before 1945. Describe what you observe.

- **Hint 1 (Task 1)**: The command `xtset` takes the panel identifier and the time variable as arguments — check `xtdescribe` after declaring to verify balance.
- **Hint 2 (Task 3)**: In a standard DiD setup, the coefficient on the interaction term `treated × post` captures the average treatment effect on the treated (ATT) — make sure you understand which group and which period each main effect refers to.
- **Hint 3 (Task 4)**: Firm fixed effects absorb all time-invariant firm-level characteristics, including the `treated` dummy itself (which never changes within a firm) — this is why it gets dropped. Look at the note Stata prints when a variable is omitted.
- **Hint 4 (Bonus)**: Before using `collapse`, preserve the data or work in a frame. `collapse (mean) invest, by(year treated)` will give you the group-year means you need for the plot.
