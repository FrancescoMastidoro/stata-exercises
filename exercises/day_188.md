## Background
The PSID extract contains 4,165 observations tracking 595 individuals across 7 time periods, with variables on wages, union status, occupation, industry, and demographics. Difference-in-differences (DiD) estimation is a cornerstone of modern labor economics, allowing researchers to identify causal effects by comparing changes over time between a "treated" and "control" group.

## Your tasks

1. **Load and explore the panel structure** — Load the dataset and declare it as a panel using `xtset`. Then use `xtdescribe` to verify the panel is balanced (all individuals observed in all 7 periods). Report how many unique individuals are in the dataset.

2. **Define a treatment indicator** — Create a binary variable `treated` equal to 1 if the individual is in a union (`union == 1`) in their *first* observed period (i.e., when `t == 1`), and 0 otherwise. Use `egen` to carry this fixed characteristic across all time periods for each individual. *(Hint: think about how to assign a time-invariant "ever treated at baseline" status using a group summary.)*

3. **Define a post-period indicator** — Create a binary variable `post` equal to 1 for time periods `t >= 4` and 0 otherwise. Then construct the DiD interaction term `did = treated * post`. Summarize `treated`, `post`, and `did` to confirm their distributions look sensible.

4. **Run the DiD regression** — Regress `lwage` on `treated`, `post`, and `did`, controlling for `ed`, `blk`, `fem`, and `south`. Interpret the coefficient on `did`: what does it estimate, and what identifying assumption underlies this estimate? Then re-run the same regression adding individual fixed effects using `xtreg, fe` — explain what changes and why the `treated` variable drops out.

5. *(Bonus)* **Event-study visualization** — Instead of collapsing the post period into a single dummy, create a separate interaction term `treated_t#` for each time period `t` (using `i.t#c.treated` or manually), omitting `t == 3` as the reference period. Run this event-study regression using `xtreg, fe` and use `coefplot` (if installed) or `marginsplot` to visualize whether pre-trends are flat before `t == 3`. Discuss what the pre-period coefficients tell you about the parallel trends assumption.
