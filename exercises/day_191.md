# Day 191: LASSO for Variable Selection in Labor Economics

**Dataset**: `webuse mroz87`
**Estimated time**: ~25 minutes
**Difficulty**: ⬛⬛⬛⬛⬛

## Background
The Mroz 1987 PSID dataset is a classic in labor economics, containing detailed information on married women's labor supply, wages, education, and family structure for 753 observations. LASSO (Least Absolute Shrinkage and Selection Operator) is a powerful regularization technique that automatically selects relevant predictors by shrinking coefficients toward zero, making it especially useful when you face many potential regressors and need a principled way to choose among them.

## Your tasks

1. **Load and explore** — Load `webuse mroz87`, then list the variables `wedyrs`, `wexper`, `hedyrs`, `hwage75`, `kl6`, `k618`, `mtr`, `unemprt`, `faminc`, and `lfp`. Run `summarize` on these variables to get a sense of the distributions you will be working with.

2. **Run a LASSO for binary outcome** — Use `lasso logit` to model `lfp` (wife's labor force participation, 0/1) as a function of `wedyrs`, `wexper`, `hedyrs`, `hwage75`, `kl6`, `k618`, `mtr`, `unemprt`, `faminc`, and `smsa`. Allow Stata to choose the penalty parameter automatically. After estimation, use `lassoselected` to inspect which variables were retained in the selected model.

3. **Compare with OLS-LASSO** — Now run `lasso linear` using the same outcome (`lfp`) and the same predictor set. Compare which variables are selected under `lasso linear` versus `lasso logit` from Task 2. Do both methods agree on which predictors matter most for labor force participation?

4. **Post-LASSO OLS estimation** — After running `lasso linear lfp ...`, use the `lassocoef` command to view the selected coefficients, then use `estimates store lasso_model`. Next, run a standard `regress` using only the variables that LASSO selected (from `lassoselected`), and use `estimates store ols_postlasso` to save this model. Use `estimates table lasso_model ols_postlasso` to compare coefficient magnitudes between the LASSO-shrunk estimates and the post-LASSO OLS estimates — explain in a comment why OLS coefficients are typically larger in absolute value.

5. *(Bonus)* **Cross-validation and the lambda path** — Re-run `lasso linear lfp wedyrs wexper hedyrs hwage75 kl6 k618 mtr unemprt faminc smsa` but this time explicitly specify `selection(cv, folds(10))` to use 10-fold cross-validation for selecting lambda. After estimation, type `cvplot` to visualize the cross-validation curve. Then use `lasso linear ..., selection(bic)` and compare which lambda selection method (CV vs. BIC) retains more variables in the final model.
