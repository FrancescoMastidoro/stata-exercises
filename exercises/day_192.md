## Background
The PSID extract contains 4,165 observations tracking 595 individuals across 7 time periods, with variables on wages, employment conditions, and demographics. Difference-in-differences (DiD) is a cornerstone method in labor economics for estimating causal effects of policies or treatments by comparing changes over time between treated and control groups.

## Your tasks

1. **Load and inspect the panel structure** — Load the dataset, then use `xtset` to declare the panel structure with `id` as the panel variable and `t` as the time variable. Confirm the structure with `xtdescribe` and report how many individuals and time periods are in the dataset.

2. **Define a treatment group and a post period** — Create a binary variable called `treated` equal to 1 if `union == 1` in the *first* period (`t == 1`) for a given individual (i.e., union status at baseline), and 0 otherwise. Use `egen` with `max` to assign this baseline status consistently to all observations for each individual. Then create a binary variable called `post` equal to 1 if `t >= 4` and 0 otherwise.

3. **Construct the interaction term and run a basic DiD regression** — Generate an interaction variable `did = treated * post`. Regress `lwage` on `treated`, `post`, and `did` using `reg`. Interpret the coefficient on `did` as your DiD estimate and note its sign and significance.

4. **Estimate the DiD with individual and time fixed effects** — Re-estimate the model using `xtreg, fe` to absorb individual fixed effects, including `post` and `did` as regressors (note: `treated` drops due to collinearity with fixed effects). Then add `i.t` to the regression instead of the single `post` dummy to account for time fixed effects flexibly. Compare the `did` coefficient across specifications.

5. *(Bonus)* **Test the parallel trends assumption informally** — Restrict the sample to the pre-treatment periods (`t < 4`) only. Interact `treated` with each time period indicator (`i.t`) and regress `lwage` on these interactions plus individual fixed effects using `xtreg, fe`. If parallel trends holds, coefficients on the `treated × t` interactions should be jointly insignificant — test this with `testparm`.
