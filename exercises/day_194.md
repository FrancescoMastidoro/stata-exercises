## Background
The Grunfeld dataset tracks investment, market value, and capital stock for 10 large U.S. firms across 20 years (1935–1954), making it a classic panel used in econometrics courses. Difference-in-differences (DiD) is a cornerstone identification strategy in labor and applied economics, allowing you to estimate causal effects by comparing changes over time across treated and control groups.

## Your tasks

1. **Load and explore the panel** — Load the dataset, then declare it as a panel using `xtset`. Confirm the panel structure by running `xtdescribe`. How many companies are there, and how many time periods does each span?

2. **Create a treatment indicator** — Define a binary variable `treated` equal to 1 for companies with `company <= 5` (the "treated" group) and 0 otherwise. Then create a `post` indicator equal to 1 for years strictly after 1944 (i.e., the second half of the sample) and 0 otherwise. Verify the counts of each group with `tabulate`.

3. **Construct the DiD interaction term and run the baseline regression** — Generate an interaction variable `did = treated * post`. Run an OLS regression of `invest` on `treated`, `post`, and `did`. Report and interpret the coefficient on `did`: what does it represent in a DiD framework?

4. **Upgrade to a two-way fixed effects (TWFE) estimator** — Re-run the DiD regression using `xtreg` with firm fixed effects (`fe`) and add `i.year` as a regressor to absorb time fixed effects. Compare the coefficient on `did` to the one from Task 3. Why might the two estimates differ, and which specification is more credible?

5. *(Bonus)* **Pre-trend check** — Instead of a single `post` dummy, create a full set of year dummies and interact each with `treated`. Using `xtreg, fe`, regress `invest` on the full set of `treated × year` interactions (omitting one year as the reference, e.g., 1944) and year fixed effects. Plot the interaction coefficients using `coefplot` (if installed) or inspect them manually. Do the pre-1945 interaction terms look close to zero, supporting the parallel trends assumption?
