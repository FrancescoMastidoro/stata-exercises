## Background
The NLSY 1980 cross-section tracks 935 individuals with information on wages, education, family background, and cognitive ability, making it a classic testbed for the returns-to-education literature. Instrumental variables (IV) estimation is essential in labor economics because education is endogenous — unobserved ability simultaneously drives both schooling decisions and wages.

## Your tasks

1. **OLS baseline** — Load the dataset and estimate a standard OLS regression of `lwage` on `educ`, `exper`, `tenure`, `married`, `black`, `south`, and `urban`. Report and interpret the coefficient on `educ`.

2. **Check instrument relevance** — Before running IV, regress `educ` on the proposed instrument `feduc` (father's education) plus all the controls listed in Task 1 (first-stage regression). Report the F-statistic on `feduc` and comment on whether it exceeds the conventional threshold of 10 for a strong instrument. Note that `feduc` has 194 missing values — keep this in mind when comparing sample sizes.

3. **IV estimation** — Use `ivregress 2sls` to estimate the wage equation instrumenting `educ` with `feduc`, controlling for the same regressors as in Task 1. Compare the IV coefficient on `educ` to the OLS estimate: does it rise or fall, and what does that tell you about the direction of ability bias?

4. **Test for endogeneity** — After the `ivregress` command, run `estat endogenous` to perform the Durbin–Wu–Hausman test. State the null hypothesis, report the p-value, and explain whether you can reject exogeneity of `educ` at the 5% level.

5. *(Bonus)* **Two instruments** — Re-estimate the model using both `feduc` and `meduc` as instruments for `educ`. Note that `meduc` also has missing values (78 missing). After estimation, run `estat overid` to test the overidentifying restriction (Sargan–Hansen test). Report the p-value and interpret what it implies about the joint validity of the two instruments.

## Hints

- **Hint 1** *(Task 2)*: A first-stage F-statistic can be obtained by running `regress educ feduc [controls]` and then using `test feduc` — or simply reading the partial F from the first-stage output. Look for the line Stata prints automatically when you run `ivregress` with the `first` option.

- **Hint 2** *(Task 3)*: The syntax for `ivregress 2sls` follows the pattern `ivregress 2sls depvar controls (endogenous = instruments)`. The endogenous variable goes inside the parentheses on the left of `=`, and the excluded instrument goes on the right.

- **Hint 3** *(Task 4)*: `estat endogenous` is a post-estimation command that must immediately follow `ivregress`. The null hypothesis is that the suspected endogenous variable (`educ`) is in fact exogenous — i.e., OLS is consistent. Rejecting the null favors IV.

- **Hint 4** *(Bonus)*: When you have more instruments than endogenous variables, the model is over-identified and you can test whether the extra instruments are valid with `estat overid`. A high p-value (fail to reject) is the desirable outcome, suggesting the instruments are not correlated with the error term.
