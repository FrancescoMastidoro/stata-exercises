## Background
The PSID extract contains 4,165 observations on 595 workers observed over 7 time periods, with variables capturing wages, union membership, demographic characteristics, and job conditions. Difference-in-differences (DiD) is a cornerstone of applied labor economics, using panel variation in treatment timing or status to identify causal effects while controlling for unobserved time-invariant heterogeneity.

## Your tasks

1. **Load and describe** — Load the dataset with `webuse psidextract`. Use `xtset` to declare the panel structure (the individual identifier is `id`, the time variable is `t`). Then run `xtdescribe` to confirm the panel is strongly balanced.

2. **Create a treatment indicator** — Define a binary variable `treated` equal to 1 if the worker is ever observed as unionized (`union == 1`) in *any* period, and 0 otherwise. Use `egen` with the `max()` function, grouped by `id`. Tabulate `treated` to see how many workers ever joined a union across the 7 periods.

3. **Define a post-treatment period** — Create a variable `post` equal to 1 if `t >= 4` and 0 otherwise (splitting the panel into an early and a late phase). Then create the DiD interaction term `did = treated * post`. Summarize all three new variables (`treated`, `post`, `did`) to confirm they are correct.

4. **Estimate the DiD model** — Regress `lwage` on `treated`, `post`, and `did`, controlling for `ed`, `exp`, `blk`, and `fem`. First run a standard OLS (`regress`), then re-estimate using `xtreg` with the `fe` option to absorb worker fixed effects. Compare the coefficient on `did` across the two specifications — what does the change tell you about time-invariant confounders?

5. *(Bonus)* **Cluster standard errors and assess parallel trends** — Re-run the `xtreg, fe` model but add `vce(cluster id)` to account for serial correlation within workers. Then, restricting the sample to periods `t <= 3` (the pre-treatment window), regress `lwage` on `treated`, a set of period dummies (`i.t`), and their interactions (`treated#i.t`) — if parallel trends holds, none of the pre-period interaction coefficients should be statistically significant. Comment on what you find.
