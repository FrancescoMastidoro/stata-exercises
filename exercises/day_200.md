## Background
The NLSY 1980 dataset contains earnings, cognitive ability, education, and demographic information for a cross-section of workers, making it ideal for wage determination research. LASSO (Least Absolute Shrinkage and Selection Operator) is a powerful regularization method that automatically selects relevant predictors from a large candidate set — increasingly standard in modern labor economics for model selection and causal inference.

## Your tasks

1. **Load and explore the candidate predictors** — Load the dataset with `webuse nlsy80`. List all variables and identify which ones could plausibly predict `lwage` (log wage). Then run a standard OLS regression of `lwage` on `educ`, `exper`, `tenure`, `iq`, `kww`, `age`, `hours`, `sibs`, `married`, `black`, `south`, and `urban`. Note the R² and number of predictors.

2. **Run a LASSO regression** — Use `lasso linear lwage` with the same twelve predictors listed in Task 1. Allow Stata to choose the penalty parameter via cross-validation (the default). After estimation, display which variables were selected by typing `lassocoef` and compare the selected set to the OLS specification.

3. **Inspect the regularization path** — After the LASSO from Task 2, type `lassoinfo` to see the cross-validation results, and then use `cvplot` to visualize how the cross-validation criterion varies across penalty values (lambda). Identify whether the selected lambda corresponds to the minimum CV error or to the one-standard-error rule, and explain in a comment what that distinction means.

4. **Post-LASSO OLS** — After LASSO variable selection, Stata can automatically run OLS on only the selected variables. Use the `lasso linear` result together with the `poregress` command to obtain post-LASSO OLS estimates. Compare these coefficients to the full OLS from Task 1: which variables were shrunk to zero by LASSO, and did dropping them visibly change the remaining coefficients?

5. *(Bonus)* **Double-LASSO for causal inference** — Suppose you want to estimate the causal effect of `educ` on `lwage` while controlling for the other eleven variables as potential confounders. Use `dsregress lwage educ, controls(exper tenure iq kww age hours sibs married black south urban)` (Stata's double-selection LASSO command). Compare the resulting coefficient on `educ` to the plain OLS estimate from Task 1. In a comment, explain in one or two sentences why double-LASSO gives a more credible estimate than simply using whichever variables the naive LASSO happened to keep.

## Hints
<details>
<summary>Click to reveal hints (try first!)</summary>

- **Hint 1 (Task 2)**: The syntax for LASSO in Stata 16+ is `lasso linear depvar varlist`. Stata selects lambda by cross-validation by default; you do not need to specify any options to get a reasonable result. `lassocoef` with no options shows the coefficients at the selected lambda.

- **Hint 2 (Task 3)**: After `lasso linear`, `cvplot` plots the cross-validation function. The two vertical lines you see correspond to the lambda that minimises CV error (`lambda_cv`) and the largest lambda within one standard error of the minimum (`lambda_1se`). Stata's default selection rule uses `lambda_cv`; a comment in your do-file explaining the bias–variance trade-off between these two choices is all that is required here.

- **Hint 3 (Task 4)**: `poregress` (post-regularization OLS) is a post-estimation command that uses the variables selected by the most recent `lasso linear` call. You do not need to re-specify any variable names.

- **Hint 4 (Task 5)**: `dsregress` implements the Belloni–Chernozhukov–Hansen (2014) double-selection procedure. It runs two LASSOs — one for the outcome and one for the treatment — and then includes the union of selected controls in an OLS regression for the treatment variable, protecting against omitted-variable bias that arises when the naive LASSO drops a confounder correlated with the treatment.
