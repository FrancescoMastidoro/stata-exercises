## Background
The Grunfeld dataset contains annual firm-level investment data for 10 companies observed over 20 years (1935–1954), making it a classic panel used to study capital investment dynamics. Difference-in-differences (DiD) is one of the most important quasi-experimental designs in labor and applied economics, allowing you to estimate causal effects by comparing changes over time across treated and untreated groups.

## Your tasks

1. **Load and declare panel structure** — Load the dataset with `webuse grunfeld`, then declare the panel structure using `xtset` with `company` as the panel identifier and `year` as the time variable. Confirm the setup by typing `xtset` alone and inspecting the output.

2. **Create a treatment indicator** — Using `gen`, create a binary variable called `treated` equal to 1 for companies with `company <= 5` (the "treated" group) and 0 otherwise. Then create a post-period indicator called `post` equal to 1 for years after 1944 (i.e., `year > 1944`) and 0 otherwise. Tabulate both new variables to confirm they look right.

3. **Construct the interaction term and run the DiD regression** — Create an interaction variable `did = treated * post`. Run an OLS regression of `invest` on `treated`, `post`, and `did`. Interpret the coefficient on `did`: what does it represent in a DiD framework?

4. **Add firm and year fixed effects** — Re-estimate the DiD model using `xtreg` with the `fe` option to absorb firm fixed effects, then separately use `areg` with `absorb(company)` and manually include year dummies via `i.year`. Compare the coefficient on `did` across specifications. Does controlling for firm and year fixed effects change your estimate substantially?

5. *(Bonus)* **Parallel trends check** — Drop the `post` variable temporarily and instead create five separate dummy variables for 5-year sub-periods (e.g., 1935–1939, 1940–1944, 1945–1949, 1950–1954). Interact each period dummy with `treated` and run the regression including firm fixed effects. Plot or inspect the pre-period interaction coefficients: if the parallel trends assumption holds, what pattern would you expect to see before 1945?

## Hints

- **Hint 1 (Task 2)**: Remember that `gen treated = (company <= 5)` produces a 0/1 variable directly from a logical condition — no `if` branching needed.
- **Hint 2 (Task 3)**: In a standard DiD setup, the coefficient on the interaction term captures the *average treatment effect on the treated* (ATT) — the extra change in the outcome for the treated group after the treatment period, relative to what the control group experienced.
- **Hint 3 (Task 4)**: When using `xtreg, fe`, Stata automatically absorbs the panel (firm) fixed effect. To additionally control for year fixed effects, add `i.year` to the regressor list. The `areg` approach with `absorb(company)` does the same for firm effects — try adding `i.year` there too and compare.
- **Hint 4 (Bonus)**: You can create period dummies efficiently with conditions like `gen period2 = (year >= 1940 & year <= 1944)`. Think about which period you should *omit* as the reference category and why it matters for the pre-trends test.
