## Background
The NLSY 1980 cross-section contains wages, cognitive test scores, education, and demographic characteristics for 935 workers, making it a classic dataset for studying the determinants of earnings. LASSO (Least Absolute Shrinkage and Selection Operator) is increasingly used in labor economics to select among many candidate regressors in a data-driven, penalized way — reducing the risk of over-fitting when the researcher is uncertain which controls belong in a wage equation.

## Your tasks

1. **Load and explore** — Load the dataset with `webuse nlsy80`. Summarize the variables `lwage`, `educ`, `iq`, `kww`, `exper`, `tenure`, `hours`, `sibs`, `age`, `married`, `black`, `south`, and `urban`. Note which variables are binary and which are continuous. Confirm that `lwage` ranges approximately from 4.74 to 8.03 and that there are no missing values in any of these variables.

2. **OLS benchmark** — Regress `lwage` on the full set of regressors listed in Task 1 (excluding `lwage` itself) using OLS. Record the coefficients on `educ`, `iq`, and `exper`, and note the R-squared. This will serve as your benchmark against which to compare the LASSO results.

3. **Run LASSO** — Use Stata's `lasso linear` command to regress `lwage` on the same set of predictors used in Task 2. Use the default cross-validation method to select the penalty parameter λ. After estimation, display the selected variables using `lassocoef` and identify which predictors LASSO retains and which it shrinks to zero.

4. **Post-LASSO OLS** — Use the `lassoselect` and `lasso linear` post-estimation machinery to run a post-LASSO OLS regression: after your `lasso linear` estimation, use `lasso postselection` (or equivalently retrieve the selected variables with `lassocoef, display` and then manually run `regress lwage` on only those selected variables). Compare the post-LASSO OLS coefficient on `educ` with the full OLS coefficient from Task 2. Discuss briefly in a comment (`//`) whether shrinkage has materially changed the education return.

5. *(Bonus)* **Cross-validated λ path** — Use `cvplot` after your `lasso linear` estimation to plot the cross-validated mean-squared prediction error against log(λ). Identify from the plot (or from `e(lambda)`) the optimal λ chosen by cross-validation, and re-run `lasso linear` manually specifying that exact λ value using the `lambda()` option to confirm you reproduce the same selected variables.

## Hints

- **Hint 1 (Task 3)**: The syntax for penalized linear regression in Stata 16+ is `lasso linear depvar varlist`. By default, Stata uses cross-validation to choose λ — you do not need to specify any penalty option. After running it, `lassocoef` (with no options) lists the coefficients at the selected λ; variables absent from the output have been shrunk to exactly zero.

- **Hint 2 (Task 4)**: After `lasso linear`, Stata stores the names of the selected variables. You can pass them directly to `regress` by using `lasso postselection` or by wrapping the selected variable list in `lassocoef, display`. A convenient shortcut is `lasso linear ..., postselection` together with the `coefpath` post-estimation — but the simplest approach for a beginner is to read off the retained regressors from `lassocoef` and type them explicitly into a new `regress` command.
