## Background
The PSID extract contains 4,165 observations on 595 individuals tracked over 7 time periods, with information on wages, employment characteristics, union status, and demographics. Difference-in-differences (DiD) is a cornerstone of modern labor economics causal inference, exploiting variation in treatment timing across groups to identify causal effects on outcomes like log wages.

## Your tasks

1. **Load and explore the panel structure** — Load the dataset, then use `xtset` to declare the panel structure using `id` as the individual identifier and `t` as the time variable. Confirm the panel is strongly balanced by checking how many observations each individual contributes using `xtdescribe`.

2. **Define treatment and post indicators** — Create a binary variable `treated` equal to 1 if the worker is in a union (`union == 1`) *at period t = 1* (i.e., assign treatment based on initial union status, so it is time-invariant). Then create a binary variable `post` equal to 1 for periods `t >= 4`. Use `bysort id` logic and `gen`/`replace` carefully.

3. **Construct the DiD interaction term and run the baseline regression** — Generate an interaction variable `did = treated * post`. Regress `lwage` on `treated`, `post`, and `did`. Report the coefficient on `did` and interpret it: does early union membership raise wages in later periods relative to never-union workers?

4. **Improve the DiD with fixed effects** — Re-run the DiD regression using `xtreg lwage post did, fe` (absorbing individual fixed effects, which subsume `treated`). Also add `ed`, `exp`, and `south` as time-varying controls. Compare the DiD coefficient to Task 3 and explain why the fixed-effects estimate differs.

5. *(Bonus)* **Parallel trends check** — Restrict the sample to periods `t <= 3` (the pre-treatment window). Run a regression of `lwage` on an interaction between `treated` and period dummies for `t = 2` and `t = 3` (using `i.t#c.treated`), controlling for individual fixed effects with `xtreg, fe`. Interpret whether the pre-trends are close to zero, which is required for DiD validity.

- **Hint 1 (Task 2)**: To assign a time-invariant treatment based on the *first* period's union status, try `bysort id (t): gen treated = union[1]` — this picks the first observation's value for each individual and assigns it to all rows for that person.
- **Hint 2 (Task 4)**: When you use `xtreg, fe`, Stata automatically removes within-individual time-invariant variables (like `treated`) because they are collinear with the individual fixed effects — this is expected behavior, not an error. The `did` interaction remains identified because `post` varies over time.
