## Background
The NLSY 1980 cross-section contains data on wages, education, cognitive ability, and family background for 935 individuals, making it a classic testbed for human capital research. Instrumental variables (IV) estimation is essential in labor economics when a key regressor — like education — is endogenous due to unobserved ability or family effects.

## Your tasks

1. **Explore the instrument candidates** — Load the dataset and summarize `educ`, `lwage`, `iq`, `meduc`, and `feduc`. Report the number of missing values for `meduc` and `feduc`, and think about whether parental education could plausibly serve as instruments for own education.

2. **OLS baseline** — Regress `lwage` on `educ`, `exper`, `tenure`, `black`, `south`, and `urban` using OLS. Note the coefficient and standard error on `educ`.

3. **IV estimation with a single instrument** — Re-estimate the same wage equation using `ivregress 2sls`, instrumenting `educ` with `meduc`. Remember to account for the missing values in `meduc` by restricting to the usable sample (use `if !missing(meduc)` so both OLS and IV are comparable). Compare the IV coefficient on `educ` to the OLS coefficient.

4. **Test instrument relevance and run an overidentification test** — Add `feduc` as a second instrument alongside `meduc`. After running the IV regression, use `estat firststage` to inspect the first-stage F-statistic, and then use `estat overid` to run the Sargan–Hansen overidentification test. Report what each test tells you about instrument validity.

5. *(Bonus)* **LIML estimation** — Re-run the two-instrument IV specification using the `liml` estimator instead of `2sls` inside `ivregress`. Compare the LIML and 2SLS coefficients on `educ`. Under what conditions would LIML be preferred, and does the difference here appear economically meaningful?
