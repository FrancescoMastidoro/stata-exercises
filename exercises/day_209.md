## Background
The Grunfeld dataset contains firm-level panel data on investment, market value, and capital stock for 10 large US firms observed annually from 1935 to 1954. Instrumental variables (IV) estimation is a cornerstone of causal inference in labor and industrial economics, allowing researchers to isolate exogenous variation when regressors are suspected to be endogenous.

## Your tasks

1. **Explore the panel structure** — Load the dataset, declare it as a panel with `xtset`, and summarize all six variables. Report the number of firms, the number of time periods, and the overall range of `invest`.

2. **Run an OLS baseline** — Regress `invest` on `mvalue` and `kstock` using `xtreg` with fixed effects (`fe`). Note the coefficients on both regressors and the within-R² — you will compare these to the IV results later.

3. **Run an IV regression with `ivregress`** — Suppose you suspect `mvalue` is endogenous. Use `ivregress 2sls` to instrument `mvalue` with `kstock` and `time`, while still controlling for `kstock` directly as an exogenous regressor. Include the `robust` option and report the coefficient on `mvalue`.

4. **Test instrument relevance** — After the `ivregress` command from Task 3, run the first-stage regression manually using `regress` (regress `mvalue` on `kstock` and `time`). Report the F-statistic and comment on whether the instrument `time` appears to be strong (conventional threshold: F > 10).

5. *(Bonus)* **Hausman-style endogeneity check** — After running both OLS (`regress invest mvalue kstock`) and 2SLS (same specification as Task 3), use `estat endogenous` following the `ivregress` command to formally test whether `mvalue` is endogenous. Interpret the p-value at the 5% significance level.

- **Hint 1 (Task 2)**: After `xtset company year`, the syntax for a fixed-effects panel regression is `xtreg depvar indepvars, fe` — look at the `R-sq: within` line in the output for the within-R².

- **Hint 2 (Task 3)**: In `ivregress 2sls`, endogenous regressors go in parentheses as `(endogenous_var = instruments)`. Variables listed *outside* the parentheses are treated as exogenous controls — `kstock` should appear both outside the parentheses and as part of the instrument list inside them.

- **Hint 3 (Task 4)**: The first stage is just a standard OLS regression of the suspected endogenous variable on all exogenous variables (instruments + included exogenous controls). Check the overall model F-statistic from the `regress` output — this is what you compare to the threshold of 10.

- **Hint 4 (Task 5)**: `estat endogenous` must be run *immediately after* `ivregress` — it uses stored results. The null hypothesis of this test is that the suspected endogenous variable *is* actually exogenous; a small p-value gives you reason to prefer IV over OLS.
