## Background
The `regsmpl` dataset is a panel of NLS women observed from 1968 to 1988, containing wage and demographic information across multiple years. Difference-in-differences (DiD) is a cornerstone identification strategy in labor economics, used to estimate causal effects by comparing changes over time between a treated and a control group.

## Your tasks

1. **Load and describe the panel** — Load the dataset with `webuse regsmpl`, then use `xtset` to declare the panel structure (individual identifier and year). Confirm the panel is set correctly by running `xtdescribe` and noting whether the panel is balanced or unbalanced.

2. **Define a treatment indicator** — Create a binary variable called `post` equal to 1 if `year >= 80` (i.e., 1980 onward) and 0 otherwise. Then create a binary variable called `treated` equal to 1 if `black == 1` and 0 otherwise. Tabulate both new variables to confirm they were created correctly.

3. **Construct the interaction term and run a basic DiD** — Generate an interaction variable `did = treated * post`. Run an OLS regression of `ln_wage` on `treated`, `post`, and `did`. Interpret the coefficient on `did` as the DiD estimate: what does it capture?

4. **Add controls and fixed effects** — Re-run the DiD regression including `ttl_exp`, `grade`, and `tenure` as controls, and add individual fixed effects using `xtreg, fe`. Compare the DiD coefficient from this specification to the one from Task 3 — does controlling for individual heterogeneity change the estimate substantially?

5. *(Bonus)* **Parallel trends check** — Restrict the sample to the pre-treatment period (`year < 80`). Create year dummies interacted with `treated` and regress `ln_wage` on these interaction terms (plus `ttl_exp` as a control). Plot the coefficients using `coefplot` (if installed) or inspect them manually. Do the pre-treatment trends for `black` and non-`black` women look parallel?

- **Hint 1 (Task 1)**: After `webuse regsmpl`, look up the panel identifiers in the dataset description — the panel is structured by individual (`idcode`) and time (`year`). The command `xtset idcode year` declares the structure; `xtdescribe` reports gaps.

- **Hint 2 (Task 3)**: Remember that in a classic DiD setup, `treated` captures the baseline difference between groups, `post` captures the common time trend, and the coefficient on `did` (the interaction) is your causal estimate of interest. You can generate the interaction manually with `gen did = treated * post` before including it in `regress`.

- **Hint 3 (Task 4)**: With `xtreg, fe`, Stata automatically absorbs the individual fixed effects, so you do not need to include `treated` as a separate regressor — it is collinear with the fixed effects. You still include `post` and `did` along with your time-varying controls. Note that `grade` has 2 missing values, which Stata will drop automatically.

- **Hint 4 (Bonus)**: A parallel trends check looks for statistically insignificant pre-period interaction coefficients. Use `i.year##treated` syntax within the restricted sample to generate all interactions efficiently, then examine whether coefficients in years before 1980 are close to zero.
