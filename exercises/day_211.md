## Background
The PSID extract contains 4,165 observations on 595 individuals tracked across 7 time periods, with variables covering wages, employment characteristics, and demographics. Difference-in-differences (DiD) is a cornerstone identification strategy in labor economics, exploiting variation in treatment timing across groups to recover causal effects while controlling for time-invariant confounders.

## Your tasks

1. **Load and inspect the panel structure** — Load the dataset, then declare the panel structure using `xtset` with `id` as the panel variable and `t` as the time variable. Use `xtdescribe` to confirm the panel is strongly balanced.

2. **Define treatment groups and a post period** — The variable `union` indicates whether a worker is covered by a union contract. Create a binary variable `post` equal to 1 when `t >= 4` and 0 otherwise. Then tabulate `union` and `post` jointly (using `tab union post`) to understand the composition of the DiD design. Note: because `union` varies over time, treat it as a time-varying treatment for now.

3. **Run a basic DiD regression** — Regress `lwage` on `union`, `post`, and their interaction `union#post` (or create an interaction variable manually). Include `south`, `smsa`, `occ`, and `ed` as controls. Use `xtreg` with the `fe` option to absorb individual fixed effects. Interpret the sign and magnitude of the interaction coefficient.

4. **Assess parallel trends visually** — Collapse the data to cell means by `union` and `t` using `collapse (mean) lwage, by(union t)`. Then use `twoway` to plot `lwage` against `t` for union and non-union workers on the same graph (use two `connected` plots distinguished by color or symbol). Examine whether trends look approximately parallel before `t = 4`.

5. *(Bonus)* **Add individual fixed effects and cluster-robust standard errors** — Return to the full dataset (reload it). Re-estimate the DiD model from Task 3 using `xtreg, fe` but add the `vce(cluster id)` option to account for serial correlation within individuals. Compare the standard error on the interaction term to the unclustered version and comment on whether inference changes.
