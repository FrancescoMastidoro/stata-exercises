## Background
The NLSY 1980 cross-section contains detailed information on wages, cognitive ability, education, and work history for a sample of workers, making it an ideal testbed for high-dimensional variable selection. LASSO regression is increasingly used in labor economics to select predictors of earnings from a large candidate set without overfitting, complementing traditional OLS approaches.

## Your tasks

1. **Load and explore the wage distribution** — Load the dataset and summarize `lwage`, `educ`, `iq`, `kww`, `exper`, and `tenure`. Note the range of `lwage` and identify whether `brthord`, `meduc`, and `feduc` have missing values that need to be addressed before LASSO estimation.

2. **Run a standard OLS benchmark** — Regress `lwage` on `educ`, `exper`, `tenure`, `iq`, `kww`, `age`, `married`, `black`, `south`, `urban`, and `sibs`. Store the results and note the R-squared. This will serve as your benchmark for comparing LASSO performance.

3. **Run LASSO with the same candidate variables** — Use the `lasso linear` command to regress `lwage` on the same set of predictors as in Task 2. After estimation, use `lassocoef` to display the selected coefficients. Record which variables LASSO retains and which it shrinks to zero.

4. **Post-LASSO OLS estimation** — Use the `lasso linear` result from Task 3 to run a post-LASSO OLS regression: use `lassoselect` (or the `coefpath` approach) to identify the selected variables, then manually run `regress lwage` on only the LASSO-selected variables. Compare the coefficients and standard errors to your OLS benchmark from Task 2 and comment on any notable differences.

5. *(Bonus)* **Cross-validated LASSO and lambda selection** — Re-run `lasso linear` using cross-validation (`cv` option) to let Stata choose the penalty parameter `lambda` automatically. Plot the cross-validation function with `cvplot`. Compare the selected variables under cross-validated lambda to those selected under the default lambda in Task 3, and discuss what this implies about the bias-variance tradeoff in your wage model.

After estimation, `lassocoef` displays which predictors survived penalization — look for variables whose coefficients are set exactly to zero by the LASSO penalty.

- **Hint 3 (Task 4)**: Post-LASSO OLS corrects the shrinkage bias introduced by the LASSO penalty. Once you identify the selected variables from `lassocoef`, simply pass them to a standard `regress` command. Pay attention to whether `iq` and `kww` are both retained — economic theory suggests ability measures should matter for wages even after controlling for education.

- **Hint 4 (Bonus)**: The `cv` suboption inside `lasso linear` triggers *k*-fold cross-validation. After running it, `cvplot` produces a graph of the mean squared prediction error against log(lambda). The lambda that minimizes CV error is `e(lambda_cv)` — you can retrieve it and compare variable selection under this lambda versus the default.
