## Background
The Grunfeld dataset is a classic balanced panel of 10 large US firms observed annually from 1935 to 1954, containing firm-level investment, market value, and capital stock. Difference-in-differences (DiD) estimation is a cornerstone method in labor and industrial economics for recovering causal effects when randomization is infeasible, by comparing changes over time across treated and untreated groups.

## Your tasks

1. **Declare the panel structure** — Load the dataset and declare it as a panel using `xtset`, with `company` as the panel identifier and `year` as the time variable. Then use `xtdescribe` to confirm the panel is strongly balanced.

2. **Create a treatment indicator** — Define a binary variable `treated` equal to 1 for companies 1–5 (the "treated" group) and 0 for companies 6–10 (the "control" group). Then create a binary variable `post` equal to 1 for years 1945 and later, and 0 otherwise. Tabulate both variables to verify they are correctly constructed.

3. **Construct the interaction term and run a DiD regression** — Generate a variable `did` as the product of `treated` and `post`. Regress `invest` on `treated`, `post`, and `did`, using `vce(robust)` standard errors. Report the coefficient on `did` and interpret its sign: does treatment appear to increase or decrease investment after 1945 for the treated group?

4. **Absorb firm and year fixed effects** — Re-estimate the DiD model using `xtreg invest post did, fe vce(robust)` (note: with firm fixed effects, `treated` is absorbed). Then separately run `reghdfe invest did, absorb(company year) vce(robust)` if `reghdfe` is installed, or use `areg invest post did i.year, absorb(company) vce(robust)` as an alternative. Compare the coefficient on `did` across the two-way fixed-effects specification and the simple DiD from Task 3 — does controlling for firm and year fixed effects change the estimate meaningfully?

5. *(Bonus)* **Parallel trends inspection** — Generate a variable `time_to_treat` equal to `year - 1945` interacted with `treated` for each year (i.e., create dummies for each year, interact them with `treated`, and exclude the year 1944 as the reference period). Run an event-study regression of `invest` on these interaction terms plus firm and year fixed effects. Plot or tabulate the coefficients for pre-treatment years — if the parallel trends assumption holds, what pattern would you expect to see?

## Hints
<details>
<summary>Click to reveal hints (try first!)</summary>

- **Hint 1 (Task 2)**: `generate treated = (company <= 5)` uses a logical condition that evaluates to 1 when true and 0 when false — the same approach works for `post` using a condition on `year`.
- **Hint 2 (Task 3)**: The DiD estimator is the coefficient on the interaction term `treated × post`. In a simple OLS DiD, the coefficient on `treated` captures the pre-existing level difference between groups, `post` captures the common time trend, and `did` isolates the treatment effect.
- **Hint 3 (Task 4)**: When you include firm fixed effects (`fe` in `xtreg`, or `absorb(company)` in `areg`/`reghdfe`), the `treated` dummy drops out automatically because it does not vary within firms over time — this is expected, not an error.
- **Hint 4 (Bonus)**: An event-study specification requires creating interaction dummies like `i.year#c.treated` or manually generating `treated_1935`, `treated_1936`, etc. The pre-treatment coefficients should be statistically indistinguishable from zero if parallel trends holds before the treatment cutoff.
