# Day 218: LASSO for Variable Selection in Labor Economics

**Dataset**: `webuse nlsy80`
**Estimated time**: ~25 minutes

## Background
The NLSY 1980 dataset contains a rich set of individual-level variables — including wages, education, cognitive ability, work history, and family background — making it an ideal playground for high-dimensional variable selection. LASSO (Least Absolute Shrinkage and Selection Operator) is increasingly used in labor economics to select controls in wage regressions without relying solely on researcher discretion.

## Your tasks

1. **Load and inspect** — Load the dataset with `webuse nlsy80`. List all variables and check which ones have missing values. Then keep only observations with non-missing values for `brthord`, `meduc`, and `feduc`, since these variables have documented missingness. How many observations remain?

2. **Run a baseline OLS** — Regress `lwage` on `educ`, `exper`, `tenure`, `iq`, `kww`, `age`, `married`, `black`, `south`, `urban`, `sibs`, `hours`, and `college` using standard OLS. Note the coefficient on `educ` and the R-squared for comparison with LASSO output.

3. **Apply LASSO for prediction** — Use Stata's `lasso linear` command to regress `lwage` on the same set of predictors as in Task 2. Use the default cross-validation criterion to select the penalty parameter. After estimation, run `lassocoef` to display which variables were retained in the selected model.

4. **Post-LASSO OLS** — After `lasso linear`, use `lasso linear` followed by the `postselection` option — or use `lassoselect` and then run OLS manually — to fit a post-LASSO OLS regression using only the variables LASSO retained. Compare the coefficient on `educ` to the one from Task 2. Does LASSO retain `educ`? Does the R-squared change meaningfully?

5. *(Bonus)* **Cross-fit partialling out** — Use Stata's `xporegress` command (cross-fit partialling-out OLS) to estimate the effect of `educ` on `lwage`, using all remaining predictors (`exper`, `tenure`, `iq`, `kww`, `age`, `married`, `black`, `south`, `urban`, `sibs`, `hours`, `college`) as controls. Compare the resulting coefficient and confidence interval on `educ` to the plain OLS estimate from Task 2. What does double-selection add conceptually?
