## Background
The `regsmpl` dataset is a panel of NLS women observed across survey years from 1968 to 1988, containing wages, education, work experience, and geographic identifiers. Difference-in-Differences (DiD) is a cornerstone identification strategy in labor economics, exploiting variation across groups and time to estimate causal effects while controlling for time-invariant unobservables.

## Your tasks

1. **Load and inspect the panel** — Load the dataset with `webuse regsmpl`, then use `xtset` to declare the panel structure using `idcode` and `year`. Confirm the declaration with `xtdescribe` and report how many individuals and time periods are represented.

2. **Construct a post-treatment indicator** — Create a binary variable called `post` equal to 1 if `year >= 78` (i.e., 1978 onward) and 0 otherwise. Then, create a binary "treated group" indicator called `treated` equal to 1 if an individual is `black == 1`, and 0 otherwise. Verify both variables are correct using `tabulate`.

3. **Build the interaction term and run a baseline DiD** — Generate an interaction variable `did = treated * post`. Then regress `ln_wage` on `treated`, `post`, and `did` using `regress`, clustering standard errors at the `idcode` level. Interpret the coefficient on `did` as your DiD estimate.

4. **Add individual and time fixed effects** — Re-estimate the model using `xtreg` with the within (`fe`) estimator, including `post` and `did` as regressors (note: `treated` drops out under individual FE). Also add `ttl_exp` and `tenure` as controls — be mindful that `tenure` has 433 missing values and handle them appropriately by noting how the sample size changes. Cluster standard errors at the `idcode` level and compare your DiD estimate to Task 3.

5. *(Bonus)* **Parallel trends check via event-study** — Instead of a single `post` dummy, create a set of year dummies interacted with `treated` (omitting one pre-treatment year as the reference, e.g. `year == 77`). Run an `xtreg` with these interactions and individual fixed effects, then use `coefplot` (if installed) or manually `lincom` two of the pre-period interaction coefficients to assess whether pre-treatment trends differ between black and non-black women. What would a violation of parallel trends look like in this context?
