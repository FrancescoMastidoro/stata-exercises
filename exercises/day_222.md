## Background
The Mroz 1987 PSID dataset contains detailed information on married women's labor supply decisions, wages, and household characteristics — a classic benchmark in labor economics. LASSO (Least Absolute Shrinkage and Selection Operator) is a powerful regularization method that automatically selects relevant predictors from a large set of candidates, making it especially useful when theory alone does not guide which controls to include in a wage regression.

## Your tasks

1. **Load and explore the wage variable** — Load the dataset with `webuse mroz87`. Summarize `wwage76` (wife's hourly wage in 1976) and `wedyrs` (wife's years of education). How many observations have `wwage76 == 0`? What does this tell you about the sample?

2. **Fit a standard OLS benchmark** — Regress `wwage76` on `wedyrs`, `wexper`, `wifeage`, `kl6`, `k618`, `smsa`, and `hedyrs` using `regress`. Note the coefficient on `wedyrs` and the R-squared — you will compare these against the LASSO results.

3. **Run LASSO with the same predictors** — Use `lasso linear wwage76 (wedyrs wexper wifeage kl6 k618 smsa hedyrs)` with the option `rseed(42)` to ensure reproducibility. Examine the output: which variables does LASSO retain after penalization, and which are shrunk toward zero or dropped?

4. **Expand the candidate predictor set** — Re-run LASSO adding `hwage75`, `mtr`, `unemprt`, `hsib`, `wsib`, `hfedyrs`, `hmedyrs`, and `nwinc` to the predictor list. Use `rseed(42)`. Compare the selected variables and the cross-validated mean squared error to the smaller model from Task 3. Does the richer candidate set change which variables survive selection?

5. *(Bonus)* **Post-LASSO OLS** — After running the larger LASSO in Task 4, use `lassocoef` to identify the selected variables, then manually run `regress wwage76` on only those selected variables. Compare the post-LASSO OLS coefficients on `wedyrs` and `wexper` to the plain OLS coefficients from Task 2. What does shrinkage bias correction achieve here?

Its basic syntax is `lasso linear depvar (varlist), rseed(#)` — the parentheses around the predictor list mark them as "always eligible" for selection. After estimation, type `lassoknots` or look at the output table to see which lambda minimizes cross-validation error.

- **Hint 2 (Task 4)**: You can simply extend the predictor list inside the parentheses.
