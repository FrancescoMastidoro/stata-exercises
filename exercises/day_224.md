## Background
The NLSY 1980 dataset contains cross-sectional data on 935 workers, including wages, education, cognitive test scores, and family background variables — a classic setting for returns-to-education research. Instrumental variables (IV) estimation is essential when explanatory variables like education are endogenous, and combining IV with LASSO-based control selection represents a modern approach used in applied labor economics.

## Your tasks

1. **Explore the instrument candidates** — Load the dataset and summarize `educ`, `lwage`, `iq`, `kww`, `pcollege`, `fcollege`, and `meduc`. Check for missing values in `meduc` and `feduc`, and report how many observations are complete on all six variables.

2. **OLS benchmark** — Regress `lwage` on `educ`, `exper`, `tenure`, `black`, `south`, `urban`, and `married`. Store the results using `estimates store ols`. Interpret the coefficient on `educ` in one comment.

3. **IV estimation** — Re-run the wage regression using `ivregress 2sls`, instrumenting `educ` with `pcollege` (whether father attended college) and `fcollege` (whether father is a college graduate). Keep the same control variables as in Task 2. Store results as `estimates store iv`. Compare the IV and OLS coefficients on `educ` using `estimates table ols iv, b se`.

4. **First-stage check and endogeneity test** — After the `ivregress` command, run `estat firststage` to inspect the first-stage F-statistic and assess instrument relevance. Then run `estat endogenous` to formally test whether `educ` is endogenous. Interpret the p-value in a comment: does the test suggest OLS is inconsistent here?

5. *(Bonus)* **LASSO-selected controls** — Use `lasso linear lwage (educ = pcollege fcollege) iq kww exper tenure black south urban married sibs age` with the `xporegress` command (or `ivlasso` via `pdslasso` if installed) to let the data-driven method select controls while preserving the IV structure. Compare the coefficient on `educ` to your Task 3 result and comment on any differences in a brief note.

## Hints

<summary>Click to reveal hints (try first!)</summary>

- **Hint 1 (Task 1)**: Use `misstable summarize` or `codebook` to identify missing values — remember that `meduc` has 78 missing and `feduc` has 194 missing according to the data reference; use `mark` or `count if !missing(...)` to count complete cases across variables.
- **Hint 2 (Task 3)**: The `ivregress 2sls` syntax places the endogenous variable and its instruments inside parentheses: `ivregress 2sls depvar controls (endogvar = instruments)`.
- **Hint 3 (Task 4)**: `estat firststage` and `estat endogenous` must be called *immediately after* `ivregress` — if you re-run any other estimation command in between, the stored results will be overwritten. A first-stage F > 10 is the conventional weak-instrument threshold.
- **Hint 4 (Task 5)**: The `xporegress` command (available in Stata 16+) handles IV-LASSO natively; its syntax follows `xporegress depvar (endogvar = instruments), controls(varlist)`. If unavailable, the `pdslasso` package (installable via `ssc install pdslasso`) provides an alternative.
