## Background
The PSID extract contains panel data on 595 workers observed over 7 time periods, with information on wages, union status, occupation, and demographics. Difference-in-differences (DiD) is a cornerstone method in labor economics for estimating causal effects by comparing changes over time across treatment and control groups.

## Your tasks

1. **Load and inspect the panel** — Load the dataset, declare it as a panel using `xtset` with `id` as the individual identifier and `t` as the time variable, then summarize `lwage`, `union`, `south`, and `fem` to get a sense of the data.

2. **Construct a treatment indicator** — Define a binary variable `treated` equal to 1 if a worker is in the South (`south == 1`) and is female (`fem == 1`), and 0 otherwise. Tabulate `treated` to confirm how many worker-period observations fall into each group.

3. **Identify a post-period** — Create a binary variable `post` equal to 1 for time periods `t >= 5` and 0 otherwise. Then compute the group-by-period mean of `lwage` for all four cells (`treated` × `post`) using `tabstat lwage, by(treated) statistics(mean)` run separately for pre and post periods — do this using `if` conditions.

4. **Run the DiD regression** — Estimate a DiD model regressing `lwage` on `treated`, `post`, and their interaction `treated_post` (create this product variable first). Include `ed`, `exper`, and `union` as controls. Use `reg` with robust standard errors. Interpret the coefficient on the interaction term.

5. *(Bonus)* **Add individual fixed effects** — Re-estimate the DiD using `xtreg lwage post treated_post ed exper union, fe vce(robust)`. Note that `treated` drops out — explain in a comment in your do-file why this happens, and compare the interaction coefficient to the pooled OLS result from Task 4.
