# Day 227: Difference-in-Differences with Panel Data

## Background
The PSID extract contains 4,165 observations tracking 595 individuals over 7 time periods, with information on wages, union status, occupation, and demographics. Difference-in-differences (DiD) is a cornerstone of modern causal inference in labor economics, allowing researchers to estimate treatment effects by comparing changes over time across groups.

## Your tasks

1. **Load and inspect the panel** — Load `webuse psidextract`, then use `xtset` to declare the panel structure using `id` as the individual identifier and `t` as the time variable. Confirm the panel is balanced by checking how many observations each individual contributes.

2. **Define treatment and post indicators** — Create a dummy variable `treated` equal to 1 if the individual is in a union (`union == 1`) in the *first* period they appear (`t == 1`), and 0 otherwise. Then create a `post` dummy equal to 1 if `t >= 4` (the second half of the panel). *(Hint: you may need `bysort` and `egen` to assign the period-1 union status to all observations for the same individual.)*

3. **Compute group-level mean wages** — Using `tabstat lwage`, report the mean of `lwage` separately for the four DiD cells: (treated × pre), (treated × post), (untreated × pre), (untreated × post). Then manually compute the DiD estimate from these four means.

4. **Estimate the DiD regression** — Run an OLS regression of `lwage` on `treated`, `post`, and their interaction `treated##post`. Interpret the coefficient on the interaction term and compare it to your manual DiD calculation from Task 3. Add individual fixed effects using `areg` with `absorb(id)` and comment on how the estimate changes.

5. *(Bonus)* **Test the parallel trends assumption** — Restrict the sample to the pre-period (`t <= 3`) and run a regression of `lwage` on the interaction of `treated` with period dummies for `t == 2` and `t == 3` (using `t == 1` as the baseline). If parallel trends holds, what pattern would you expect to see in the interaction coefficients, and do your results support it?
