## Background
The NLSY 1980 cross-section contains wage, human capital, and demographic variables for 935 workers, making it an ideal sandbox for wage equation estimation. LASSO (Least Absolute Shrinkage and Selection Operator) is increasingly used in labor economics to select predictors from a large candidate set in a principled, data-driven way, reducing the risk of ad-hoc model specification.

## Your tasks

1. **Load and inspect** — Load the dataset, then run `describe` and `summarize` to familiarise yourself with the variables. Note that `lwage` (log monthly wage, range 4.74–8.03) will be your outcome, and that `brthord`, `meduc`, and `feduc` have missing values. Use `misstable summarize` to confirm how many observations have at least one missing value across any variable.

2. **Restrict the sample** — Before running LASSO, create an estimation sample that drops all observations with *any* missing value in `brthord`, `meduc`, or `feduc`. Use `mark` and `markout` to create a sample indicator variable called `esample`, then `keep if esample == 1`. Report how many observations remain with `count`.

3. **Fit a LASSO regression** — Using `lasso linear`, regress `lwage` on the full set of candidate predictors: `hours iq kww educ exper tenure age married black south urban sibs pcollege college fcollege brthord meduc feduc`. Use the default cross-validation tuning (`selection(cv)`). After estimation, display the selected variables using `lassocoef`.

4. **Post-selection OLS** — Use `lasso linear` with `selection(cv)` as before, then immediately run `lassoselect` to confirm which lambda was chosen, and finally run `lasso postselection` OLS by calling `lasso linear ..., selection(cv) postestimation(ols)`. Compare the coefficient on `educ` between the penalised LASSO estimates and the post-selection OLS estimates using `lassocoef, display(coef)`.

5. *(Bonus)* **Cross-fit partialling-out (double LASSO)** — Suppose you want a valid inference-ready estimate of the return to `educ` while controlling for all other variables as potential confounders. Use the `xporegress` command (cross-fit partialling-out) to regress `lwage` on `educ`, with `hours iq kww exper tenure age married black south urban sibs pcollege college fcollege brthord meduc feduc` as controls. Interpret the resulting coefficient and its standard error. How does it compare to a simple OLS of `lwage` on `educ` alone?

## Hints

<summary>Click to reveal hints (try first!)</summary>

- **Hint 1 (Task 2)**: `mark esample` creates a 1-for-all variable; `markout esample varlist` then sets it to 0 wherever any variable in the list is missing. After `keep if esample == 1`, use `count` to see how many rows remain.

- **Hint 2 (Task 3)**: The basic syntax is `lasso linear depvar varlist, selection(cv)`. Stata's `lasso` suite requires version 16+. After fitting, `lassocoef` with no options prints the non-zero coefficients at the selected lambda.

- **Hint 3 (Task 4)**: The `postestimation(ols)` option runs OLS on only the variables LASSO kept non-zero. To compare both sets of coefficients side-by-side, `lassocoef, display(coef)` shows penalised estimates; store results with `estimates store` before and after to use `estimates table`.

- **Hint 4 (Bonus)**: `xporegress` syntax mirrors `poregress` but adds cross-fitting for valid inference. The key argument structure is `xporegress depvar mainvar, controls(varlist)`. The resulting point estimate can be interpreted as a causal effect of `mainvar` *under the assumption* that all relevant confounders are captured in the controls list.
