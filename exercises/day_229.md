## Background
The PSID extract contains 4,165 observations tracking 595 individuals across 7 time periods, recording wages, employment characteristics, and demographics. Difference-in-differences (DiD) is a cornerstone identification strategy in labor economics, exploiting variation across groups and time to estimate causal treatment effects.

## Your tasks

1. **Load and explore the panel structure** — Load the dataset, then use `xtset` to declare the panel structure using `id` and `t`. Confirm the panel is balanced by checking how many observations each individual contributes.

2. **Define treatment and post indicators** — The variable `union` records union membership status (0/1). Create a binary variable `post` equal to 1 if `t >= 4` (the second half of the panel) and 0 otherwise. Then create an interaction term `union_post = union * post`. Tabulate `union` and `post` jointly to inspect the cross-group cell counts.

3. **Run a basic DiD regression** — Regress `lwage` on `union`, `post`, and `union_post` using `xtreg` with the `fe` option to absorb individual fixed effects. Report and interpret the coefficient on `union_post`: what does it estimate?

4. **Add time-varying controls and cluster standard errors** — Re-run the fixed-effects DiD regression from Task 3, now adding `ed`, `exp`, `wks`, `south`, and `smsa` as controls. Cluster standard errors at the `id` level using the `vce(cluster id)` option. Compare the coefficient and standard error on `union_post` to your Task 3 results.

5. *(Bonus)* **Test the parallel trends assumption informally** — Create separate period dummies for each value of `t` (1 through 7) and interact each with `union`. Regress `lwage` on these interaction terms plus individual fixed effects using `xtreg, fe`. Plot the interaction coefficients using `coefplot` (if installed) or `margins`. Do the pre-period (t < 4) interaction coefficients look close to zero, as parallel trends would require?
