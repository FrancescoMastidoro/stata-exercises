## Background
The Grunfeld dataset contains firm-level investment, market value, and capital stock data for 10 large U.S. corporations observed annually from 1935 to 1954, making it a classic panel used in econometrics teaching. Difference-in-Differences (DiD) is a cornerstone method in labor and industrial economics for estimating causal effects when randomized assignment is not feasible, exploiting variation across groups and over time.

## Your tasks

1. **Declare and describe the panel** — Load the dataset, declare it as a panel using `xtset` with `company` as the panel identifier and `year` as the time variable. Then use `xtdescribe` to confirm the panel is strongly balanced.

2. **Construct treatment and post indicators** — Create a binary variable `treated` equal to 1 for companies with `company <= 5` (the "treated group") and 0 otherwise. Then create a binary variable `post` equal to 1 for years 1945 and later, and 0 for years before 1945. Tabulate the cross-distribution of `treated` and `post` to verify cell counts.

3. **Run the baseline DiD regression** — Regress `invest` on `treated`, `post`, and their interaction `treated#post` using `regress`. The coefficient on the interaction term is your DiD estimate. Interpret its sign and magnitude in a comment.

4. **Upgrade to a two-way fixed effects (TWFE) specification** — Re-run the DiD regression using `xtreg` with the `fe` option to absorb company fixed effects, and manually include year fixed effects by adding `i.year` as regressors. Use `vce(cluster company)` for clustered standard errors. Compare the interaction estimate to the one from Task 3 and note what changes.

5. *(Bonus)* **Pre-trend check** — Instead of a single `post` dummy, create a set of event-time dummies relative to the "policy year" 1945 (i.e., `year - 1945`, ranging from −10 to +9). Omit the period `t = -1` as the reference category. Run the TWFE regression with these event-time dummies interacted with `treated` and plot the coefficients using `coefplot` (if installed) or `marginsplot`. Comment on whether pre-treatment coefficients are close to zero, as required for the parallel trends assumption.

- **Hint 1 (Task 2)**: Use `generate treated = (company <= 5)` and `generate post = (year >= 1945)`. Remember that logical expressions in Stata return 1 if true and 0 if false — no `if` branching needed. Use `tab treated post` to check cell counts.
- **Hint 2 (Task 3)**: In `regress`, Stata's factor-variable notation lets you write `i.treated##i.post` to automatically generate the main effects and interaction in one go — you do not need to create the interaction variable by hand.
- **Hint 3 (Task 4)**: `xtreg invest i.post i.treated#i.post i.year, fe vce(cluster company)` — note that with `fe`, the time-invariant `treated` main effect is absorbed by the fixed effect, so you drop it from the right-hand side.
- **Hint 4 (Bonus)**: Generate `gen etime = year - 1945` and then use `i.treated#ib(-1).etime` inside `xtreg` with `fe`. The `ib(-1)` syntax sets `etime == -1` as the base category.
