## Background
The `regsmpl` dataset is a panel of NLS women observed across survey years from 1968 to 1988, containing wages, education, work experience, and geographic identifiers. Difference-in-differences (DiD) is a cornerstone method in labor economics for estimating causal effects of policies or events by comparing changes over time across treated and untreated groups.

## Your tasks

1. **Load and inspect the panel** — Load the dataset, declare it as a panel using `xtset`, and summarize the key variables `ln_wage`, `south`, `black`, `ttl_exp`, and `year`. Report how many unique individuals and time periods are in the data.

2. **Define treatment and post indicators** — Create a binary variable `treated` equal to 1 if `black == 1`, and a binary variable `post` equal to 1 if `year >= 78` (i.e., 1978 onward). Then create the interaction term `did = treated * post` by hand. Tabulate `treated` and `post` jointly to verify cell counts.

3. **Run a simple DiD regression** — Regress `ln_wage` on `treated`, `post`, and `did` using `regress`. Interpret the coefficient on `did`: what does it represent in a DiD framework? Note whether it is statistically significant at the 5% level.

4. **Add controls and cluster standard errors** — Re-run the DiD regression adding `ttl_exp`, `grade`, and `south` as controls. Cluster standard errors at the `idcode` level using `vce(cluster idcode)`. Compare the standard error on `did` to the unclustered version from Task 3 and explain why clustering matters for panel data.

5. *(Bonus)* **Event-study plot** — Instead of a single `post` dummy, create a set of year dummies interacted with `treated` (omitting one pre-treatment year as the reference, e.g., `year == 77`). Run the regression with these interaction terms, individual fixed effects (`i.idcode`), and `ttl_exp` as a control. Use `coefplot` (if installed) or `estimates store` followed by manual extraction to plot the interaction coefficients across years — this is the basis of an event-study diagram that checks the parallel trends assumption visually.
