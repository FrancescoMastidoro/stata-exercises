**Dataset**: `webuse nlsy80`

## Background
The NLSY 1980 dataset contains a rich cross-section of young workers with earnings, cognitive scores, education, and family background variables — a classic setting for studying wage determination. LASSO (Least Absolute Shrinkage and Selection Operator) is increasingly used in labor economics to perform principled variable selection when the researcher faces many potential regressors and wants to avoid over-fitting.

## Your tasks

1. **Load and inspect the data** — Load `webuse nlsy80`, then run `describe` and `summarize` to familiarise yourself with the variables. Note that `lwage` is the log of monthly earnings and that `brthord`, `meduc`, and `feduc` have missing values. Use `misstable summarize` to confirm the missing pattern before proceeding.

2. **Estimate a standard OLS baseline** — Regress `lwage` on `educ`, `exper`, `tenure`, `iq`, `kww`, `age`, `married`, `black`, `south`, `urban`, and `sibs`. Store the estimates with `estimates store ols_baseline` and note the R² and coefficient on `educ`.

3. **Run LASSO with the same covariate set** — Use Stata's `lasso linear` command to predict `lwage` using exactly the same eleven regressors as in Task 2. After estimation, run `lassocoef` to display which variables were retained in the selected model and compare the retained set to the OLS specification.

4. **Post-LASSO OLS and coefficient comparison** — Use `lassoselect` (or inspect the LASSO output) to identify the lambda that minimises the cross-validation criterion, then run a plain OLS regression containing only the variables that LASSO selected at that lambda. Store these estimates as `estimates store post_lasso`. Finally, use `estimates table ols_baseline post_lasso, b se` to place the two models side by side and comment (in a code comment) on how the coefficient on `educ` changes.

5. *(Bonus)* **Add squared and interaction terms** — Create `exper2 = exper^2` and `tenure2 = tenure^2`, then interact `educ` with `iq` to form `educ_iq = educ * iq`. Re-run `lasso linear lwage educ exper exper2 tenure tenure2 iq kww educ_iq age married black south urban sibs` with the enriched covariate set. Examine how the selected model changes compared to Task 3 and reflect (in comments) on why LASSO's penalty helps discipline this expanded specification.

- **Hint 1 (Task 3)**: The LASSO command in modern Stata follows the syntax `lasso linear depvar varlist`. After running it, `lassocoef` lists nonzero coefficients at the chosen lambda — read the output carefully to see which variables survive shrinkage to zero.

- **Hint 2 (Task 4)**: The cross-validation selected lambda is reported in the `lasso linear` output under "CV". You can explicitly select it with `lassoselect cv` before using `lasso postselection ols` or simply running a manual `regress` with only the surviving variables — both approaches are valid for a beginner.
