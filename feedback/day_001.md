## What to work on

For Task 4, always re-read what the task asks the output to contain and map each requirement to a command option — here `, percent cumulative` (or just `tabulate foreign, cum`) is all that was missing, but omitting it means the output does not satisfy the specification. For the bonus, internalize the rule that `by varlist:` requires the data to already be sorted on `varlist`; prefer `bysort foreign: summarize price mpg` as a single safe command that handles sorting automatically. Getting into the habit of checking option lists in `help tabulate oneway` and `help by` will catch both of these gaps quickly.
