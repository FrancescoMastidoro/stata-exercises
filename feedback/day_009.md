## What to work on

There is nothing substantively wrong in this solution. For future work, note that `count if hours > 60` would be risky if `hours` could contain system missing values (since Stata treats `.` as larger than any number), so habitually writing `count if hours > 60 & !missing(hours)` is a safer practice — as you correctly applied in Day 8 retries. Consider also using `assert` statements (e.g., `assert iq >= 50 & iq <= 145 if !missing(iq)`) as a more rigorous alternative to `count` for range checks, since a failing assert immediately flags a problem rather than requiring you to inspect the count output.
